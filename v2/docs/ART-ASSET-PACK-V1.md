## 1. 北极星与视觉原则

- 画面参考：温暖灯笼照明的精致奇幻木结构工坊、铜制蒸汽装置、玻璃温室、月光蓝城市远景；强调**可操作的微缩世界**，不是整张概念插画。
- 镜头：固定斜俯视 3/4 视角，所有设备一致；主光源画面左上方暖橙，右上/背侧冷蓝轮廓光，地面接触阴影向右下延伸。
- 原创美术，不截取其他游戏素材、不临摹受版权保护角色；画面内不得绘制按钮、中文菜单、数值、Logo、水印。
- 不使用 SVG 改名 PNG、单张静图缩放假装 8 帧，也不把一张完整工坊概念图贴成不可交互场景。
- 调色板：月夜 `#24334F`，暗蓝 `#465E87`，黄铜 `#CB9C61`，熔火 `#F0A85D`，玻璃 `#8BCFC6`，植被 `#81AD83`，象牙白 `#F4E6C9`。
- 当前仓库 `art/*.avif` 是几 KB 的**低清过渡素材**，不可充当正式高清资产；程序绘制的角色八帧也非最终手绘帧。只有正式图集接入、浏览器质量门槛达标后才能把相应清单条目标记 ready。

## 2. 游戏可操作区域与图层契约

当前 PixiJS 棋盘必须保留已有逻辑坐标：桌面逻辑视口 **1050 × 645**、手机 **830 × 820**；固定格子 **146 px**，中心距 **160 px**，5 列 × 3 行；桌面起点 (131,104)，手机起点 (15,225)。资源流动严格四向相邻，任何艺术改版不得改变机器点击热区和世界快照。

后景 → 前景：**远景月亮/窗外建筑 → 墙梁与家具 → 石板地块 → 机器底座 → 设备主体 → 工匠角色 → 设备前景遮挡 → 资源光效/交付反馈 → 独立 DOM 操作台**。需分离 PNG/WebP 精灵，不得以画好的机器背景阻挡移动后机器所在位置。

锚点：设备 `(.5,.92)`、人物 `(.5,1)`；透明像素外轮廓留 **至少 24 px** 安全边距、落地阴影独立层；升级三等级轮廓与底座对齐。导出统一透明通道、sRGB、无背景、禁止白底/黑底假透明。正式源稿保留可编辑分层文件，运行包只取压缩 WebP/PNG。

## 3. 三台机器的正式规格

| 设备 | 视觉轮廓 | 1→2→3 级的实质区别 | 互动反馈 |
|---|---|---|---|
| **水汽泵 / well** | 青蓝圆顶水胆、黄铜立管、冷凝环 | Lv1 单泵；Lv2 双阀门和强化管线；Lv3 透明双水胆与水雾导流罩 | 运行时活塞推进、水位变化、雾气喷吐；停工时阀门不动 |
| **孢子温室 / garden** | 绿叶包裹的拱形透明玻璃罩 | Lv1 单层温室；Lv2 多层种植架和导水管；Lv3 双层穹顶、额外生长盆 | 孢子闪光与叶片轻摆；断水时暗淡，不制造虚假的生产粒子 |
| **晶核熔炉 / kiln** | 深铜铁炉身、橘色炉口、高烟囱和晶核模具 | Lv1 普通熔炉；Lv2 第二组导热鳍片和加宽炉口；Lv3 双火口、强化导轨和发亮铆钉 | 有输入时炉口发光、火舌跃动、晶核成型；缺孢子时熄火 |

每台提交：`lv1.webp`、`lv2.webp`、`lv3.webp`（均为 **512×512** 透明画布），以及 `working.webp`（**2048×512**，4 列 × 1 行，每帧 512×512）；机身静图不内嵌会遮挡其他地块的冗长烟雾。若需要更多帧，另提交扩展图集并同步 manifest，不向源美术私自拉伸插帧。

**绘制提示词主干（供原创概念生成/美术）：** 手绘奇幻经营游戏中的可移动单体炼金设备、固定 3/4 斜俯视角、深色桃花心木与磨砂黄铜、精细铆钉/刻线/真实玻璃折射、暖橙局部光配冷蓝轮廓光、可读轮廓、无任何背景与文字、透明画布、完整底座和接触阴影。分别加入上一表中唯一辨识轮廓，不可三台机器仅换颜色。

## 4. 月纱（28 岁成年魔女）

身份是专业商人而不是装饰头像。人物应具备成年人面部骨相与成熟气质，深紫发、月牙金饰、露肩深色礼装、收腰与高开衩、长手套、披风，性感但不露骨；主要亮点为手套的丝绒质地、金饰反光、眼神和独特职业道具（契约卷轴）。保留可识别的服装结构，不能每个表情改脸和身高。

- `full.png` **1024×1536** 全身透明立绘，用于人物档案与详情；宽度受 UI 限制，不遮挡棋盘。
- `bust.png` **1024×1024** 半身高精度立绘，用于订单对话；对话文字始终由 DOM 渲染，不写死在图片。
- `idle.webp`、`talk.webp`、`trade.webp` **2048×1536**，4×2 图集，每帧 **512×768**，8 帧；循环分别为呼吸/眨眼、口型/目光和递交契约卷轴。帧内人物锚点位置保持一致。
- 成功、失败情绪先由口型和表情片段组合，后续另做独立表情层。所有交互延续已有共享库存、135 星币成功奖励、20 星币违约扣费，不新增无关好感度按钮。

## 6. 验收门槛（必须通过）

1. **美术**：单独放大看无锯齿/贴图拉扯；三机 1×缩放明显不同；2560×1600 和 390×844 截图中能分辨 Lv1/2/3、工种、炉火是否工作。
2. **交互**：五列三行每个地块仍能被点击，移动后设备不会留下绘景残影。水泵→温室→熔炉断链与真实库存计算不受美术影响。
3. **性能**：桌面目标 60 FPS，移动目标稳定不低于 30 FPS（以实际设备测量）；首屏美术包建议控制在移动端 **2.5 MB 内**，其余按需加载，超额需记录原因而不是盲目压成无法辨识的小图。
4. **动画**：8 帧不是一张静图平移；月纱至少能看出独立的眼睛/发丝/披风微动作。停工与工作不同，动画节奏不因点击工具栏从头重播。
5. **页面**：手机不出现双向页面滚动，订单按钮与数值无遮挡；开启减少动态效果时仍能清楚读取状态。
6. **发布**：运行 `npm --prefix v2 run audit:art`，随后 TypeScript / Vitest / Playwright 全绿且 GitHub Pages 成功；正式机型原始截图、资源来源授权及图集逐帧验收一并记录。
