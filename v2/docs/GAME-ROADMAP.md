# 《月光工坊》V2 完整游戏开发蓝图

> 状态：可运行实验版本，不是完整商业游戏。研发版本均落在主分支，旧 V1 保留，V2 独立存档。本文是里程碑与验收规范，已交付和未交付明确区分。

## 1. 产品定位

**类型：** 固定斜俯视角奇幻工坊建造经营 + 生产链优化 + 怪物工种管理 + 角色互动。

**目标体验：** 玩家能从一间略显凌乱的夜间工坊起步，通过调整相邻设备、投资升级和安排合适的怪物工匠，完成不断升级的真实订单，让工坊成长为灯火通明的月光商区。困难来自有限土地、材料流动、工位、现金与期限，而不是重复点击爱心。

**美术北极星：** 用户提供的月夜立体木铜玻璃工坊参考图；烛光暖橙、月色深蓝、植物翠绿、玻璃高光与精致角色。图仅作美术规范，**禁止把整张图贴成无法操作的背景冒充游戏**。

**角色尺度：** 泉泡/青枝/炽角等小型魔物保持非性化造型；成年女性类人角色可用更成熟、露肩露腰、较少覆盖的礼服以及有魅力的性格设计，但不涉及幼态人物性化或露骨内容，明确成年设定及与经营相关的选择。

## 3. 下一阶段：从实验室走向完整经营游戏

### M1 — 垂直切片完善（当前阶段）
**完成标准：** 玩家无额外解释即可完成前五单；错误布局有清楚反馈；升级/就业/访客选择有实际利弊；手机竖屏可一屏操作；旧存档持续兼容；流水线 E2E 全绿。
**排除：** 没有画面功能的纯签到/任务/好感度按钮。

### M2 — 正式的美术生产流水线（未完成）
- 从用户批准的场景参考图制作“可独立寻址”的木平台、屋檐、栏杆、黄铜设备、玻璃温室、灯具、窗景等 PNG/WebP 图块
- 正式图层：远景 / 建筑结构 / 机器基座 / 角色 / 粒子与灯光 / 文字 HUD；明确 Z 轴与遮挡排序
- 3 名工匠各：待机 8 帧、步行 8 帧、工作 8–12 帧、胜利及疲惫各 4–6 帧，人物尺寸和锚点统一
- 成人类人 NPC：待机、说话、交付、不同情绪，特殊服装设计统一质感
- 真正加载纹理图集并复用贴图，**不用 SVG 改后缀 / 程序生成的同色圆点假装正式美术**
- 目标验收：独立截图对照、手机画面可读、60 FPS 桌面与适宜设备的稳定移动端帧率、可控内存与资源尺寸

### M3 — 产业扩张（未完成）
- 至少三条不同的可替代生产路线和可切换产品配方，不只沿用水泵→温室→熔炉单一答案
- 建立传送带 / 资源箱 / 仓储容量、拥堵解决与不同工段节拍
- 大型订单要求玩家考虑保留库存、拒绝订单和临时改线而不是单一升级数值
- 不预先堆 30 台无意义设备：每种设备先证明有独特布局价值，再扩展

### M4 — 工坊世界与居民生活（未完成）
- 角色工作时自主行动 / 休息 / 互动的场景动画与工位分配，不靠静止头像呈现
- 固定数位明确成年的关键 NPC，有专属剧情与职业能力；关系发展通过真实合作解锁事件
- 建造影响小镇评价、访客类型、装饰与生产空间的取舍
- 日夜、天气、节庆具有可感知的视觉或交易变化，不止换背景图片

### M5 — 正式发布质量（未完成）
- 音效、循环 BGM、音量/静音、减少动态效果、键盘/触控反馈
- 存档迁移、导入导出、异常保存恢复、无效数值防护、断网可玩（条件允许）
- 平衡验证：前五单、前 20 天、困境恢复、订单失败不软锁、货币增长有边界
- 页面加载大小、场景性能监测、移动端弱机和多个浏览器兼容
- 连贯教程、成就回顾、清晰的自定义目标以及可发布的品牌页面

## 4. 经济与升级设计（已落地的首版）

| 机器 | Lv.2 价格 | Lv.3 价格 | 效果 |
|---|---:|---:|---|
| 水汽泵 | 40 | 88 | 每级额外 +1 水汽/日 |
| 孢子温室 | 48 | 98 | 每级额外 +1 孢子/日，依然需要相邻水泵 |
| 晶核熔炉 | 60 | 124 | 每级额外 +1 晶核/日，依然消耗两份相邻孢子 |

- Lv.2 需要先完成第一单；Lv.3 需要完成第三单
- 完成第三单一次性追加 70 星币，完成第五单一次性追加 160 星币
- 同一机器升级与搬迁不能重复领取奖励、不能在负现金时升级；旧机器没有 level 字段意味着 Lv.1
- 关键策略：更多水汽不代表一定更多晶核；玩家须识别哪一环真正限制了产量

## 5. 工程发布规则

- `main` 为唯一开发主线；提交后先执行严格 TypeScript、Lint、Vitest、静态构建，再执行 Playwright 桌面/手机真实浏览器
- CI 全绿后确认 Pages 工作流成功，才使用“已上线”措辞；任何旧存档不丢失
- 永远保留旧版主页 `/` 与独立 V2 `/workshop/`，直到正式决定发布切换
- 不能用“概念图很精美”冒充“游戏素材已经集成”；逐帧表现必须在真实浏览器截图 / 视频帧中验收
- 每次升级先回答：玩家做了什么有意义的决定、付出了什么、看到了什么变化；无法回答时不增加按钮
