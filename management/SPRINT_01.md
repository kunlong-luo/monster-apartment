# Sprint 01：第一轮玩法验证

**建议周期：** 2026-10-20 至 2026-11-03（可根据现实时间调整）

## Sprint Goal

能让独立试玩者不看开发代码就完成五天经营、感受到房间组合的影响。

## 交付物

- Web V0.1、README、规则单元测试、手动验收清单。
- 至少 5 个试玩反馈样本；从中得到“哪里不懂 / 哪个组合好玩 / 会不会重玩”的结论。
- 修复阻断游玩的缺陷；不加多余玩法。

## 本地待办

1. `npm install` 并运行 React/Phaser 页面，记录实际环境结果。
2. 运行 `npm run test:rules` 和 `npm run build`，如报错，优先修复。
3. 浏览器实际完成 5 天经营；试一局赢、一局输。
4. 在不同窗口宽度测试按钮可用性和文本显示。
5. 邀请真实玩家试玩并记录反馈。

## Definition of Done

完成 = 代码可以启动 + 相关操作可验收 + 没有已知严重阻断问题 + 任务 CSV 标记 DONE + changelog 有记录。

如果某一条无法达标，状态记 BLOCKED，不标称已完成。
