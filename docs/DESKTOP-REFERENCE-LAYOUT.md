# 《怪物公寓》参考图布局验收 · V3.87

原稿参照：用户已认可的四张哥特大厅设计图（横向 1536×1024，中央银发赤瞳女主人、左侧四人名册、右侧月蚀活动与绘景海报、底部七项功能导航）。这些是**用户提供的视觉基准**，不是已烘焙 UI 的可直接游戏背景。

## 当前截图对比发现的真实差异

- V3.86 的自动截图左侧是较宽的主线任务和契约图文卡，没有四位住客列表。
- 右侧只有尺寸很小的三个功能方块，与原稿强调的右侧月蚀大海报 + 图像菜单不同。
- 原稿强调中央女主人、通透场景和大面积留白；当前页面存在不必要的中央空白，用户难以发现说话/人物房间的入口。
- V3.86 还存在截图采样早于图片完全载入的情况，部分快照只有暗色底图；即使布局代码正常，也不能把加载中的图当成最终视觉。

## 本轮修正

使用一个统一的桌面参考布局样式：`src/components/game/gothic-reference-layout.css`，在 `src/components/game/gothic-lobby.tsx` 中将已有功能组合成**左人像、右海报、中人物、底导航**。已保留工坊委托、召唤、对话、房间、剧情回顾的真实操作。只做布局，不改抽卡结果、资源、存档、七个基础路由及角色画面来源。

验收优先使用 `e2e/gothic-desktop-hud.spec.ts` 里的 1440×900 及 1648×928 断言、主图像 `naturalWidth` 和截图。现有的 `lobby-hero-v3.webp` 绘画中人物构图和参考图仍有差异；**本轮解决布局，尚未宣称重绘人物或达到像素级 1:1**。

## 不允许的回退

不得将本次恢复的左侧人物名单再次替换为 KPI/任务看板；不得只保留右侧小图标按钮；不得为该桌面参考布局添加第八个路由或使功能浮层遮住人物。具体布局数值和原则已加入 `DESIGN.md`。
