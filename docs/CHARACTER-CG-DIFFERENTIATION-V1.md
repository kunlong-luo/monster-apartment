# 《怪物公寓》角色 CG 差异化制作规范 V1

> 2026-11-21 冻结第一轮重绘镜头表。**本文定义制作要求，不代表 CG 已重画、人工审核通过或已上线**。镜头的可执行结构存于 `docs/art-reviews/CG-DIFFERENTIATION-SHOT-LIST.json`。

## 1. 目标与边界

五张卡对应 **四位独立人物**，而不是五张不同的脸。两张月纱卡共用同一人物身份；但卡面场景、姿势、服装、武器和情绪必须显著不同。泉泡、青枝、炽角要从骨相、眼距、眉形、鼻梁、嘴唇、耳形、体态、衣服轮廓和武器用途区分，不能只依靠发色或背景。

当前候选图仅约 **1086×1448**；正式生产要用原生至少 **1536×2048** 的独立 3:4 画布，从头顶/武器尖端到鞋尖均留安全边距。插值放大不算新的原生绘画。绘景必须是单角色单图；不允许拼贴、角色排列四宫格、烘焙 UI、虚构品阶字样。

## 2. 强制差异化的六个轴

1. **脸部身份**：同一角色有稳定的下颌、颧骨、眼距、眉眼弧度和鼻唇特征；不同角色不可共享一套面部模板。月纱月蚀/誓约例外：她们必须是**同一张脸**，只改变表情、妆容浓淡和发饰配置。
2. **骨架与重心**：五张画面分别使用前踏支配、侧坐邀约、踏浪旋身、侧身拉弓、低重心战斗五个不同主姿势；不能全部站直、双脚并排、双手自然下垂。
3. **武器与手部动作**：每把武器必须被人物真实握持/操控、方向与受力合理；禁止只把武器浮贴在旁边，也禁止抽象发光团代替指定武器。
4. **服装轮廓与材质**：战斗礼服、仪式轻纱、潮汐透纱、游侠轻甲、锻炉重甲五套不同纸样；鞋、护手、肩部、裙摆的结构必须可辨。仅换颜色不算换服装。
5. **构图与动态线**：长镰斜线、誓约坐姿弧线、踏浪 S 曲线、满弓三角线、火链外弧各自不同；建议从黑色剪影和缩略图就能区分，不靠特效遮挡脸或武器。
6. **场景与叙事**：每张独立环境讲清人物正在做什么，环境透视和投影、材质、接触阴影、头发和布料运动一致。不可把“统一模板换背景”当成完成。

## 3. 逐卡镜头和服装约束

### 1. 月纱·月蚀 (`yuesha-eclipse`)

- **脸部**：心形脸、银白长发、赤瞳、细长上挑凤眼（与誓约版同一张脸）
- **站姿/动作**：前脚落在台阶边缘，重心朝前，躯干三分之二侧转，左手前伸操纵血月、右手提起巨型长镰形成高对角线
- **剪影/动态**：tall-diagonal-crescent；下摆与长发被血月风暴卷向画面左侧，镰刃映出反向红色光轨
- **武器与受力**：月蚀长镰，镰刃沿画幅右上至左下切出独立弧线
- **服装**：黑金铠饰战斗礼服：硬挺束腰、分叉裙摆、非对称长披风、红宝石胸甲饰片；非婚礼礼服
- **机位**：略低机位 3/4 正面
- **环境**：血月哥特高塔/破碎玫瑰花窗
- **禁止**：双脚并拢正面站桩；把权杖当成镰刀；与誓约版共用裙装/姿态

### 2. 月纱·誓约 (`yuesha-vow`)

- **脸部**：心形脸、银白长发、赤瞳、细长上挑凤眼（必须与月蚀版保持同一身份）
- **站姿/动作**：侧坐在低矮祭坛边缘，膝盖朝左、上身朝镜头转回，左手掌心向上邀请缔约，右手让誓约细剑剑尖朝下轻触地面
- **剪影/动态**：soft-seated-veil-curve；纱袖柔缓垂落，手指与悬浮圣印形成柔和闭环
- **武器与受力**：纤细誓约剑与悬浮圣印，手腕必须有承重/连接关系
- **服装**：酒红银白色仪式礼服：细致刺绣、轻纱长袖、短拖尾、蔷薇胸针；无硬甲、分叉战裙或月蚀战斗披风
- **机位**：与坐姿齐平的 3/4 机位
- **环境**：月光誓约礼堂/银色烛台与拱窗
- **禁止**：换成另一张脸或换成黑发；举镰刀战斗；复制月蚀的高机位站立姿势

### 3. 泉泡·潮汐 (`brook-tide`)

- **脸部**：圆润鹅蛋脸、较宽眼距、柔和下垂大眼、自然圆润眉骨，保留原角色蓝色系耳朵特征
- **站姿/动作**：脚尖踏上起伏水浪，身体扭转呈 S 曲线，左臂拨出水环，右手把三叉戟向后上方斜举
- **剪影/动态**：s-curve-wave-trident；水流向两侧旋涡扩散，水蓝头发向后扬起，衣摆随浪倾斜
- **武器与受力**：珍珠镶嵌潮汐三叉戟，戟尖和水流相连形成动态引导
- **服装**：海蓝到珍珠白渐层的短外披、非对称多层薄纱水纹裙、贝壳护肩、水晶腰带，水润轻盈而非黑金宫廷裙
- **机位**：略高的斜角动态镜头
- **环境**：月夜水上宫殿/潮汐台阶
- **禁止**：女王尖脸与赤瞳妆；双脚平行正面端戟；使用玫瑰王冠或重铠

### 4. 青枝·春芽 (`fern-spring`)

- **脸部**：长椭圆脸、平直清秀眉、自然杏眼、略宽下颌角，绿瞳、花叶冠与浅金发保持辨识度
- **站姿/动作**：侧身弓步站在苔石上，前腿屈膝稳住重心，双手真实搭箭拉满藤弓，视线沿箭尖而非看镜头
- **剪影/动态**：triangular-drawn-bow；拉弓形成强张力，披风往后展，枝叶被弦风推动
- **武器与受力**：藤蔓活木弓与花苞灵箭，弓弦、箭羽、握弓/拉弦手指清楚且合理
- **服装**：绿金森林游侠轻甲、皮革护臂、叶片拼接短斗篷、便于拉弓的长靴与层叠短裙/裤装；不穿拖地宫廷礼服
- **机位**：水平侧面 3/4 广角
- **环境**：晨光林地/盘根温室与古树
- **禁止**：手持三叉戟；正面对称站桩；和泉泡采用相同柔软大眼/纱裙

### 5. 炽角·余烬 (`cinder-ember`)

- **脸部**：宽颧骨和鲜明下颌转折、略厚眉、尖锐猫眼、成熟挑衅的嘴角，保留红发与独特魔角
- **站姿/动作**：双脚大幅分立并弯膝，身体明显前倾，右臂甩出火焰锁链镰，左手回收链尾以控制弧线
- **剪影/动态**：angular-lunge-chain-arc；铁链由远向近形成速度线，红发逆风扬起，火花和碎炭从脚边炸开
- **武器与受力**：熔火锁链镰，链节有重量方向和正确握法，镰刃绕出完整外弧
- **服装**：炭黑赤铜非对称锻炉战甲、单侧金属肩甲、厚实护腰、分节护腿与战靴；衣片短而结构硬朗，与四张裙装区分
- **机位**：低机位近距离广角但保持整个人及武器完整
- **环境**：熔岩锻炉/铁砧桥与裂纹金属
- **禁止**：优雅并腿宫廷站姿；薄纱礼裙/花冠；与月纱同款细下巴脸

## 4. 重绘工序与提交约束

**阶段 G0 · 设计冻结**：锁定现有 canonical identity 参考，先做五人黑色剪影板和服装款式表。得到姿态与武器轮廓后，才开始细画脸和材质。

**阶段 G1 · 第一批三张**：`yuesha-eclipse` → `brook-tide` → `cinder-ember`。每张从独立原稿创作，保存源文件、原生尺寸、导出 WebP、sha256 与审查说明。未通过差异性对照不替换既有候选。

**阶段 G2 · 第二批两张**：`fern-spring` → `yuesha-vow`。月纱誓约必须与月蚀并排审查同一脸部，不允许把两张不同人物当作同一角色；但镜头/服装/姿势必须不同。

**阶段 G3 · 游戏适配**：完整 3:4 `contain` 预览 + A05 窄卡 `cover` 预览；1440×900、1648×928、390×844 三种真实浏览器尺寸分别记录。头饰、肩部、手部、武器要在完整查看中不截断，窄卡至少保证脸/身份清楚、铭牌不遮挡重要内容。

**阶段 G4 · 正式批准**：逐张检验手指、武器连接点、关节、透视、黑白剪影与小图辨识；做跨人物 2×2 比较并人工签署角色身份、权利来源和原生分辨率。不得自动将视觉规范 JSON 当作人审证明。只有 `art:cg:review` 和 `art:cg:promote` 的完整流程通过后才修改 `cg-manifest.json` 的生产状态。

- 候选路径：`public/art/beauty-beasts/characters/{yuesha,brook,fern,cinder}/cg-*-candidate.webp`，使用仓库已锁定的精确卡位表，不随意换路由。
- **绝不能**为了上线将低像素图放大当原生 CG、将 `status: portrait` 强行设为 `production`、将月纱退役黑发概念用作现行 identity 基准。
- 武器首先是**人物叙事与视觉身份设计**，不代表已经有战斗玩法；若要加入装备数值、技能与锻造，必须另外设计数据和游戏系统，不能靠美术暗示“已经实现”。

## 5. 人工差异化验收表（五张逐张填写）

- [ ] 将五张图的脸部裁切单独并排比较：四位人物明显不同，两张月纱明显同一人
- [ ] 纯黑剪影 96px 高仍能分辨至少四位角色及各武器主轮廓
- [ ] 每张的重心、关节、足部接触点符合动作逻辑，不存在统一模板站姿
- [ ] 五套服装版型差异可辨，至少肩、腰、裙/裤、鞋四处有不同结构，而非换色
- [ ] 武器轮廓完整，手指握持/弓弦/锁链运动合理，不悬空穿模
- [ ] 画面原生像素满足 1536×2048、3:4、头脚完整和无 UI
- [ ] 三种浏览器视口的完整图和窄卡图均人工审核并签署，检查版权与来源

**执行原则**：宁可延后晋级，也不使用同脸换装、武器贴片、重复站姿、低清放大等廉价生产替代高品质角色设计。
