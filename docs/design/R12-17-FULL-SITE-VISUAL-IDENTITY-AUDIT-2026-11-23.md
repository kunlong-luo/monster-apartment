## 结论：你的观察成立，但原因并不只有一个

1. **真正的同一图片误用，已经修复。** 首页左上角按钮名称是「玩家资料 · 夜色蔷薇」，原本却直接使用了月纱 `yuesha-avatar-v3.webp`。玩家和女主人同脸、同人像，是一个真实的身份混用 Bug。现在改为不会冒充任何人物的「夜」字蔷薇家纹，资料按钮和账号日数都保留。
2. **三人宣传封面被当作街景，已经修复。** `world-cover.webp` 是三位成年女性与野兽的哥特群像（1920×1080），脸部有近似的大眼、小鼻、尖下巴和神态。中间黑发人物不符合现行银发赤瞳的月纱身份锚点，**不能直接声称她就是月纱，更不能当作月光街商铺环境**。`/town/` 的主画框现改成已有 `town-moonlit-gate.webp`（1920×1080 建筑入口**过渡**绘景）；三个实际可操作地点仍是工坊、委托、仓库。不是借此宣称独立真实商铺街景已经完工。
3. **四张身份头像不是重复文件，但骨相和表情的差别仍不够。** `brook/face.webp`、`fern/face.webp`、`cinder/face.webp`、`yuesha-avatar-v3.webp` 四个源图分别不同；视觉上却沿用了近似细下颌、相似眼线与娇柔表情。发色、兽耳/角、颜色不应成为辨别身份的唯一依据。**更换裁切/滤镜修不了人物同模版的问题，必须重新设计面部结构并逐人重画。**
4. **月纱·月蚀与月纱·誓约应同脸。** 这两张是同一个 `characterId` 的两张卡，服装/武器/站姿/故事可以不同，但若为了「五张卡五张脸」将月纱变成两人，反而违背人物设定。

## 封面到底怎么重制

- **不是简单给三位旧封面女性「换脸」**。先选择品牌封面的真实内容：*月纱单主角＋另三位分离镜头*，或 *四位已定义居民的群像*。不得用三个身份不明的漂亮人形代表四个现有可玩角色。
- 若做四人群像，应先由四张审核通过的 G1 身份版保证月纱银发、泉泡银蓝兽耳、青枝浅金绿眼、炽角玫红铸角；四人的脸型、眉眼、鼻、嘴、表情、姿态、服装轮廓都不同，位置层级也不同。武器和野兽只作额外视觉身份，不抢脸。
- **分开画 16:9 PC 与 9:16 手机封面**，别把横图中间裁成竖图；原生像素/源 PNG/哈希/来源权利/美术人审/三种屏幕真测缺一不可。
- `world-cover-mobile.webp` 为 900×1539，需重审高 DPI 采样；横版 `world-cover.webp` 虽有 1920×1080，不能因为尺寸够就判身份合格。当前原图保留作**未通过身份验证的历史宣传候选**，没有更改为 production，也没有在游戏里新绘封面。

## 不应因为全站重做而回退产品

全站应统一夜色、酒红、黑金、黄铜材质、轻量 HUD、动效节奏、导航意义与「画面优先」的原则；**不要**把公寓、工坊、委托、仓库、街区统一成同一大厅背景、相同 CSS 换色。七条正式路由、卡池抽取、六房索引、存档、订单、库存和剧情不改。

本次代码实改文件：`gothic-lobby.tsx` / `gothic-lobby.css`、`world-town.tsx`，两个 E2E `gothic-art-review.spec.ts` / `gothic-desktop-scenes.spec.ts`。**静态不同 Git SHA 并不能证明「不是同一张脸」**，最终身份审核必须有四人物同尺度对照与人工验收签名。CI、Desktop Visual、Gameplay Browser、Pages 按本轮 SHA 单独汇报，不把代码提交等于原画通过。
