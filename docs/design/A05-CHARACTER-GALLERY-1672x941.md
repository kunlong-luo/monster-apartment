## 2. 美术与身份规范

- 场景：暗紫黑哥特长廊、紫色月光、高窗、玫瑰、蜡烛及金属浮雕。绘景为独立图片层，HUD 不能烘焙进背景。
- 五张牌的顺序：月纱·神话月蚀（赤红）、月纱·月下誓约（紫）、泉泡（水蓝）、青枝（青绿）、炽角（铜红）。面孔、年龄感、服饰、姿态和光源都需独立。
- 神话红、传说紫、水蓝、森林绿、赤铜金边属于人物品阶/身份的局部语义色，其他通用 HUD 继续复用 single source of truth 的 --craft-* 主题令牌。
- 参考图右边的数十万攻击/生命、Lv.100 并不是当前角色真实数据。当前角色能力为 20 项、每项 1–100，必须显示真实属性。技能区目前显示真实专长，不编造技能等级。
- 本轮仓库已存在一张月蚀候选绘景 cg-eclipse-candidate.webp；其他四张主要仍是肖像/脸图，尚不能算参考图中的正式全身 CG。
- 现有 workshop-gothic-hall.webp 是过渡背景，不等于正式专属 A05 场景。不得声称首轮已达到美术像素 1:1。
- 语音档案目前没有已验收的语音资源，只能标为待开放且不可点击。
- 禁用 Sparkles/WandSparkles 图标，保持 Impeccable 设计审查流程。

## 3. 独立视觉层

1. Background：独立大场景、远景月光、前景气氛，不影响 UI 点击。
2. TopBar：标题 LOGO、当天数/晶核/星币、真实委托入口。
3. Sidebar：七类设计功能入口；没有能力的项目必须明确不可用。
4. Gallery：五卡 + 锁定/收录状态 + 选择态，优先保持人物比例。
5. CharacterDetails：当选中卡变更时更新人物姓名、简介、能力、装备与房间行动。
6. Dock：复用项目正式唯一七项目的地导航；不新增第八条路由。
