# R12.25 · Web 优先：欢迎页按需加载与 PC 世界地图操作优化（2026-11-24）

> **本轮已提交真实 Web 前端代码、Playwright 定向回归和 Desktop Visual Review 工作流；GitHub Actions、PC 实机截图及 Pages 上线状态必须按最新提交 SHA 分别核实。** 本轮**不是**新封面、四位 G1 正式头像或五张正式 CG 已经制作/应用。承接 [R12.24 美术入库状态](../art-reviews/R12-24-G1-SOURCE-INTAKE-REGRESSION-2026-11-24.md)，本阶段优先改善用户直接进入的 Web 版本。

## 为什么先做这一小轮

- 首页由 `GothicEntry` 在同一个 `/` 路由里展示欢迎封面或大厅。此前它**同步静态导入完整 `GothicLobby`**；大厅又引入经营状态、抽卡、特效及多张图。这会把欢迎页与游戏大厅耦合进同一入口，首屏有不必要的模块依赖。尚未取得真实 Lighthouse / JavaScript 字节统计，因此不声称已获得具体加载速度百分比。
- 首页右上角 R12.15 世界地图已经替代大型底部导航，但此前弹层需要点外部或按 Esc 才能关闭，缺少**可见且满足触控尺寸**的关闭按钮。PC 用户的操作可发现性和键盘焦点体验仍可更好。
- 用户明确要求 **Web / PC 优先**。本轮不再以美术 ZIP 研究稿代替玩家可见的改进；同时不在缺少 G1 人审时把新写实脸接入现有二次元游戏头像。

## 版本可见性修复

本轮进一步发现 Web 界面的 `GAME_UI_RELEASE` 与静态 `public/release.json` 长期停留在 `V3.90.0`，新提交即使 Pages 发布成功也难以让玩家识别。现在**同步提升至 `V3.91.0`**，欢迎页与大厅原本已有的版本标识会展示它；旧标签页检查到 `release.json` 较新时，原有 `GameReleaseNotice` 会提供由玩家自行选择的「更新画面」操作，避免自动刷新影响存档。现有 `tests/game-release-version.vitest.test.ts` 已有发布清单与 UI 版本一致性断言，本轮没有重复造一个版本系统。

**注意：** 最初 `007cd77` Web 改动已经通过 Quality 且 Pages 部署成功；`V3.91.0` 标识属于后续提交，必须**另按更新后的最新 SHA** 复核 Quality 和 Pages，不能拿早一条流水线替代此版本的发布证据。
