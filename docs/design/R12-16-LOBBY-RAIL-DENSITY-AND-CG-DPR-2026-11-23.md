# R12.16 · 首页场景边栏收敛与图鉴候选画原生像素保护

> 2026-11-23；继续 [R12.15 顶角世界地图](R12-15-LOBBY-CORNER-WORLD-ATLAS-2026-11-23.md)。本轮是**真实布局细化和角色画质防回归**，不是新 CG 绘制、场景正式晋级或游戏机制改造。质量结论必须与本轮最新 Git SHA 的 CI 记录对应。

## 最新审计证据

1. `bf750bea` 的 Quality 和 Pages 成功，**Desktop Visual Review 失败**：`e2e/a05-character-gallery-layout.spec.ts` 在 1648×928 像素采样时看到候选画幅约 **552.11 CSS px**，门槛为 546px，超过约 6.11px。该问题与顶角导航不同，它是实际的过度放大，不应修改测试宽容值。浏览器全量测试当时仍在进行。
2. 代码根因：`character-gallery-artwork.tsx` 的 Motion 入场设有 `scale:1.025`（候选原画）；即使 `artworkPixelBudget()` 先正确把原生图片限制为 DPR2 宽度，动画仍会临时放大至 102.5%，破坏原生像素预算。
3. PC 首页右侧三个大图牌中，**工坊、月光街**为两个真实地点，**剧情回顾**只是打开原来就有的故事弹窗。旧实现仍然为这第三项加载同一月纱 Bust 并占用至少 **96px 高的绘景卡**，而左边角色列表和月纱主绘景已展示人物，视觉信息重复。

## 改动

| 区域 | 本轮改动 | 保留的不变量 |
