# R12.3 · 首页人物完整展示与小型菜单

依据 2026-11-21 Desktop Visual Review 的**真实** 390×844 首页截图，而不是概念绘图：手机顶部右下的「初次契约」大卡占据约 120px 高、遮住月纱的头发和眼睛；底部四项导航几乎填满整个屏幕宽度，像后台固定按钮栏。PC 1440×900 图中独立召唤推荐与右侧绘景已获批准，不应因移动修复而改版。

## 范围与视觉原则

- **只在 ≤600px 的手机首屏**压缩原「初次契约 / 神话 · 月蚀」卡，保留同一个真实 `/characters/#summon-screen` Link、契约主题、称号和真实召唤券数量摘要。它由原来单独铺开的肖像缩略拼贴改为紧凑邀请，不额外加一个重复入口，也不改概率和契约收藏状态。
- 手机契约卡控制在约 65–70 CSS 像素，减少对人物脸部的遮挡；卡内仍保留可聚焦且尺寸大于 44px 的点击目标。人物绘景继续使用真实原图、无滤色或 CSS 放大。
- 首页唯一的常驻导航仍保留四项手机快捷路径，并继续通过「全部地点」访问七个正式场景；只将屏幕贴边栏改成居中的小型暗金浮岛，保证每项点击面积不低于 44px。PC 只轻微收窄底栏到 670px、保留原本的功能和展示结构。
- 使用既有 `--craft-*` 材质色板，禁止添加新的 Sparkles 图标或通用 SaaS 玻璃卡。没有改变其他六个页面的导航结构。

## 验收门禁

真实 Chromium 390×844 与 1440×900 截图：

1. 手机推荐卡高 44–76px 且底边不超过纵坐标 328px，人物眼睛下方不再被 120px 推介卡覆盖；主线、契约和召唤入口依然可见、可点击。
2. 手机浮动 Dock 宽不超过 358px，四个快捷链接和七地点弹出入口不丢失，无页面横向滚动。
3. 点击契约卡仍真实进入人物抽卡舞台；桌面参考画面中的独立大卡高度 ≥200px，Dock 宽度保持 550–670px。
4. `visual-evidence/lobby/mobile-art-clearance-390.png` 与 `desktop-art-clearance-1440.png` 需在真实 GitHub Desktop Visual Review 中产生。CI 测试通过不是人工美术签审，但可以防止再次退回厚重固定条。

## 独立高清美术仍未完成

本轮仅修复现有已认可首页原画被操作区遮挡的问题。S02 / S05 / S06 的**独立原生高清**环境、角色与互动热点一致性、9:16 专用手机背景及版权来源仍按 #16 / #24 单独验收。不得将该 UI 收敛声称为正式美术资源交付。
