# R12.63 · 工坊三种工序的独立动效

依赖 R12.62 场景候选 `66525ce0a88f0a39b0ab1e7717d5df608c64d4e5`，在独立后续分支开发，不修改当前 PR #56/#57 的运行 SHA。当前正式版仍 V3.103.0；PR #56 修复后的 Quality 45368652906 与图片取证 45368652701 已通过，定向玩家房间浏览器尚未确认。

现有 PC 全景的三设备使用同一类呼吸光晕，工序区分不足。本轮复用 Motion：月井用短水汽光线向上，苗床用缓慢漂移叶片，熔炉用短促晶核/火星上升。每个当前展示工位最多三个纯装饰粒子（全景最多九个），仅当真实 featured 工位的 signal 为 working 且其生产预测 amount > 0 时存在，闲置、未建造、受阻不显示；它们表示可生产的工序状态，不是后台实际结算或运输模拟。系统或游戏减少动效设置切换时保留静态提示，不启动循环。组件无计时器、随机数、Canvas/纹理分配及写入存档，pointer-events:none 并限制在设备层，不影响真实点击。原结算反馈、设备状态、原画与 Pixi 棋盘保持不变。没有正式工作帧、骨骼动画或人工签审，不将现有武器立绘冒充工匠工作动作。

扩展既有真实 Playwright 用例：仅月井可生产时不显示另两工序；三设备均有真实产量时各有三粒子、显示工序状态且不抢输入，游戏减少动效生效，存档字符串不变。后续需同基础分支正式合并后重新同步、按真实 CI 和截图验收，当前不声称上线。
