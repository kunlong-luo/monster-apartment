# V3.26 · 从设计稿到其他场景

以 2026-10-29 的两张原始设计稿为准，延用暗红、黑金、烛光边线、月蚀角色主题。

## 已实现范围

- 七个页面仍只有一套全局导航。大厅使用影院式宽 dock；公寓、工坊、月光街四大分页面统一黑金 dock 和红色当前页高亮。
- 公寓保留真实的六扇房门与住客经营操作，左门牌与右侧房间操作面板使用统一边框，绝不把截图底图当点击热区。
- 工坊保留 PixiJS 场景、手机派工标签和常驻开始轮班按钮。只改动 React 控制面板视觉材质，不改变生产、经济或存档。
- 月光街/委托/仓库/人物图鉴继续使用现有真实场景与数据。此阶段不再增加重复的“回大厅”“所有功能”入口。
- 游戏中装饰性文案与原始设计稿的演示数据分开：资源与交期只来自存档，红色“神话·月蚀”仍按当前真实 1% 概率，不伪造活动期限。

## 待生产

- 原始设计稿中精美的人物需拆成独立高清背景、人物透明图层和 UI 小件。未审核的 CG 候选不得假装已是透明游戏 sprite。
- 要用浏览器在 1440px/390px/320px 分辨率检查视觉遮挡、当前页指示、六房门操作和工坊派工。

## 统一世界材质的补充

旧月光街、角色肖像卡、委托和仓库中的蓝灰色占位面板改成酒红黑金；扩大桌面经营页的信息宽度，手机委托/仓库以数据面板优先，其余仍保留全屏场景透出。新增 390px 公寓/委托/工坊和 320px 月光街自动化测试，校验唯一七路由 dock 与真实经济数据。
