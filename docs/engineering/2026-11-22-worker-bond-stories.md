# 人物与经营联动：工坊牵绊支线（2026-11-22）

> 目标：让生产经营的真实进度在人物房间得到叙事回报，补足“经营与角色故事没有联系”的体验缺口。属于本轮可玩小切片，不等于正式角色 CG 已交付。

## 玩家体验

玩家在现有 `/workshop/` 实际交付第一单委托后，到 `/characters/` 拜访泉泡、青枝、炽角的私人房间。完成该人物的首次对话抉择并调查指定的两件关联物件，可永久收录**第一幕**。真实完成第三单、查清该房间第三件物件后，可收录**第二幕**。不同角色有不同的故事和不同的首次选择回应，展示她们与月光街旧水脉、花期、工坊安全工程及月纱旧契约有关的线索。

使用房间已有的右侧交谈栏，不创建第八条页面或额外全屏剧情菜单。叙事不会虚构委托成绩、奖品或设备产量；工匠上班时可阅读已留在房内的信笺，但首次对话仍需要工匠休息（既有规则）。

## 单一真值与存档约束

- 委托完成次数仅从 `monster-apartment:workshop-v2-lab` 的**已校验当前存档**读取。读取错误或缺失不解锁，且绝不为了剧情写入工坊存档；无跨存档资金交易。
- 剧情永久进度仅写到 `monster-apartment:character-life:v1` 的**可选** `workerChapters` 映射（每位工匠只能为 1 或 2）；以前没有这个字段的原存档照常读取，无需迁移。
- `workerStoryProgress` 和 `recordWorkerStoryChapter` 是领域纯函数；第二幕必须先收录第一幕，前后条件不能越级，重复操作幂等。
- 第一幕需要对象列表的前两项（与既有调查记忆一致）；第二幕需要三项。已有首次 `workerDecisions` 不变，阅读不反复奖励。
- 角色图鉴“月光记忆”区域只增加 `工坊牵绊 x/6 幕` 只读进度，避免新增按钮、另起游戏货币或改动召唤概率。

## 定向验收

`tests/worker-story-chapters.vitest.test.ts` 覆盖 0 单、未对话、缺线索、首单解锁、3 单解锁、重复收录、人物独立、旧存档兼容和篡改字段拒绝。前端入口与跨页实测使用对应 SHA 的 Quality / Desktop Visual Review / Gameplay Browser Review 记录分别判断；提交并不等于上线。

## 留待后续

人物剧情与新生成的高清 CG、角色装备对工坊产能的实际增益、真人玩家可理解性均未完成。后续联动增益应保持跨存档原子性，不允许从前端提示文案直接增加数值。
