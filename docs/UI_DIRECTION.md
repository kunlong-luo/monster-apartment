# V0.3.0 UI 方向：Midnight Cozy

## 设计原则
公寓是主角，面板只是玩家的工具。整款游戏像一栋住着古怪却可爱房客的夜间公寓，而不是后台数据管理系统。

## 核心视觉
- 世界：深夜紫、星空、月亮、斜屋顶、暖色室内窗光
- 游戏界面：奶油色文字，暖金色主按钮，薄荷色收益与选中状态，粉红表示负面影响
- 房间：墙壁、地板、窗框、壁画、柜子、地毯、吊灯；空房与住户房亮度不同
- 怪物：由 Phaser Graphics 形状绘制。史莱姆＝薄荷水滴状椭圆；火精灵＝橙金火焰；幽灵＝紫色漂浮形；石像鬼＝石块方形
- 信息：左栏资金/选房/招募，中间公寓和引导，右栏组合收益/结算/夜间日志

## 技术与性能
- 保持 Next.js 16 和 Phaser 4，纯 Graphics，无第三方贴图、远程字体与新的运行依赖。
- Phaser 每次数据更新重画最多六间房；未来房间规模增大再采用对象复用。
- Canvas 显示使用百分比宽度并保持 628×676 原始比例；所有房间点击行为仍通过原有事件总线。
- 保留系统键盘焦点、标签与手机端无横向溢出，CSS 尊重 prefers-reduced-motion。

## 视觉验收（必须人工看图）
1. 打开 CI 的 v030-ui-review Artifacts，检查 desktop/mobile 实拍截图。自动截图不是审美评审。
2. 1440×900 时，中间公寓明显更大，侧栏没有截断招募操作和数值。
3. 390×844 时，公寓位于操作列表前，画布没有横向溢出；按钮和文字可读。
4. 玩家能分辨四种怪物，并知道选中房、搬家源、可移动目标。
5. 公寓内高亮、按钮状态、收益颜色不会只依赖颜色传达意义。
6. 旧版 Playwright 流程与本地自动存档和中英文切换全部通过。
7. V0.2.2 PR #2 已合并；V0.3.0 PR #3 目标是 main。合并后应复核 Pages 部署与公开页面。
