# V3.4 产品定位与游戏玩法需求

> Status: Planned。所列新功能尚未全部上线。关联： [自动生产 PRD](02-AUTO-PRODUCTION-PRD.md) · [剧情](05-MAIN-STORY-SCRIPT.md)。

## 1. 游戏承诺与目标玩家

**类型：** 剧情对话驱动、精美回忆 CG 收藏、自动化工坊与公寓经营、哥特奇幻悬疑叙事。

**体验优先级：** 人物与故事（留下来）→ 收藏与回忆（长期期待）→ 自动经营的决策（有真正可玩的事情）→ 章节高潮特效（难忘演出）。不是把所有资源投入持续播放的全屏特效。

**一句话体验：** 继承旧公寓与魔法工坊，让泉泡、青枝、炽角自主工作；你通过布局、订单策略、居民合作与探索，让月光街的灯一盏盏重新亮起。

**设计支柱：**
- **自主世界**：工匠在玩家观望、切页或短暂离开时仍按规则工作；动画不是假进度。
- **有代价的决策**：设备位置、原料路径、库存预留、角色关系与公共建设互相争夺有限资源。
- **被记住的人物**：NPC 有固定性格、利益、主动反应和成长；不靠送礼刷爱心。
- **可居住的环境**：公寓休息、街道照明、植物变化、钟楼与天气把经营结果可视化。
- **公平且可恢复**：无付费加速、无强制在线、离线有上限且不会因睡觉被违约罚破产。

## 2. 核心循环（不再「点一次生产一天」）

1. 观测工坊真实状态与缺料原因。
2. **低频设定**：配置机器位置/配方、工匠岗位、订单预留优先级，之后自动执行。
3. 生产按各设备周期持续流动：水汽 → 孢子 → 晶核；仓库增减真实可追踪。
4. 订单按策略自动交付；玩家可选择扩张、公共建设、贸易或拒绝高风险委托。
5. 经营事件解锁剧情，改变街区照明、居民生活、角色关系与新配方。
6. 回到第 1 步；主线结局后继续自由经营。

**时间尺度提案（待实测调优）：**
- 30–90 秒：观察生产脉冲、物料流向、故障恢复。
- 3–10 分钟：做一次设备布局/配方/合约决策。
- 15–20 分钟：完成序章和第一章垂直切片。
- 多次游玩：解锁主线、人物支线与重建路线。

## 3. 七个正式页面的唯一职责

| 路由 | 核心任务 | 不应增加的无效操作 |
|---|---|---|
| `/` 大厅 | 场景导航、主线入口、可选对话、重大抉择 | 直接发放无来源奖励的日常签到 |
| `/apartment/` 公寓 | 房间/灵核入住、生活质量、居民事件、庇护与能力 | 把住客心情做成反复点爱心 |
| `/workshop/` 工坊 | 建造、派工、排程、自动生产、故障提示、供需流动 | 必须手动按班次按钮领取生产 |
| `/town/` 月光街 | 街区项目、贸易、调查、公共照明变化 | 只显示没有策略的 NPC 菜单 |
| `/orders/` 委托大厅 | 订单队列、自动履约与预留、高风险选择 | 每批材料手工领取/交付 |
| `/characters/` 图鉴 | 人物小传、专长、岗位、关系剧情、能力变化 | 静态低清立绘 + 无意义升级 |
| `/warehouse/` 仓库 | 全链路库存、容量、预留策略、补货与流量诊断 | 拆分同一资源为多个无法对账余额 |

**统一信息架构：** 七页共享剧情章节/任务追踪，工坊和仓库共享生产快照；所有入口小而清楚，舞台始终是视觉中心，不加大面积管理后台表格覆盖游戏场景。

## 4. 必须成立的系统关系

- 工坊消耗产能和资金才能生产晶核；订单、公共照明、月纱合同竞争同一批晶核。
- 街区居民向工坊提出真实订单/采购请求；支持拒绝并有明确代价。
- 公寓提供角色安置与氛围、能力等非货币加成；**不允许从另一条存档悄悄铸造工坊星币**。
- 角色职业成长以真实产量、帮助街区、解锁支线为依据，重复无风险点击不涨技能。
- 主线必需材料可用确定性玩法获得；不能要求特定稀有度召唤或抽卡。
- 结局由经济/生态/公共服务三种长期证据加关键剧情选择决定，不存在只能花钱解锁的“真结局”。

## 5. 经营路线与冲突

| 路线 | 玩家优势 | 成本与风险 | 世界反馈 |
|---|---|---|---|
| 商业优先 | 订单报酬、扩建设备速度较快 | 需配置污染/耗材管理与公共预留 | 商街繁荣、旧居民区可能缺能 |
| 生态优先 | 稳定生产、生态材料和环境恢复 | 扩张慢、前期利润较低 | 月光花生长、青枝/菲娅认可 |
| 平衡发展 | 商业与公共服务均衡，可逐步实现理想结局 | 布局/订单优先级更复杂 | 灯火与生态同步恢复 |

路线不是初期永久选边；中途可以改策略，但已发生的剧情事件和资源支出不可撤回。

## 6. 20 分钟最小完整垂直切片（P0/P1）

**可交付的玩家故事：** 接过钥匙 → 唤醒泉泡/青枝/炽角 → 指派岗位 → 水汽泵自动生产 → 与温室/熔炉连接 → 订单自动结算 → 阿洛报告东街熄灯 → 玩家设定公共库存预留 → 第一盏街灯亮起。

**成功判据：**
- 玩家无需教学说明也能发现缺料/断链原因；
- 连续观察 3 分钟无需点击“开始一天生产”，库存仍正确变化；
- 切换七页或重开浏览器不丢产能、不发生重复发货；
- 玩家能说清下一步是为钱还是为街灯积攒晶核；
- 剧情演出真实反映生产结果，支持跳过已看对话；
- 手机 320/390px 不重叠遮挡操作，大厅主视觉保持清晰。

## 7. 不进入当前范围的功能

多人联机、实时服务器市场、付费加速、每日强制签到、无限抽卡叠属性、自动广告收益、地图无限扩张、完整战斗系统、跨平台云存档。先保证单机本地优先的经营和故事成立。

## 8. 关键平衡原则

- 玩家的瓶颈应是**有限资源如何分配**，而不是重复劳动或无意义等待。
- 首次接触时不强制复杂最优配方；第一单可以稳定完成。
- 关键订单必须给出预计可完成时间、所需资源、保留量、违约影响；特别委托需主动确认。
- 失误可通过搬迁、升级、回收和贸易恢复；禁止硬性软锁。
- 美术和动画验收分开：能播放、看得清、符合角色 IP、对应真实状态才算完成。

## 9. V3.1 叙事 + 收藏的玩法闭环（新增）

- 角色不是静态属性卡：玩家通过真实生产、街区建设与公寓生活满足对话触发条件，认识人物并理解其矛盾。
- 对话只有少量真正影响路线、关系或库存政策的选择，保持节奏和选项后果透明；普通剧情可跳过已看并回顾。
- 每完成一个有意义的章节或人物转折，解锁永久回忆 CG；需要先审核角色一致性，不能把 AI 候选图当正式美术。
- 所有 CG 与生产/剧情事件绑定；已看回忆与隐藏彩蛋可重放但不再发钱/物资。
- 主线伏笔必须有开头埋设、中期重复提示、后期明确回收；彩蛋必须可重访且不影响主线可达性。见 [10 伏笔和彩蛋](10-FORESHADOWING-AND-EASTER-EGGS.md)。
- 首个垂直切片：**自动产晶核 → 首单/东街灯亮 → 与月纱对话 → 解锁 CG → 玩家自愿发现屋顶明信片**；技术/艺术范围见 [11 纵切片](11-VERTICAL-SLICE-AND-CONTENT-PIPELINE.md)。

## 10. V3.2 概率招募与故事角色的界限

- 允许通过**免费游戏内契约券**抽取 N/R/SR/SSR/UR 不同品质的原创**可入住角色**，但不抽主线必需 NPC；抽卡不是推动自动经营的手工重复生产按钮。
- **三种不同收藏**：人物招募卡（随机发现）/ 人物档案和职业羁绊（真实互动）/ 剧情 CG（确定性任务和隐藏彩蛋）。不得把「没有抽到 UR」作为看结局或收集主线 CG 的阻碍。
- 保底、重复转碎片、概率明示、保留旧 `cozy:v1` 住客、公开免费来源均需在实装前完成；高品质不意味着高倍率生产碾压。
- 保持七页：图鉴增加召唤和角色卡分页，公寓展示已拥有住客；**不新增第八个抽卡首页**。详情见 [12 抽卡 PRD](12-GACHA-RECRUITMENT-PRD.md)、[13 角色卡池](13-CARD-ROSTER-AND-ART-DIRECTION.md)。
- 首次体验必须先让玩家体验自动生产与角色故事，再送免费十连奖励；避免第一屏就出现大型抽卡按钮，掩盖原本的游戏特色。

## 11. V3.2 人物专属房间：让收藏变成一段可拜访的生活

- **每位人物都有一个可进入、可观察、可对话的独立空间和一张高品质房间绘景。** 抽卡只是认识角色的起点，玩家可以进入她/他的房间，看人物写信、整理工具、休息，与其交谈或发现有意义的秘密道具。
- 招募人物按 `characterId` 自动解锁个人私室，主线 NPC 随故事认识开放可拜访的客室/工作室。由于部分 NPC 本身住在钟楼和月光街，「专属房间」不等于声称所有人都租住公寓。
- **不扩张旧经营房来刷收入**：现有六个经营房间保持盈利与旧存档，新增人物私室仅提供独立展示/对话/线索/CG，不附加无条件房租。
- 角色房间不仅精美，还要随羁绊和剧情变化：花生长、桌上出现信件、月纹注释渐显、钟表重新报时；不设计十次点击送礼玩法。
- **UR「神话·月蚀」的主色正式改为绯红**，SSR 金、SR 紫、R 蓝、N 暖灰。卡背、召唤、角色品质标签、房间门牌统一，可访问性不能只靠色彩。
- 文件：[14 私室需求](14-CHARACTER-PRIVATE-ROOMS-PRD.md) · [15 人物房间原画分镜](15-CHARACTER-ROOM-BIBLE.md) · [16 品阶视觉](16-RARITY-VISUAL-TOKENS.md)。

## 12. V3.3 六维培养与真实锻造的长期经营循环

在「召唤角色 → 拜访私室 → 触发人物故事 → 获得人物 CG」之外，加入可持续的**角色养成与工坊锻造**：查看人物六维 → 选择职业/训练计划 → 工坊自动生产锻造材料 → 设定一份首饰或器具工单 → 角色穿戴，变化反映在真实岗位、房间饰品展示或可选剧情对白。

- 人物品质决定成长潜力，装备品质独立于人物品质；**UR 红色**只是稀有美术标识的一部分，不能把高稀有角色+装备做成指数倍速引擎。
- 角色六维是**体魄、智慧、力量、精神、血气、速度**，分别影响疲劳、判断、锻造、魔力、恢复、物流；目前未设计战斗，不添加空洞攻击面板。
- 装备来自**同一本工坊真实资源账本**，不能抢走已锁定公共照明晶核，也不能新增游离的第二物料货币。
- 装备/训练由计划与自动时钟推进，主要操作为选择配置与观察结果，不能退化为连续点锻造/点击加经验。
- 主线必须由已有确定获得的角色完成，任何装备/UR 都不成为第五章或三结局的强制门槛。

开发与数值规范：[17 六维属性](17-CHARACTER-ATTRIBUTES-AND-POTENTIAL.md) · [18 装备锻造](18-EQUIPMENT-FORGING-PRD.md) · [19 装备配方](19-EQUIPMENT-RECIPES-AND-ART.md)。

## 13. V3.4 人物像「真实的独立个体」而非装备容器

以前的六项属性仅是身体/认知/灵能能力的一部分。人物新体系覆盖**身份外貌、20 项基础能力、性格人格、动态心情与生理需求、双向人际关系、兴趣和生活习惯、职业技能、过去/目标/秘密**。每个人都有适合的房间、对话、偏好与缺点。玩家更换一枚戒指可以提高能力，**不能一键修改对方价值观或信任程度**。稀有度影响未来成长潜力，并不将 N/R 人物写成「没有人格的废卡」。

人物默认卡面只展示**最具代表性的 3–5 项强项 + 性格概述 + 当前心情**，完整档案在子页展示，不把 20 根进度条铺满屏幕。先验证性格和行为能在月纱/泉泡/青枝/炽角的私人房间和经营选择中被玩家感受到，再逐步增加复杂数值。规范见 [20 完整人物](20-HOLISTIC-PERSON-SYSTEM.md)、[21 人物生活档案](21-CHARACTER-LIVING-PROFILES.md)。
