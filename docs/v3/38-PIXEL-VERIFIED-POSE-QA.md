# V3.16 · 透明立绘真实像素门禁

上轮出现了有真正透明通道、却由四个人物连在同一张画布组成的候选图。四等分会切掉大量发丝、袖口和腿部。仅检查 WebP Alpha 标记或哈希无法发现这种问题。

现在 `pnpm art:poses`、`pnpm art:promote-poses` 都通过已安装的 Playwright Chromium 解码每一帧 WebP，自动采样 128×128 的真实透明通道，并检查：

- 透明像素至少 5%，可见不透明人物至少 8%，四角透明。
- 求出可见轮廓的最小外接矩形：左或右侧如果有超过 24% 的边缘被像素占据，或头顶超过 40%，视为明显直线裁切（可能发丝、身体被截断）。
- 预审报告 `pixelReport` 随四帧 SHA-256 保存，但不代替真正美术审核；单靠透明背景不能排除细小缺损、身体结构错误或假动画。
- 浏览器审核面板使用同样的轮廓检测，无法通过的本地图不能进入预览层。
- `portrait-provenance.json` 生产审核必须保存每帧像素预审通过状态。

如果本机还没有 Playwright 浏览器，先执行 `pnpm exec playwright install chromium`。默认不从网络获取美术资源，也不把图片上传第三方。

本轮的四张裁切测试图因为左右边缘截断，被明确标记为 REJECTED，不得复制到 `public/art/rooms/*/poses/`。
