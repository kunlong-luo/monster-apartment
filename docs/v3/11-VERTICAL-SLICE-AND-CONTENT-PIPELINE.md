# V3.1 首个 15–20 分钟可玩纵切片与内容生产流程

> **状态：Planned。** 本文把「自动经营 + 月纱剧情对话 + 正式 CG 收藏 + 第一个隐藏彩蛋」串成真实体验，不靠概念图演示代替实现。依赖 [自动生产 PRD](02-AUTO-PRODUCTION-PRD.md)、[对话 UX](08-NARRATIVE-DIALOGUE-UX.md)、[CG 规范](09-CG-COLLECTION-AND-ART.md) 与 [伏笔和彩蛋](10-FORESHADOWING-AND-EASTER-EGGS.md)。

## 1. 玩家第一局流程（具体触发与演出）

| 阶段 | 目标时长（待玩家测试） | 玩家做什么 | 世界自己做什么 | 叙事/收藏回报 |
|---|---:|---|---|---|
| A. 继承旧公寓 | 1–2 分钟 | 观看/跳过钥匙剧情，选择调查或经营 | 不强制计时 | P00，CG-M-001；非整点钟响 F-01 |
| B. 唤醒工坊 | 2–3 分钟 | 给泉泡派工一次、观察设备 | 水泵自动运行并真实产出 | P01，CG-M-002 |
| C. 接通工坊链 | 3–5 分钟 | 调整三设备相邻关系与岗位 | 自动消耗水汽和孢子、形成晶核 | C01，CG-M-003 |
| D. 第一张订单 | 2–3 分钟 | 查看订单策略（正常默认自动交付） | 达标自动交付且到账一次 | C03，月纱首次提示，CG-M-005 待其对话后解锁 |
| E. 重燃东街 | 3–5 分钟 | 设置公共储备优先级、确认建设 | 晶核被真实预留并自动送往街灯 | C02，CG-M-004，街道亮灯 |
| F. 惊喜回访 | 1–2 分钟 | 返回公寓，发现屋顶信使鸟和明信片 | 生产持续，游戏不会因回忆停机 | E-06，CG-S-006 隐藏回忆 |

**顺序弹性**：第一单与东街工程可根据真实库存和玩家选择交错完成；播放器不应强行要求玩家按 A→F 线性点击。月纱会在首单后出现，但不是首单必须立刻点开的强制对话。若 15–20 分钟目标超时，应优先压缩等待/生产周期、教程文本或任务链，而不是提供付费加速。

## 2. 演出脚本最小产能

**首次可见**：主角收到钥匙（静态/轻视差）、泉泡独立精灵在泵旁工作、流动资源（对应真实产量）、街灯逐个亮起、月纱来访沉浸式对话、屋顶信使鸟隐藏卡片。六个情感点至少要有六种不同的视觉/听觉节奏，不是统一黑屏 + 粒子。

**收藏第一批 6 张**：CG-M-001 夜色钥匙、002 第一滴月露、003 三人工坊、004 东街第一盏灯、005 月夜来客、CG-S-006 屋顶秘密信使。每张都必须经过 [美术质量门禁](09-CG-COLLECTION-AND-ART.md)；精美参考图和现有 498px 回退精灵不等于 6 张正式 CG。

**对话第一批**：P00、P01、C01、C02、C03、C04；每幕有完整可跳过的文字、表情和地点；至少两处不同结果的选择。重复观看只读，不产生生产或订单奖励。

**伏笔第一批**：F-01 序章非整点钟响（视听提示，字幕可读）；F-02 钥匙月纹与月纱合同印章（不提前解释）；E-06 明信片作为玩家第一张可探索隐藏收藏。其余伏笔后续章节逐渐回收。

## 3. 端到端内容制作流水线

1. **内容登记**：所有 sceneId、lineId、choiceId、eventId、collectionId、foreshadowId 进统一 manifest；前置事件和揭示阶段可审查。
2. **文本**：编剧按场景脚本写对白/镜头；人物圣经审稿；测试所有分支有出口且选择后果真实。
3. **分镜**：针对收藏和高潮给出场景背景、镜头景别、角色站位、道具线索位置、移动安全区域与色彩指引。
4. **角色/CG 资产**：先建立统一人物身份参考，再生成/绘制候选，人工校对服饰、五官、比例、物体位置和伏笔连续性；审核通过后导出 WebP/AVIF。
5. **代码绑定**：剧情数据只绑定权威领域事件；Pixi/React 展示统一 `StoryScene` 和 `CollectibleRecord`，不要把奖励写进动画回调。
6. **质量回归**：状态机单测、多标签/离线安全、七页跨场景 E2E、窄屏截图、收藏图放大、关闭音画体验。
7. **玩家试测**：找几位习惯经营/叙事游戏的玩家，观察无需额外解释是否会自然进入第一章和发现一个彩蛋；记录真实行为而非只问喜不喜欢。
8. **按反馈修订**：若玩家一直等设备产出不明白做什么，优先调整预估和清晰反馈；若看过月纱对话却无兴趣，优先修编剧和角色演出，不以追加大特效掩盖节奏问题。

## 4. 建议源码职责（不新建第八个页面）

```text

v2/src/workshop-model.ts          设备和库存定义
src/lib/moonwork/                存储与 UI 订阅桥接
src/lib/story/                   （待建）StoryScene、Quest、WorldProgress、Collection 规则
src/components/moonwork/         （待加）场景内剧情呈现和收藏画廊
public/...                       （待建）已审核 CG、头像、缩略图、CG manifest
docs/v3/                         V3.1 需求和脚本（本目录）
```

**关键限制**：`story` 不应另建独立经济存档；七页共用剧情进度。生产、库存、订单结算从单一权威模拟器输出不可变事件，剧情解锁与 CG 解锁是其只读衍生。既有两个旧存档键保留兼容。

## 5. 逐项验收测试（发布前必须全过）

- [ ] 开始游戏后工匠按真实时间自动生产，1 分钟内有可理解的产能反馈；不再点击「开始一天生产」。
- [ ] 原料不凭空传送；缺水、缺孢子、满仓、停工均正确显示，不因动画异常改金币。
- [ ] 从工坊切大厅、公寓、街区、图鉴时生产继续；返回不重建/重置真实生产时钟。
- [ ] 第一单与东街项目库存互斥、预留可见、每一份晶核只能交付一次。
- [ ] 首次月纱剧情可跳过已看，重要选择不能被自动跳过。
- [ ] 六张首批 CG 解锁与对应事件一致，重看/重复点击/重新加载不重复领收藏或其他奖励。
- [ ] F-01 与 F-02 视觉/字幕有正确埋设，前期 CG 不泄漏第三章真相。
- [ ] E-06 在东街点灯后稳定可发现，后期重访仍可找到，不要求现实时间或随机概率。
- [ ] 手机 320/390px 对话与 CG 不卡/不遮选项；桌面全屏图片清晰，不因返回大厅变模糊。
- [ ] 现有 V2/公寓旧档迁移不损失资金、设备、工匠、住客；多标签并发不重复结算；CI/E2E 通过。
- [ ] 剧情文字和美术对照人物圣经与伏笔表校对；关键画面通过**人工**截图检查。
- [ ] 即使资源加载失败/减少动效/无音频，仍能完成经营和剧情，不出现空白不可操作界面。

## 6. 不做的事

不做额外签到、装饰性的大批按钮、无限投喂抽卡、按“点击总数”解锁 CG、必须现实半夜触发的彩蛋、玩家离线受到无上限罚款、没有人工审核的随机运行时 AI 生图、不经过测试就声称所有剧情/动画已经上线。

## 7. 第一批工作顺序

1. 验证自动生产+旧档迁移的 P0 规则；
2. 设计故事/收藏的统一数据模型与可重播事件；
3. 生成6张候选分镜，人工审稿正式 CG；
4. 接入 P00/P01/C01/C02/C03/C04 剧情对话与 CG 收集；
5. 在公寓添加 E-06 可发现热点和隐藏 CG；
6. 检查端到端流程与移动端观感，之后再开发第二至五章。

**完成定义：** 玩家完成真实订单、主动发现角色故事、看见东街灯重新亮起，并把一张有意义的精美 CG 收藏进图鉴，知道还可以回来寻找隐藏故事。只完成「按钮可点击」「概念图好看」不算纵切片完成。
