# V3.22 · 真正的一键派工与常驻生产入口

之前“选择空闲工匠”只是选中一个人物，玩家仍要回到 Pixi 场景找设备；手机在“派工”标签里又看不到“开始生产”，必须额外切换到“生产”标签。这让完成一次基础经营循环需要不必要的操作。

本轮在现有按钮位置实现**真正的一键派工**：
- 自动寻找尚未有岗位的工匠；仅投放至空闲、技能匹配的机器（水汽/泉泡、孢子/青枝、熔炉/炽角）。
- 不打乱玩家手动安排的工匠，即使手动选择了不匹配的机器也不替换；不自动建机器、不扣星币、不生成新产出。
- 通过原有 Pixi 运行时派发 `auto-assign`，一次更新单一 WorkshopState，继续沿用 localStorage + Dexie，切换页面不丢失。
- 所有岗位已安排或无技能匹配设备时按钮禁用，不误导玩家为已完成。
- 原有逐人工匠点击设备的精细派工方式继续保留。

把唯一的“开始生产轮班”按钮移到工坊底部控制台的常驻动作行：手机不再需要切换“生产”标签才能推进工坊天数，生产日志标签只用于查看报告；“移动设备”仅在已经选中设备时出现在动作行。
删除列表中虚假的 `Lv.30`，改为工匠真实的技能类别（未实现等级成长前不显示等级）。

回归：Vitest 验证自动派工不替换、不花钱、重复无操作；Playwright 验证 390px 直接派工+生产+刷新，及桌面/320px 布局和原有手动流程。正式像素美术仍需独立制作，此提交不会改造存档结构。
