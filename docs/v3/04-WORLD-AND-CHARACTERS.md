# 《永不熄灭的月光》世界观与人物圣经

> 剧情、台词及新角色为 V3 策划创作稿，未作为游戏正式资产上线。与 [主线剧本](05-MAIN-STORY-SCRIPT.md)、[角色支线](06-CHARACTER-QUESTS.md) 配套。

## 1. 世界结构：月光街 Moonveil Street

**大陆背景：** 人类、拥有灵智的魔物、精灵与机械生命同居的奇幻城市。这里夜晚由一座巨大装置「月心灯」供能，人们在它的照耀下开店、制作、居住和交易。

**月心灯的历史：**
1. 早期依靠地下的「月光水脉」与月光花形成缓慢循环，能量温和但规模有限。
2. 城市人口与商业扩张后，钟表师诺因设计「晶核增幅装置」，短期满足了所有人的需要。
3. 过度抽取水脉使系统失衡，街灯和月光花开始一盏盏、一朵朵失去生命；诺因选择把自己关在钟楼核心区持续维护。
4. 多年前旧工坊拥有可逆转增幅问题的零散技术，但技术记录与住客分离。玩家继承它，成为第一次可能同时修复经济、生态和公共供能的人。

**起始场景：**
- **怪物公寓：** 生活与休息的核心，收容不同灵核住客；房间状况反映社区稳定。
- **月光工坊：** 铜管、水汽泵、玻璃温室、晶核熔炉，15 格真实物料链。
- **月光街：** 商业街、旧居民区、伊索维修点、菲娅花店、街灯和公共建设。
- **旧钟楼：** 阿洛工作地点，存放旧事故档案与月心灯核心区；剧情后期进入。
- **地下月光花园：** 藏于老街地下，是青枝与菲娅的重要研究区域。

**主题冲突：** 不是「资本家是坏人」或「生态不该发展」，而是当城市不得不消耗能源时，谁有权分配资源、谁承担风险、谁被听见。三结局都要有能自圆其说的发展原则。

## 2. 角色关系网与剧情推动

玩家：无预设姓名/性别，角色形象可由玩家配置；拥有继承工坊、公寓与最终经营规则的决定权。玩家不需要被迫对 NPC 做单一评价。

**核心关系：**
- **泉泡 ↔ 青枝：** 水与植物的互相依赖；泉泡愿帮忙，却不懂说“不”。
- **青枝 ↔ 炽角：** 生态/产能冲突最强，彼此尊重对方技术但怕对方牺牲自己的底线。
- **炽角 ↔ 月纱：** 都欣赏高效率，但对是否承担长期成本意见不同。
- **月纱 ↔ 诺因：** 共同参与旧月心灯采购/扩建；月纱知道一些真相并背负愧疚。
- **阿洛 ↔ 诺因：** 曾是钟楼工程合作者，阿洛保留档案也曾因畏惧而沉默。
- **菲娅 ↔ 青枝：** 调查自然水脉异常并发展可持续配方。
- **伊索 ↔ 月纱：** 公共照明与商业订单之间的价值分歧，最终可以相互认可。
- **公寓灵核住客 ↔ 玩家：** 用生活/庇护事件反映居民对世界的感受，不能被强制卷入劳动。

## 3. 主要人物档案

### 月纱 / Yuesha — 28 岁，成年魔女商人

- **视觉识别：** 成年类人魔女，深色礼服、柔金/月紫配色、成熟气质，眉眼机敏。服饰与场景保持统一，台词演出不将人物物化。
- **公开身份：** 经常造访月光街的契约与晶核贸易商人，订单与行情的引路人。
- **性格：** 聪明、优雅、擅长谈判、偶尔俏皮调侃；极少直接表达脆弱。
- **核心欲望：** 证明商业可以帮助城市重生，同时弥补自己参与旧采购计划的过失。
- **恐惧/弱点：** 害怕再做出伤害不相识居民的决定；习惯用合同隐藏真实情绪。
- **秘密：** 曾替诺因采购增幅用晶核，保留部分旧合同与事故记录。
- **外在矛盾：** 高额委托的诱惑与公共晶核储备冲突。
- **成长：** 从只相信交易与利润，到愿意公开旧合同、承担供应代价并帮助紧急抢修。
- **行为：** 接特别委托前明确提醒风险；友好路线也不会无条件送钱。
- **台词音色：** 克制、幽默、留白，句尾常有一丝反问。
- **代表句：** 「我可以给你一个好价格。但有些东西，再多星币也买不到。」
- **主线：** 第二章登场，第三章揭露旧合同，第四章调动商队，第五章与诺因对质。
- **关系触发：** 守约、公开说明资源配置和帮助居民提高信任；隐瞒违约或过度逐利引发质疑但不永久断线。

### 泉泡 / Brook — 水汽工匠，成年灵智魔物

- **视觉：** 蓝色半透明水灵、柔光耳鳍/波纹头冠、随呼吸轻微波动；与另两位轮廓不可混淆。
- **性格：** 热情、活泼、善良、容易紧张，主动照顾他人。
- **目标：** 让居民获得安全稳定的水汽供能。
- **弱点：** 害怕让人失望，过度承担工作，不敢休息或拒绝不合理任务。
- **外在矛盾：** 供给越来越大，管路出现漏水，泉泡以为是自己能力不足。
- **成长：** 学会排班、请别人协助，理解稳定生产不等于永远不休息。
- **能力：** 擅长水汽泵；个人支线解锁漏水诊断/节能机制（必须映射真实生产数据）。
- **语气：** 经常说「咕噜」，句子短，活跃但不幼态性化。
- **代表句：** 「咕噜！今天的水汽很充足……不过，我的扳手好像又不见了。」

### 青枝 / Fern — 温室园艺师，成年灵智魔物

- **视觉：** 层叠叶冠、绿金色植物体、手制围裙与植物纹，动作轻柔。
- **性格：** 温柔、耐心、敏感，有坚定原则，观察力胜于表达力。
- **目标：** 恢复地下月光花园，证明生产与自然可以共存。
- **弱点：** 容易把所有机器看作威胁，不愿承认工业技术也可解决生态问题。
- **冲突：** 与炽角对「加快熔炉」与「停下来调查水脉」争执。
- **成长：** 与炽角联手开发可持续配方；不再只从自己的专业角度看世界。
- **能力：** 擅长孢子温室；支线解锁节水孢子/生态恢复项目。
- **语气：** 语速不快、用观察与比喻说服人，不以尖锐训斥沟通。
- **代表句：** 「植物会告诉我们很多事情。只是大多数人从来没有认真听过。」

### 炽角 / Cinder — 晶核锻造师，成年灵智魔物

- **视觉：** 深炭色外壳、暖橙角冠、护目镜、锻造锤，动作干脆。
- **性格：** 豪爽、倔强、骄傲、嘴硬心软，行动优先。
- **目标：** 打造全城最高效、最可靠的魔法自动化工坊。
- **弱点：** 过度崇拜高产量，低估维护、原料与生态风险。
- **冲突：** 想扩建炉群，与青枝反复争论资源使用。
- **成长：** 研究稳定器和能耗；以可靠性而非最高炉温作为成功标准。
- **能力：** 擅长熔炉；支线解锁低耗锻造或维护效率。
- **语气：** 句短、有力、爱夸口，关键时刻十分可靠。
- **代表句：** 「只要炉火还没熄灭，就没有什么机器是修不好的！」

### 阿洛 / Arlo — 31 岁，成年男性钟楼守护人

- **视觉：** 旧钟楼制服、怀表、工具袋、疲惫却端正的神情。
- **性格：** 严谨、守时、务实、很有责任感；面对旧事故迟迟不敢开口。
- **目标：** 让钟楼重新为城市服务，并勇敢面对前任设计者。
- **弱点：** 遵守规章有时压倒了对人的关心。
- **秘密：** 留下了诺因项目的最后一页维修记录；隐瞒是出于羞愧与担心居民恐慌。
- **成长：** 不再把「守住档案」误认为「保护居民」。
- **主线：** 交钥匙，提供钟楼线索与调度，最终启动钟楼。
- **代表句：** 「钟声不会解决所有问题，但它至少该让每个人知道现在是什么时候。」

### 菲娅 / Fia — 27 岁，成年女性月光花艺师

- **视觉：** 带星光花瓣的园艺服、温柔的手、随身植物手札。
- **性格：** 细心、亲切、具有韧性，必要时非常固执。
- **目标：** 守住最后一批月光花的种子。
- **弱点：** 害怕再失去，所以曾把稀有种子藏起来不愿分享。
- **成长：** 愿意与青枝、炽角共同做开放种植实验。
- **主线：** 第一章报告枯萎，第三章提供水脉证据，第五章支持循环种植。
- **代表句：** 「花不会因为有人盯着它就开得更快，但有人照料，它总会找到机会。」

### 伊索 / Iso — 36 岁，成年男性街区照明匠

- **视觉：** 黄铜提灯、皮质工作围裙、沾煤灰的手套。
- **性格：** 直率、开朗、可靠，反感空话，关心街道角落里的普通居民。
- **目标：** 让商业街以外的人也有安全的夜晚。
- **弱点：** 曾把商人视为只会算账的人，低估贸易帮助的可能。
- **成长：** 学会与月纱合作建立保供协议。
- **主线：** 第一章东街灯熄灭，第二章资源冲突，第四章紧急接线。
- **代表句：** 「灯具没坏，是晶核不够。商业街有备用的，东街却一枚也没有。」

### 诺因 / Noin — 46 岁，成年男性前月心灯设计师

- **视觉：** 苍白发色、深绿长衣、精密怀表与旧式机械手套；沉静，不以夸张恶相代表反派。
- **性格：** 理性、克制、孤独、倔强，对技术与责任近乎苛刻。
- **目标：** 不让城市再经历当年全面断供的黑暗。
- **弱点：** 认为只能由自己决定必要牺牲，低估公众参与和生态系统反馈。
- **历史：** 晶核增幅装置曾救下居民，但长期透支地下水脉；他失误后守在钟楼。
- **冲突：** 他坚持「有限资源只能优先给最需要的人」，玩家证明可以通过协作改造供能方式。
- **成长：** 承认设计有缺陷，提供核心技术与改造机会，不在最终章简单洗白或被草率惩罚。
- **代表句：** 「我不是为了让机器永远运转。我只是见过没有灯的夜晚。」
- **戏剧原则：** 他是可理解的立场对手，而不是邪恶终极 Boss。

## 4. 其他生物与既有角色资产

现有公寓原创灵核住客、收藏/成长机制**不被删除**；公寓住客可出现在生活镜头和支线，但主线通关不绑定稀有抽取。保留已有名字、职业与存档数据，新故事不擅自重命名。

三位工匠应采用非性化小型奇幻生物视觉；人形成年 NPC 服装可有成熟魅力，但不将幼态角色性化，也不以身体展示替代人格和职业设定。

## 5. 对话写作规范

- 一句对白 10–40 个中文字符为主；长信息拆开并辅以场景镜头，适合手机阅读。
- 每个人不使用同一种口吻：月纱有反问，泉泡有拟声词，青枝观察自然，炽角短促直接，阿洛精确，菲娅轻柔坚定，伊索务实，诺因长于逻辑。
- 对白中**先建立困境，再透露信息，最后交给玩家决策**；不连续念三屏设定。
- 角色意见冲突之后要有真正的关系修复和协同场景；无意义争吵不推进剧情。
- 关键玩家选项不预设道德答案，不能把「经营赚钱」一律写成邪恶。
- 每条主要人物成长都要在工坊、街区或公寓出现**可以被观察到的变化**。
- 一次重看剧情不可再次领取剧情奖励，旁白与配音版本必须共用 sceneId/lineId。

## 7. V3.2 可招募住客的人物规则

关键人物（泉泡、青枝、炽角、月纱、阿洛、菲娅、伊索、诺因）的初次相遇与主线职业能力由**故事事件**授予，不能要求抽卡获得。概率招募的对象是原创住客与可选人形访客。每位可招募人物须有完整年龄/非幼态呈现、个性、居住偏好、关系对象、职业边界和可选故事。SSR/UR 的稀有性主要表现在更复杂的艺术与剧情，而不是用数值碾压普通居民。

首批人物及拟议品质、房间能力和与月光街的关系见 [13 首批招募角色与卡面](13-CARD-ROSTER-AND-ART-DIRECTION.md)；完整概率、重复补偿与公开规则见 [12 招募 PRD](12-GACHA-RECRUITMENT-PRD.md)。五个已有 `COZY_RESIDENTS` 的身份与存档不允许因重新设定品阶而丢失。

## 8. V3.2 人物的私人房间和生活表达

每位人物应该拥有**可拜访的独立房间美术和生活活动**，而不仅是图鉴头像、抽卡数值或一段文字。现有 12 位招募住客及 8 位剧情 NPC 均在 [15 人物房间图鉴](15-CHARACTER-ROOM-BIBLE.md) 中有专属空间、家具、道具、动作、对白线索与变化。主人公不会无理由闯入尚未认识的人的私人空间；NPC 拜访需通过人物相识/剧情许可。

UR 神话·月蚀标识统一为**绯红色**，但角色自身身份和个性优先于稀有度颜色，房间仍应真实地像一个有人生活的地方。详见 [16 品阶视觉](16-RARITY-VISUAL-TOKENS.md)。
