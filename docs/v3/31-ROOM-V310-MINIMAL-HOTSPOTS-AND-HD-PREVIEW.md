# V3.10 · 私室高清美术与小型交互热点

## 本轮代码落地

- 四间私室的可点击标记统一缩小为 **44×44 CSS px**，图标居中、锚点不随标签长度漂移。触屏不永久显示物件长标签，减少遮挡；鼠标悬停和键盘聚焦可以查看物件名称，屏幕阅读器仍通过 `aria-label` 获取名称。
- 选中后仍用 `RoomSceneFocus` 对应物件发光圈，并通过既有 `scene-discovery` 和故事记录反馈；不变更点击次数、存档或角色状态。
- 生产级背景使用较轻的两端暗角，尽量保留高质量画面细节；概念背景继续原本调色、月光和烛光。
- Playwright 回归验证手机 390px 下标记仍在视窗内，触控范围至少 44px，聚焦与物件调查仍生效。

## 本轮美术候选与不能越过的审核

独立制作了月纱契约会客室**无人物**参考插画（生成源像素 1672×941），并在会话产物中另外导出 2560×1440 WebP 候选。该文件并未推送到 GitHub 仓库，因此生产图像清单**保持 concept**，不能冒充已发布 CG。
