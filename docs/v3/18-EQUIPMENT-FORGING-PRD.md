# V3.3 装备、首饰、自动锻造与穿戴系统 PRD

> **状态：Proposal / 未实现。** 玩家要求：每个人物都可以穿戴装备与首饰，提升体魄/智慧/力量/精神/血气/速度；所有物品由工匠用**实际原料打造**；高品阶角色长期潜力更强。相关：[17 角色成长](17-CHARACTER-ATTRIBUTES-AND-POTENTIAL.md)、[02 自动生产](02-AUTO-PRODUCTION-PRD.md)、[19 配方与外观](19-EQUIPMENT-RECIPES-AND-ART.md)。

## 1. 装备不是另一个抽卡池

**核心循环**：观察设备自动产水汽/孢子/晶核 → 获得/研究一张锻造蓝图 → 玩家一次性指定制作数量与材料预留 → **炽角或其他合适工匠自动完成锻造** → 物品进入独立装备仓 → 根据角色属性与职业需求手动或一键选择装备 → 对话、人物房间、工作和探索出现可验证的改变。

- **锻造本身不需要抽卡、不用随机分解、不需要反复点进度条**；蓝图和主线必需物品从确定性任务获得。
- **物品品质独立于人物品阶**：N 人物也可使用 SSR/UR 级装备，只要满足真实工种/等级/特殊材料条件；装备不会改变角色天生 N 品阶。
- 制作高阶装备需高级材料、时间、蓝图与真正的资源竞争，**而非让 UR 角色天然免费拥有 UR 套装**。
- 角色在自己私室中可看见已装备的有代表性饰品、工具或小型悬浮护符；对非人形精灵设计佩戴适配，不给无手角色强套人类手套。

## 2. 六个稳定装备槽位（首版建议）

| slot | 中文 | 典型装备 | 职业/属性用途 |
|---|---|---|---|
| `tool` | 主手器具 | 锻锤、学者笔、藤杖、检修钳 | 力量、智慧、精神或职业特性 |
| `body` | 护具 | 工匠护衣、苔纹披风、铜制防护服 | 体魄、血气、工作环境适配 |
| `head` | 头饰 | 护目镜、灵木冠、夜巡发饰 | 智慧、精神、观察 |
| `necklace` | 项链 | 苔光坠、月纹护颈珠 | 精神、血气或特殊互动 |
| `ring` | 戒指 | 晶露指环、星纹灵契 | 智慧、精神、锻造调谐 |
| `charm` | 护符/腕饰 | 祝福护符、风行腕环 | 速度、血气、职业恢复 |

**非人形兼容**：实际外观可以是悬浮灵环、甲壳镶晶、叶冠或胸前徽章；在数据上只占同一个部位槽，不重复套用额外效果。初版先实装 `tool`、`body`、`ring` 三槽，其余在 UI 标记未开放并避免显示可装备假按钮。

## 3. 装备品阶：同五档、独立制造

| 品阶 | 描述与主要材料方向 | 典型用途 | 蓝图来源 |
|---|---|---|---|
| N 星尘 | 基础水汽/孢子器具 | 训练与入门舒适度 | 初始工坊 / 免费教学 |
| R 月辉 | 稳定结构 + 少量晶核 | 角色适配、基础效率 | 普通订单/街区项目 |
| SR 星纹 | 角色职业配方、特定材料比例 | 更清晰的职业专精 | 人物支线 / 工坊研究 |
| SSR 夜冠 | 高级稳定器零件与精密铭刻 | 复合功能、收藏外观 | 完成公共工程与稀有蓝图 |
| **UR 月蚀** | **后期永续晶核工艺与专属设计图** | **红色月蚀外观、有限的独特协同** | 确定性后期剧情/成就，不靠购买随机包 |

**UR 稀有色 = 绯红 `#DE344B`**，装备品质徽记、锻造完成、背包边框、人物房间陈列与卡牌 Token 一致；不能把红色故障警告误当 UR。

品质决定复杂度/属性预算范围，但**不能直接用「装备品质 × 角色品质」做无限倍数乘法**。高等级的低品阶职业专属工具仍可能优于不契合的高品阶通用器具；高阶物品不能在序章让全工坊瞬间满效率。

## 4. 自动打造工作流和队列

### 一次性操作

1. 玩家选中蓝图，看到需要原料、库存/已预留、预计完成时间、适用角色与预期属性。
2. 设置制作次数（例如 1、3 或直至指定库存量）。默认只造 1 件；**生产维持目标**可在后期开放，不能意外自动消耗全部晶核。
3. 确认后，系统生成 `CraftOrder`，**预留而不重复消费**所需原料，显示优先级和当前等待原因。
4. 有工匠/锻造站/原料后自动开工，工作时间由真实时钟模拟；完成时事务中扣除原料、发放唯一 itemId 的装备实例，自动进入装备仓。
5. 选择「自动穿戴推荐」需在 UI 展示受益属性与会替换的旧物品，由玩家确认；系统不能强制把正在穿的高品质饰品拆掉。
6. 未穿戴物品可保留、移给其他角色、未来分解回收（P3），不因为房间容量满就消失。

### 产线约束

- **原料守恒**：已有 V2 只有水汽、孢子和晶核；首批配方只使用这三种加已有独立金币成本。工坊目前水汽/孢子主要在机器内部，晶核在共用仓库，**先完成 P0 统一库存和资源路由，再接入装备锻造**。
- **优先级**：公共照明/已锁库存 → 已接受订单 → 玩家为锻造明确锁定的材料 → 普通贸易；玩家可改策略但必须看到预计资源冲突。不能写两个独立“可用晶核”余额。
- **容量**：每个已经开始的锻造工单有已预扣原料和唯一 `jobId`，不能在工坊机器和锻造台同时消费同一原料；未开始仅锁定可用量。
- **工匠唯一性**：炽角负责熔炉时不能同时作为另一座锻造台的真实生产者；配置角色到锻造站需要有可见的熔炉产能机会成本，或把首个锻造工作嵌入同一熔炉运行队列。
- **真实时钟**：锻造如同生产周期，由 `simulateUntil(nowMs)` 纯函数结算；离线 8 小时封顶、多标签只结算一次、切换页面不重置工单。
- **队列暂停与取消**：未开始工单取消可完整释放锁定原料；已开始工单的材料在在制品账本中，取消只退未消耗部分（第一版建议**退回材料但不返还已经过去的制作时间**，经济平衡需实测），防止无限造拆资源。
- **锻造产出是装备仓中的实物**，不能在剧情动画播放时凭空发放第二件，也不能直接加成角色而没有对应物品。

## 5. 装备强化、调谐与属性成长（P2 后期）

建议强化采用 **0～5 级确定性升阶**，每次消耗真实资源，**成功率 100%，不损坏物品**，防止玩法成为另一个赌博按钮。

- +1～+5 每一级提高该物品的**固定属性附加值**；成长有上限，不能无限强化。
- 装备的「镌刻」后期可让玩家在力量/精神等两种方案之间选择，不随机洗练无数次。
- 品质决定最高可承载的属性预算与艺术细节，**并不限制低品质角色穿高品质装备**。
- 支线特殊道具可以有「角色专属故事效果」，例如泉泡的漏水告警、青枝的生态观察；这些奖励也应存在非随机路线。
- **不做**装备随机品质抽取、概率炸装、刻意稀缺收费材料、强制短期活动、付费洗词条。

## 6. 角色穿戴与真实能力

最终属性来自 [17 六维成长公式](17-CHARACTER-ATTRIBUTES-AND-POTENTIAL.md)：装备附加数值**只加一次**，不会先乘角色 UR 系数，再乘装备 UR 系数。

- **体魄/血气装备**分别影响工作疲劳积累与休息恢复，不自动添加一个没有战斗用途的血条。
- **智慧/精神装备**帮助研究、温室、水汽调谐与可选故事线索；不能变相用装备锁定第五章主线信息。
- **力量装备**改善熔炉重型任务/物流，**速度装备**可改善物流或设备切换；所有百分比受总体上限保护。
- 房间拜访时代表性项链、戒指、头饰与护具可体现在透明图层或角色立绘的独立装备挂件；角色的真实装配来源是物品实例，不靠单纯变色的卡面假装已穿戴。

**人物对话举例（装备 × 生活）：**

炽角（锻造完成）：「这把锻锤现在像真正属于我了！不过那根管线还得青枝帮我调整。」  
青枝（佩戴苔光坠）：「花园的变化听得更清楚了。你是把它专门留给我的吗？」  
泉泡（装上水纹护腕）：「咕噜！修水泵的时候终于不会把扳手滑进水池了。」

这些是可选人物生活台词，不形成重复送礼刷好感。

## 7. 领域数据建议（非已实现代码）

```ts
type EquipmentSlot = 'tool'|'body'|'head'|'necklace'|'ring'|'charm';
type EquipmentRarity = 'N'|'R'|'SR'|'SSR'|'UR';
interface ItemTemplate {
  id:string;slot:EquipmentSlot;rarity:EquipmentRarity;
  stats:Partial<Record<AttributeKey,number>>;
  recipeId:string;equipTags:string[];
  artKey:string;passiveId?:string;
}
interface EquipmentInstance {
  itemId:string;templateId:string;forgeJobId:string;
  enhanceLevel:0|1|2|3|4|5;equippedBy:string|null;
}
interface CraftOrder {
  jobId:string;recipeId:string;quantity:number;
  completedQuantity:number;workerId:string|null;
  status:'queued'|'running'|'blocked-input'|'completed'|'cancelled';
  materialReservationId:string;
  activeItemId:string|null;finishAt:number|null;
}
interface EquipmentInventory {
  schemaVersion:1;revision:number;
  items:Record<string,EquipmentInstance>;
  craftOrders:CraftOrder[];
  itemSlotsByCharacter:Record<string,Partial<Record<EquipmentSlot,string>>>;
}
```

`AttributeKey` 是 [17 属性模型](17-CHARACTER-ATTRIBUTES-AND-POTENTIAL.md) 中建议定义的六维类型。**实现应避免两份双向写入的 `equippedBy` 与 `itemSlotsByCharacter`：推荐选其中一个作为权威索引，另一个是可校验派生视图，若暂时保留两者则提交事务必须检测一物多穿。**

### 推荐原子事件

`forge-reserved`、`forge-started`、`forge-completed`、`equip-changed`、`enhancement-completed`；每个事件具备唯一 ID 与事务 revision。画面特效来自已确认的事件，不得触发第二次产出。

## 8. 旧存档与互操作

- 旧 `cozy:v1` 已有住客/房间/金币保留，所有装备槽初始为空，属性由迁移器从角色静态表和等级记录推导，不给老玩家强制重抽。
- 旧 `workshop-v2-lab` 的仓库/设备/工匠岗位保留，新配方、材料预留和已开工单采用独立版本化持久层，必须避免双写竞态。
- 公寓金币与工坊星币暂未合并；**锻造成本只能明确属于一个经济账本（建议工坊星币），不能从公寓和工坊两边扣同一费用**。
- 装备不改变一人一私室规则；同一 `characterId` 的装备和属性在图鉴、私室与工作场景中是同一份权威数据。
- 错误或未知道具模板不能静默删除老物品：保留无效记录用于迁移修复，并展示安全占位。

## 9. UI 与设计验收

**角色图鉴**：人物大卡、六维属性、六格装备位、两三条当前职业受益提示；点击空格跳到有可制作配方的锻造列表。  
**角色私室**：可以查看穿戴的项链/头饰/护符，打开「衣柜/饰品盒」切换已拥有装备，并看见不伤害故事设定的小对白。  
**工坊**：一台与炽角关联的锻造台或熔炉子功能，有制作队列、原料来源、预计完成时间、缺料原因及取消/暂停；无需要连续点击的「敲打一百次」按钮。  
**仓库**：原料预留、在制品、装备仓与订单储备分栏，且总账严格守恒；装备实例与数量可对账。  
**月光街**：图纸研究/商人卖蓝图，但先前产物来自工坊真实材料而不是游离的第二经济系统。

- [ ] 首批 3 装备槽 + 至少 6 个可制作配方，确实消耗真实物料并产出唯一物品。
- [ ] 未开始取消不扣料；开始后迁移/刷新不重复产出，离线 8h 封顶，多标签最多一次。
- [ ] 卸装属性完整回退；同一 itemId 不可同时穿戴两名角色；更换装备原物回装备仓不消失。
- [ ] 材料不够时可预估缺口并暂停，不出现「已经扣了材料但出不了装备」的永久软锁。
- [ ] 工匠真实在岗：锻造与熔炉不能复制炽角工作量，视觉角色动作与工单状态吻合。
- [ ] UR 红色物品与 SSR 金色、SR 紫色不同，且所有等级有文字与图案而不只颜色。
- [ ] 即使 N/R 角色只穿基础装备，主线、主要 CG 和三种结局仍可达成。
- [ ] 制作动画关闭或资源加载失败后仍能完成锻造/穿戴；手机 390px 能看清六属性和物品效果。
