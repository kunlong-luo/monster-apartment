# V3.0 角色支线剧本、关系成长与职业奖励

> 角色关系通过真实经营结果、调查和对话选择成长，而不是每日送礼/点击好感度。这是可实施支线内容稿；正式任务系统尚待开发。参见 [人物圣经](04-WORLD-AND-CHARACTERS.md) 和 [主线剧本](05-MAIN-STORY-SCRIPT.md)。

## 1. 支线共通规则

**每人三阶段：** 相识（发现其需求）→ 矛盾（面临真实成本/选择）→ 和解（完成可见改善）。每一阶段最多一个首次触发奖励事件；可重看对白但不再改变经济或关系。

**关系数值建议：** -3 至 +3，只影响人物反应、部分配方提示和后日谈；不以单人好感值卡住主线结局。多人关系可能冲突：支持炽角高产不是「背叛」青枝，但长期无视环境成本会被两人指出。

**关系事件原则：** `relationshipDelta` 必须由首次完成的任务或有代价的选择触发，不能按 UI 打开次数累加。建立「能力奖励」时优先改变真实参数（节能、停机诊断），并明确条件、上限和测试。

## 2. 泉泡：《消失的扳手》

### BR-01 相识「咕噜，工具不见了」
【前提】至少一台水泵完成 3 次有效生产循环。  
【场景】工坊的水阀边。  
**泉泡：** 「咕噜……我的扳手又找不到了。」  
**玩家：** 「怎么每次工作都丢工具？」  
**泉泡：** 「其实是因为压力表一直报警，我跑去检查别的管路，回来就忘了放在哪里。」  
**玩家选项：** 「先排查压力」（支持技术诊断）／「先把工具位整理好」（支持工坊秩序）。  
【任务】检测一处真实缺水/断链设备，或放置基础工具整理设施。非随机丢失小游戏。  
【奖励】解锁水汽管路提示 UI，首次关系 +1。

### BR-02 矛盾「每个人都在等泉泡」
【前提】温室或熔炉因水汽瓶颈累计停机一定时间。  
**青枝：** 「泉泡已经连续工作了很久。不能再让他一个人扛着。」  
**泉泡：** 「我没事！再多一点水汽就够了……咕噜……」  
**玩家：** 「效率不该靠一个人疲惫地坚持。」  
【任务】调整生产节拍、添加缓冲储罐或安排合理休息；完工后产线缺水时间降低。  
【反馈】泉泡主动到休息区喝水，再回岗位；设备按排班自动恢复。  

### BR-03 成长「水会找到路」
【前提】水汽管路连续稳定运转一段有效营业时间。  
**泉泡：** 「原来不是我一个人跑得快，大家就一定能拿到水。」  
**青枝：** 「对，我们需要一条每个人都能信赖的管路。」  
**泉泡：** 「以后我会先把管路修好，再开工！也会记得休息！」  
【建议解锁】自动漏水/断链诊断与低额维护节省；不凭空生产额外水汽。

## 3. 青枝：《最后一朵月光花》

### FE-01 相识「叶片上的灰」
【前提】温室完成一次真实孢子生产。  
**青枝：** 「这不是正常的季节。月光花的叶子上出现了灰色纹路。」  
**玩家：** 「我能帮你做什么？」  
**青枝：** 「给我一点时间和稳定的水汽。我想知道它们在害怕什么。」  
【任务】维持温室供水一段生产时间，采集有效花样；首次触发生态线索。

### FE-02 矛盾「炉火与种子」
【前提】第二章温室争执后，玩家拥有至少一台工作中的熔炉。  
**炽角：** 「我只需要更高一点炉温，就能赶上订单！」  
**青枝：** 「但你身边那排种子会被烤坏。」  
**玩家选项：** 「调整隔热和设备布局」／「减少一部分高温批次」。  
【任务】真实建设隔热区或重新配置熔炉/温室配方，降低环境压力而非仅改 UI 标签。  

### FE-03 成长「花园会自己呼吸」
【前提】完成生态实验并修复一处水脉。  
**青枝：** 「以前我总觉得机器只会伤害植物。」  
**炽角：** 「可我这次的低温炉子，也得谢谢你的孢子！」  
**青枝：** 「也许我们都该给对方的办法留一点地方。」  
【建议解锁】节水温室配方（消耗降低须有产能/成本权衡）、可见的花园恢复阶段。

## 4. 炽角：《不肯熄火的旧炉子》

### CI-01 相识「旧炉门上的名字」
【前提】第一枚晶核真实出货。  
**炽角：** 「这台炉子的铭牌，比你想的还老。我小时候见过同样的结构。」  
**玩家：** 「它曾经属于谁？」  
**炽角：** 「属于一群相信机器可以让所有人过得更好的人。」  
【任务】检查炉子的真实温度/效率与铭牌，解锁一次有限的旧技术资料。

### CI-02 矛盾「最高产量的代价」
【前提】第二章商业/平衡路线启动扩产。  
**青枝：** 「炉子越热，温室的水汽波动就越明显。」  
**炽角：** 「我知道！但如果停工，交货怎么办？」  
**玩家选项：** 「升级散热管线」／「为设备设置安全峰值」。  
【任务】调整产线/维护策略；订单预测说明成本与风险，不能靠再点击一次“修复”免费完成。

### CI-03 成长「真正的作品」
【前提】完成第四章临时稳定器。  
**炽角：** 「我以前只关心产量。今天我更想让这台机器明天还能开机。」  
**泉泡：** 「咕噜！那我帮你检查供水！」  
**青枝：** 「我也把温室的数据给你。」  
【建议解锁】稳定器配方、减少熔炉缺料停机的可见策略提示，奖励不是无限免费晶核。

## 5. 月纱：《未寄出的合同》

### YU-01 相识「合同背后的名字」
【前提】第一单完成，月纱第一次来访。  
**月纱：** 「名字很重要。签字就意味着，哪怕别人没看见，你也得承担它的后果。」  
**玩家：** 「所以你会为自己签过的合同负责吗？」  
**月纱：** 「……我正在学。」  
【任务】对一份普通/特别委托作出风险知情选择（接受或拒绝都可完成）。  

### YU-02 矛盾「被藏起来的旧账」
【前提】第三章从钟楼取得旧采购记录。  
**玩家：** 「这些合同与你有关。」  
**月纱：** 「是。当年的每一笔账我都记得，可我一直不敢把最后那页拿给居民看。」  
**玩家选项：** 「现在公开」／「先核实并联系旧居民区代表」。  
【任务】公开或核验历史证据；不要求交出全部财产/现金，影响后续伊索对话。

### YU-03 成长「不收钱的一次运输」
【前提】第四章商队参与紧急抢修。  
**月纱：** 「没有写在合同里的义务，并不代表没有人需要承担。」  
**伊索：** 「那我以后会先看你做了什么，而不是看你穿什么衣服。」  
**月纱（笑）：** 「很好。做生意也应该看结果。」  
【建议解锁】一次性、限定用途的紧急运输券和公开报价系统，不能重复领取免费材料。

## 6. 阿洛：《第十三声钟》

### AR-01 相识「怀表慢了一格」
【前提】序章交钥匙完成。  
**阿洛：** 「我的怀表从来没有慢过，除了钟楼出事的那一夜。」  
【任务】调查钟楼外墙的报时错误，获得可追溯的第一条故障线索。

### AR-02 矛盾「被封住的记录」
【前提】第三章进入旧账本。  
**玩家：** 「为了避免恐慌，你就可以替所有人决定隐藏事实？」  
**阿洛：** 「我不是想骗谁。我只是担心大家承受不了。」  
【任务】选择公开/分阶段核验并协助联系居民，无惩罚性死路。

### AR-03 成长「重新报时」
【前提】月心灯修复或临时稳定器成功。  
**阿洛：** 「钟声应该告诉大家真正的时间，而不是替人遮住错误。」  
【建议解锁】钟楼调度视图与街区任务可视化；不提供制造额外生产资源的“时间加速”。

## 7. 菲娅：《夜里唱歌的花》

### FI-01 相识「没有开放的花店」
【前提】第一章东街缺光。  
**菲娅：** 「我这里不缺浇花的人，缺的是愿意听花的人。」  
【任务】调查一处月光花的异常光泽，不消耗金钱刷次数。

### FI-02 矛盾「藏起来的种子」
【前提】第三章发现地下水脉问题。  
**菲娅：** 「我把最后一批种子藏起来了。如果实验失败，我就真的什么都没有了。」  
**玩家选项：** 「先做小规模安全试验」／「邀请青枝共同分担风险」。  
【任务】配置有限试验田与可恢复材料上限，不要求把所有种子押给玩家。

### FI-03 成长「让花种重新流通」
【前提】成功恢复一个花园项目。  
**菲娅：** 「原来把种子交给值得信赖的人，它们才会继续盛开。」  
【建议解锁】月光花园种植、街道绿化变化、生态证据一次性提升。

## 8. 伊索：《最后一盏街灯》

### IS-01 相识「旧居民区的黑暗」
【前提】第一章东街事件。  
**伊索：** 「灯具没有坏，是晶核不够。」  
【任务】配置公共库存预留，完成一次真实自动交付。

### IS-02 矛盾「贸易与照明」
【前提】第二章月纱合同出现。  
**月纱：** 「让工坊有利润，才有能力修更多街灯。」  
**伊索：** 「但街上的人不能等到你们算完所有利润才回家。」  
【任务】设计一个可持续的照明保供规则，能同时显示订单预估与东街缺口。

### IS-03 成长「两个人的保供协议」
【前提】完成临时照明网与公开策略。  
**伊索：** 「我以前不相信商人。现在我相信有些规则真的可以让所有人受益。」  
**月纱：** 「我也终于学会，合同里应该有一栏写着‘公共安全’。」  
【建议解锁】照明设备维修排程与街区公共工程；不是每天领取奖励。

## 9. 诺因：《无人签名的设计图》

### NO-01 相识「图纸上的修改痕迹」
【前提】第三章得到档案。  
【对白】诺因不露脸，只留下旧机械录音：「如果有人看见最后一版图纸，请先读完能量损耗报告。」  
【任务】找到水脉/增幅对应关系。

### NO-02 矛盾「只有一种答案吗」
【前提】第五章钟楼核心区见到本人。  
**诺因：** 「我为了不让任何人回到黑暗，选择承担所有决定。」  
**玩家：** 「正因为你没有让大家一起决定，后果才被藏了这么久。」  
【任务】修复水脉循环并与阿洛、月纱共同面对历史责任。

### NO-03 成长「被补上的签名」
【前提】三结局任一达成。  
**诺因：** 「这次设计图上有了所有人的名字。我不再独自签字。」  
【建议解锁】月心灯历史展览、钟楼核心外观及后日谈。诺因的行为被理解，但其错误仍有清晰后果。

## 10. 支线验收

- 每条支线必须有**事件触发、真实玩家行动、视觉/经营反馈、独特台词**；单独做头像与任务列表不算完成。
- 同一 `questId` 不重复给奖励，关系变化与物资结算同一事务语义。
- 失去一种资源时任务可延后或替代解决，不永久软锁。
- 各支线与主线可以交错游玩，除诺因结尾外不要求完成全部支线才通主线。
- 任一支线至少测试「开始 → 切七页 → 刷新 → 完成 → 重看」全过程。
- 支线内容在正式上线前需核对人物小传、台词人格与美术一致性。

角色支线是彩蛋的**可选提示途径**，而不是解锁主线的强制条件。

| 青枝 FE-01/03 | F-04 月光花反常 | E-04 暗处花朵→CG-S-004 | 研究的发现变成地下水脉恢复指标 |

## 12. V3.3 人物支线与装备成长结合（无强制装备门槛）

- **泉泡 BR-01/03**：在维修任务中引出「晶露指环」水汽调谐蓝图；玩家完成首批真实锻造后，私室有发现指环的小对白。即使不装备也能发现备用水脉线索。
- **青枝 FE-01/03**：月光花园研究关联「星纹观测笔」「苔光披风」；智慧/精神帮助观察，但主线花园恢复有可替代调查路径。
- **炽角 CI-01/03**：通过锻造台制作炽纹锻锤，力量/体魄可改善高温设备日常维护；支线真正的结局仍是理解可靠性而非追求无限产量。
- **月纱 YU-01/03**：可选「月心护符」象征承担旧合同责任；配方材料需明确来源，剧情不因没有护符而卡关。
- **阿洛/菲娅/伊索**：各自有与智慧、精神或体魄相关的职业器具/首饰，但关键责任选择必须由玩家而不是属性自动决定。

装备制造与强化必须消耗真实资源，人物关系来自有意义的首次故事事件；可见配饰在私室/图鉴/工作场景同人同形。参考 [17 人物成长](17-CHARACTER-ATTRIBUTES-AND-POTENTIAL.md) 与 [19 装备配方](19-EQUIPMENT-RECIPES-AND-ART.md)。
