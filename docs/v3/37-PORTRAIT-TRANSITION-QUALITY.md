# V3.15：人物与环境独立的情绪演出

正式角色（residentStatus=production）及审核模式中的本机透明姿态，在姿态变化时使用仅作用于人物图层的 Motion opacity 交叉淡变；无需更换或过滤整张房间绘景，背景不会随人物动作失焦。遵循系统或游戏减弱动画设置，减弱时 transition 为 0。

四间 concept 角色依旧使用原样，不会假装现有静态人物有独立四个表情。现在全角色正式人物资源仍是 0/4，未来实际原画通过 portrait-provenance 审查后此演出才会在普通游戏中生效。

存档、经济、人物拜访与线索调查没有改变；任何审核素材的浏览器 Blob URL 只会在用户设备的本次预览中存在。
