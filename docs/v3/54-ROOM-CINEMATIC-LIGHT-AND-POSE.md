# V3.54 · 私室对白、人物与环境光同步演出

本轮实现四间房共享的故事光效演出，**不将概念图标为 production**。

- `RoomDialogueTheater` 自动分句，前段倾听、关键句使用该话题的亲近或警觉姿态；用户跳过直接进入最后一拍。
- `RoomSceneBackdrop` 接收同一房间的临时演出姿态，映射到 `attentive/warm/guarded` 光照状态。普通调查时仍是 ambient，关闭对话自动退回 ambient。
- 月纱为月白与暖烛；泉泡为冷蓝铜光；青枝为银绿花影；炽角为赤铜火光。新增光照绘在独立、不可点击的 CSS 图层中，**不移动、不模糊、不替换任何背景图像或触摸热点**。
- `usePageVisibility` 同时控制对话计时与环境动画暂停，减少动态效果时停用渐变过渡，剧本文字直接完整可读。
- 只改变临时 React state；不改七条路由、不增加操作按钮、不更改人物档案/工坊/存档结构。
- Vitest 验证姿态与光效映射；Playwright 覆盖月纱分句/跳过、减少动画及青枝房间回退到可调查场景。

已完成的工程改动不代表四姿态透明立绘已通过人工视觉与版权审核。实际 CG 保持 `concept`，直到来源、角色一致性、脚点、四帧透明、移动端和人工审核全部完成。
