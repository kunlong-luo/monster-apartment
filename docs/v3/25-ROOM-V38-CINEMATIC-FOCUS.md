# V3.8 · 私室画面聚焦和实际美术限制

## 本轮可玩的增量

- 新增 RoomSceneFocus：点击物件时，在正确的场景位置显示非阻塞的局部灯光及物件光圈，不缩放、不虚化背景原画。
- 光圈随房间主题和人物互动反应切换暖金、冷青、紫色，所有热点都按 room-stage-layout 的物件 ID 获取位置。
- 剧情演出将不透明的全面遮罩改为渐变底部字幕带，保留上方的场景视觉，观感更接近游戏演出而不是普通网页覆盖弹窗。
- 用户在设置中减少动效或操作系统开启减少动效时，聚焦层不执行入场动画，调查反馈直接显示。
- 人物档案和商业玩法的 LocalStorage 数据格式完全不变；聚焦仅由当前选中的物件驱动。

## 自动验收

- Vitest 校验四间房每个物件的灯光坐标和对应热点完全一致，颜色状态不影响坐标。
- Playwright 验证初次无光圈、检查物件后出现、不同物件颜色切换、剧情可跳过、手机端热点可点击。
- 额外采集月纱调查时的 desktop/mobile 截图进入已有的 GitHub Actions 美术审查产物。
- 所有七页面和 GitHub Pages 发布基线保持原状。

## 独立美术仍待制作

本轮尝试生成的图像仍将人物、窗口和 UI 烘焙到一张整图，不符合 V3.7 的“纯室内背景 + 透明人物 + 真实物件”准入标准，因此未使用也未设置生产美术标识。当前的 room-art manifest 保持 concept，不能误称已完成完整眨眼、口型或 4 张透明姿态帧。

下一项美术验收的顺序是：无人物月纱会客室 16:9 全幅绘景 → 同尺寸 4 张透明姿态立绘 → 与角色匹配的短帧动画 → 物件坐标人工校准 → production 质量门禁 → 完整发布。
