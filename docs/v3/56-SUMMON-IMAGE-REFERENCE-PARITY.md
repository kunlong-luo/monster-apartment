# V3.56 · 契约召唤原图对齐与资源可靠性

参照 `docs/design/2026-10-29-gothic-red-gold/phase-3-pixel-parity-and-functions.md` 的 1648×928 三段式原图布局，延续大厅的黑紫酒红、哑金细边、场景主体、底部七目的地。此次不新增页面，不重写卡池概率或玩家存档。

## 本次真实改动

- 召唤背景不再使用 `backgroundImage:'url(/art/...)'`，改为编译时静态导入并以真实 Next/Image 渲染，支持 GitHub Pages `/monster-apartment/` basePath，且不直接动画缩放画面本体；原生图像来源保持不变。
- 月纱中心立绘和右栏展示卡亦改为静态导入，防止子路径显示为破图。没有伪称已生成四姿态透明人物。
- 切换泉泡、青枝、炽角主题时，右栏卡牌改为对应真人头像、称谓与该人物异兽名，而不是永远固定月纱。人物稀有等级标签对应当前主题的展示档次；五池实际抽取权重保持完全不变，主题不产生隐藏 UP。
- 减轻活跃卡池的持续闪烁边框，移除中心人物图像的额外 CSS transform 缩放，避免浏览器重采样导致模糊。
- 端到端回归新增背景实际图片解码与跨主题右栏身份一致性；现有 1648×928 布局宽度比例、390px 手机点击与七路由继续检查。

## 不夸大审核

本轮主要解决了引用路径与场景/人物视觉一致性，不是对参考 PNG 的逐像素色彩测量，也不是新的高分辨率原画交付。正式四姿态 CG、异兽独立原画、版权与人物一致性仍须独立验收。只有完整 Quality 与 Pages 成功后方能称上线。
