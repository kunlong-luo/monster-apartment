# V3.2「月影契约」卡牌召唤、品质与招募 PRD

> **状态：Proposal，尚未实现。** 设计目的：让抽卡成为「发现新的公寓居民与人物故事」的可选惊喜，而非把主线、工坊生产和结局锁在随机数后面。本系统属于未来 V3.2，与 [对话玩法](08-NARRATIVE-DIALOGUE-UX.md)、[CG 收藏](09-CG-COLLECTION-AND-ART.md) 和 [角色池/卡面](13-CARD-ROSTER-AND-ART-DIRECTION.md) 并行。**首版免费离线抽卡，不引入真实货币充值、限时付费池或购买概率物品。**

## 0. 溯源与迁移边界

历史 `docs/SPIRIT_COLLECTION_V050.md` 曾经设计 18 个灵核、五种品质、N45/R30/SR17/SSR7/UR1、10/50/100 阶梯保底、免费十连与重复碎片。然而**当前正式代码** `src/core/cozy-engine.ts` 以精简 `SpiritId` 模型和五个 `COZY_RESIDENTS` 可见定义运行为主；不能声称历史 18 人/保底系统仍在当前七页完整可用。V3.2 必须单独定义兼容映射和版本迁移，禁止恢复旧 UI 或清空公寓存档。

**角色三种来源，不能混为一谈：**
1. **固定剧情角色**：月纱、泉泡、青枝、炽角、阿洛、菲娅、伊索、诺因。通过主线/支线认识、合作；**不得在概率池内成为推进主线的唯一可得角色**。
2. **可招募住客**：原创灵核、小型怪物，以及明确成年的人形访客；通过免费召唤、剧情赠送、居民交换凭证等方式获得。每人有生活习惯、房间偏好、职业和自己的故事。
3. **CG/回忆收藏**：角色首次相遇、升阶、生活事件与秘密照片所产生的插画，作为独立收藏类型。**拥有角色卡不等于自动看过其全部剧情，也不等于获得所有 CG。**

## 1. 玩家体验循环

工坊自动生产并完成可追踪订单 → 获得有限的「月影契约券」/招募进度 → 在公寓「月影召唤」进行单抽或十连 → 获得有个性的居民卡牌（含品质、工种、阵营、故事钩子） → 把他们安置在可住的房间、形成邻居关系 → 触发生活对话/职业小帮忙/支线 → 解锁 CG、图鉴传记与收藏回忆 → 返回主线继续经营。

玩家每天不需要手动收菜或点击上百次赚券；券来自**首次完成的剧情里程碑、公共建设、长期经营成就及有限可重复的周常经营目标**，不可依靠单一短周期设备无限产币买券，避免自动挂机变成无限抽卡。

## 2. 品阶和能力分配（五档保留历史概念）

| 品阶 | 名称 | 角色意义 | 主要特点 | 与剧情的关系 |
|---|---|---|---|---|
| N | 普通 · 星尘 | 亲近又有个性的街区住客 | 低成长成本、日常事件、部分房间互补能力 | 可完整参与日常故事 |
| R | 稀有 · 月辉 | 有明确职业专长的住客 | 专属生活技能、小幅生产/维护便利 | 能发现普通线索 |
| SR | 精英 · 星纹 | 多机制协同的职业角色 | 特殊住客互动、明显的布局选择空间 | 有一条完整人物小故事 |
| SSR | 传说 · 夜冠 | 身世与城市历史有关的角色 | 独特环境互动与高品质立绘/分支演出 | 可解锁可选的世界观侧写 |
| UR | 神话 · 月蚀 | 极少见的神秘住客 | 最独特的外观、额外 CG/背景、个性能力 | **不掌握主线唯一钥匙**，不会使普通队伍失效 |

**品阶决定稀有美术和角色复杂性，不应简单决定生产收益倍率。** 优先控制单角色对全产线影响的上限：UR 不应一张卡让生产翻数倍；N/R 在相应房间和邻居组合中可有优选场景，避免全被丢弃。

人物可以有三态：普通卡面（首次获得）→ 进阶立绘（完成职业/生活故事）→ 特别回忆 CG（关键支线/隐藏秘密）。角色升级不改变其原始品质，避免稀有度与故事深度绑定。

## 3. 首测概率与保底（**新方案，不是已上线概率**）

首个测试池建议基础单抽概率：

| 品阶 | 基础概率 | 说明 |
|---|---:|---|
| N | 20% | 普通居民 |
| R | 35% | 专长居民 |
| SR | 29% | 进阶角色 |
| SSR | 13% | 传说 |
| UR | 3% | 神话 |
| **总计** | **100%** | 不随动画/时间/点击速度改变 |

这组概率适用于**免费游戏内招募**，相对历史 V0.5 的 1% UR 和高保底更温和，目的是减少纯重复劳动。正式冻结需游戏内测和概率模拟，避免 10 连抽看起来“都是没用的普通卡”。

**建议保底（测试中可调整）：**
- 连续未得到 SR 或更高品质，到第 **5 抽** 强制至少 SR。
- 连续未得到 SSR 或更高品质，到第 **20 抽** 强制至少 SSR。
- 连续未得到 UR，到第 **60 抽** 强制 UR。
- 三条计数分别记录；抽到符合等级的卡重置相应计数；达到多个阈值时**先执行最高品质保底**。所有保底对单抽和十连统一适用，十连只按顺序执行十个单抽，不单独隐性优惠概率。
- **新手契约**：第一章可免费获得 10 抽以及一个可选择的 SR 初始住客；初始招募首十抽至少 1 个 SSR（新手独立一次性保证，不重置 UR 保底、不影响日常池规则）。必须在 UI 写清新手池与普通池差异。
- 抽取算法必须将 **基础概率** 与 **含保底后的综合实际概率** 区分公示；公示实际概率需要 Monte Carlo/确定性推导验证，不要把表中数字冒充最终综合出率。
- 十连结果和十次单抽在同样初始状态与同一组 RNG 输入下严格等价；不得隐藏“最后一张概率更高”但不披露。

**不做**：未披露动态概率、近失误假演出、无限循环自动抽、因在线时长强行降低出率、夸大限定角色损失、付费十连、充值保底、逼迫每天登录的任务。

## 4. 抽取资源与节奏

- **货币独立**：`MoonContractTicket` 月影契约券不等于公寓金币/工坊星币；不自动把两本经济账合并。
- **获得渠道**：首次修复街灯、完成角色支线、章节里程碑和每周有限的模拟经营成就。原则是**单个 eventId 只能发一次奖励**。
- **首次进入**：玩家完成序章可获得初始可用角色与少量招募券；第一章后拿到新手十连。不要要求抽到指定人物才能运行三台初始设备；三工匠仍由主线获得。
- **长期资源**：例如每周 3–5 次真实经营挑战各提供有限券，保底进度跨周累计且永久保留，不随期限归零。实际发放量在经济平衡测试后冻结。
- **可选定向召集**：未来用通过剧情获得的「居民邀请函」兑换一个基础 R/SR 住客；为长期非随机补全角色提供路径。
- 不为制造冲动设置人工短期过期券；可离线领取应得但未处理的里程碑奖励。

## 5. 重复卡、公平度与保底误区

- 同一住客的实体所有权唯一；重复抽中不能凭空让公寓出现两个同名居民。
- 重复会转换成**对应品质与身份的回忆碎片**，可用于非线性小幅成长、扩展角色房间互动、解锁可选皮肤或纪念相框。
- 不以重复 UR 作为解锁其个人剧情的前提。角色主要情节由相处与真实行动决定。
- 低品质重复累积可通过可见比例兑换未来的 R/SR 指定邀请函；进度永久有效。
- 不允许复杂币种套娃：P1 初版只需契约券 + 一种碎片进度，后续是否细分品质碎片要通过用户测试。
- 同一品质内角色出现概率如果等权，则按等权公布；若有活动定向，需明确角色权重与必得条件。

## 6. 公寓经营/工坊/故事的实际功能

抽到一位居民，不是马上拥有万能战斗英雄。每人附带一项**可解释的生活/辅助能力**：

| 专长 | 价值 | 限制 |
|---|---|---|
| 水汽协助 | 降低水泵小幅维护成本，或提前预警漏水 | 不能凭空生成无限水汽 |
| 生态护理 | 提高温室稳定性/减少某种资源浪费 | 不替代青枝的主线职责 |
| 巡夜守护 | 影响公寓住客舒适度和夜间事件 | 不直接生产晶核 |
| 商贸沟通 | 改善部分普通订单提示与交易效率 | 不能让高额特别委托无风险 |
| 档案探索 | 解锁可选调查提示/传记注释 | 不直接提供诺因的核心主线线索 |

**能力上限建议**：同类生产辅助仅计算 1 个主动住客的主要加成；高品质不与重复副本无限叠加。根据房间喜好、阵营羁绊、相邻好友形成差异，而非 SSR 自动碾压 N/R。

**主线 NPC 决不进入常规池**：月纱、泉泡、青枝、炽角的基础人物卡和演出随剧情解锁；可以通过其个人支线获得服装立绘/特殊回忆，但不能靠概率抽卡获得“在剧情中认识她”的资格。

## 7. 召唤 UI、揭晓动效和高品质卡牌感

### 7.1 容器

保持七个正式路由，优先在 `/characters/` 放置小型「召唤 / 居民 / 回忆」分页；公寓里可保留一次性轻入口，**不新增大面积抽卡页或第八个正式路由**。后台主舞台持续存在；召唤弹窗可关闭，不停止工坊生产。

### 7.2 每次抽取演出

1. 点击「召唤一次」或「召唤十次」，明确展示消耗券数。
2. 在事务内先核验余额，再决定本次卡牌结果、保底变化、碎片与 eventId；**保存成功后才呈现揭晓动画**。
3. 1 秒符文环聚光 → 卡背翻面 → 依品质展示不同边框、花纹、人物高清卡面 → 可选查看新角色简介/故事伏笔。
4. SSR/UR 首次获得使用 2–4 秒可跳过特殊镜头：星纹破碎、月色从窗边涌入、卡面图层视差；音效可关，遵守减少动态效果。
5. 十连结果一次性收纳为 10 张缩略卡 + 重点高阶角色特写，玩家可一键跳过重复抽中的长动画，不做十次强制等待。
6. 「加入公寓」「查看档案」「继续经营」路径明确；离开前记录结果，不因动画被关闭损失卡。
7. **隐私/剧透**：UR 人物背景和月心灯真相按玩家章节解锁注释。抽卡预览不能提前展示第五章真相 CG。

### 7.3 稀有卡视觉语汇（不是满屏随机闪光）

- N：旧羊皮纸与银灰描边，柔和暖灯；安静的「回家」感。
- R：银蓝月纹、细小水晶亮点，轻微卡面光泽。
- SR：紫罗兰星纹、1–2 层视差、完整名字徽章。
- SSR：深金黄铜雕框、浮起人物与星座符号、稀有声音主题。
- **UR：深绯红/赤红月蚀主题**，红宝石卡框、绯月天空与个人引入镜头；黑金只作辅助材质，**大特效仅在第一次获得或主动重看**。统一视觉源见 [16 品阶 Token](16-RARITY-VISUAL-TOKENS.md)。

品质不只靠颜色区分，还要有文字标签/可辨边框与图案；prefers-reduced-motion 显示静态卡面同样完整。

## 8. 推荐存档模型（非现存代码）

```ts
type Rarity = 'N'|'R'|'SR'|'SSR'|'UR';
interface RecruitPoolConfig { id:string;version:number;weights:Record<Rarity,number>;memberIds:string[]; }
interface RecruitProgressV1 {
  schemaVersion:1;
  revision:number;
  tickets:number;
  ownedIds:string[];
  duplicates:Record<string,number>;
  memoryShards:number;
  pity:{sinceSR:number;sinceSSR:number;sinceUR:number};
  beginnerSSRGuaranteedUsed:boolean;
  summonHistory:Array<{eventId:string;poolId:string;characterId:string;rarity:Rarity;at:number}>;
}
```

- 抽取 **事务化**：`draw(pool, state, RNG, count)` 纯函数处理顺序、保底、扣券、首次登记/重复补偿；权威存档原子提交，不让 React 控件负责抽卡经济。
- 随机源在浏览器使用 Web Crypto（测试可注入确定性 RNG）；**本地游戏无法保证防客户端篡改**，不能宣称有服务器级防作弊。
- 恢复旧存档时已有居民映射为 `ownedIds`，不得失去已安置角色。历史 V0.5 的等级、阵营、卡牌、抽数若能找到已验证的字段则逐项迁移；不存在的字段不臆造。
- `eventId` 与 `revision` 幂等；十连途中刷新或两个标签同时抽取不能重复扣券或重复给 UR。
- 配置池 `poolId + poolVersion` 冻结后写入历史，变更概率必须更新版本，兼容旧结果。
- `summonHistory` 长期应归档或分段，保留玩家最近可见记录与权威保底计数，不无限扩大 JSON。
- 任何通过主线赠送的卡不消耗契约券，也不假装随机抽取。

## 9. 风险与研究

1. **故事被稀释**：玩家只想刷 UR，人物性格无用。应让每张卡有可见房间生活、对话和角色剧情。
2. **低稀有无价值**：N/R 只能拆碎片。必须给低品阶独特偏好、相邻关系与少量可爱/幽默故事。
3. **保底折磨**：玩家为了 UR 被迫机械挂机。用免费易理解的 60 抽保底与选择性兑换，且不能影响主线。
4. **美术成本**：18 张人物立绘 + 品阶动画 + 3 个形态不是一周做完。先 8–12 张审核卡牌试验，再迭代。
5. **合法性/年龄**：当前设计仅限离线、免费游戏内契约券；以后如果加入真实付费抽取，需针对发行地区重新评估概率公示、未成年人保护、平台规则与当地法律，**必须在评估前禁止收费**。

## 10. 验收用例

- 100 万次模拟（可固定种子）基础品质频率符合权重，含保底后实际概率单独报告；五档总权重为 100。
- 保底在第 5/20/60 次精确触发，抽到合格级别正确清空相关计数，十连与十次单抽结果在相同输入下相等。
- 新手保底 SSR 与通常 SR/SSR/UR 计数互不制造回退或双重额外卡；新手 10 张恰好 10 次，不多发第 11 张。
- 首次卡片到账后重复抽取变为碎片；相同角色只拥有一个身份和一个专属私室，不产生经济克隆；剧情授予的 NPC 不进入概率池。
- 无券、双击十连、页面重载、多标签并发和存档迁移均不重复扣除/发放。
- 全程关闭动画时卡牌和稀有度准确；资源加载失败能够展示文字卡并完成召唤。
- 未招募角色可通过非随机途径完成主线；抽到 UR 不自动解锁诺因秘密或全部隐藏 CG。
- 320/390/820/1280/1920px 清楚呈现十张卡，不能逼迫纵向无限滚动和遮住继续按钮。

**实施依赖**：先完成 P0 自动生产与 V3 剧情事件存档；再做 V3.2 召唤逻辑与图鉴；首批卡面审核后才能对外展示正式招募效果。

## 11. 召唤成功后自动出现专属个人房间

招募成功后的下一步不应仅是「抽到一个角色」：**该 `characterId` 解锁一间独立精美私室**，可以从公寓走廊或人物图鉴拜访，看见角色生活、与其交谈、观察私人物件和触发可选小故事。

- 一人物一间 `CharacterSuite`，与 `CozyState.rooms` 的既有六间经营房不同；不因六间满载而无法拜访，也不增加免费房租。
- 重复抽到不产生第二个房间，专属展示的角色不因派到工坊而复制生产实体；保持旧档入住位置。
- 主线 NPC 通过剧情开放私人工作室，不需要概率抽卡获得入室资格；隐藏故事/CG 仍由真实剧情事件锁定。
- **UR 神话·月蚀主色固定为绯红**，非旧版「月虹/黑金」主色。查看 [14 房间 PRD](14-CHARACTER-PRIVATE-ROOMS-PRD.md)、[15 房间大图美术设定](15-CHARACTER-ROOM-BIBLE.md)、[16 品阶视觉规范](16-RARITY-VISUAL-TOKENS.md)。
