# V3.15 · 四间私人房间收藏级美术制作任务单

> 状态：制作规格（不是已交付原画）；更新于 2026-10-30。遵循 `AGENTS.md`、`public/art/rooms/README.md` 和 V3.14 透明姿态准入流程。当前四间房依旧为概念资源；禁止改写 `production` 状态或声称高清 CG 已上线。

## 本轮目标与验收

一间私人房间应让玩家在 5 秒内辨认住客个性，在 30 秒内发现至少三个可调查的叙事物件。环境负责空间与光，角色负责表情/动作，调查热点由游戏代码覆盖；**任何文字、按钮、UI、角色都不能烘焙进场景背景**。

每间房分别制作：
1. **空景原画**：优先原生 3840×2160（至少 1920×1080）；16:9，WebP，有清晰空间透视、近中远三层、明确唯一主光方向；不是对原 SVG 简单高清插值。
2. **独立人物**：同一角色四张真实透明的 `idle / attentive / warm / guarded` WebP，画布均至少 1000×1000、相同分辨率/脚点/视角、差异明显且身份一致；禁止从合成场景里裁剪人物。
3. **交互标注**：三个叙事道具各有背景原画中真实可见的中心坐标，记录到 manifest 的 `objectAnchors`（x/y 归一化），并在桌面、390px 窄屏、极宽屏手动确认不误触/遮挡；不可见道具必须有可访问的后备列表。
4. **资产来源及审核**：作者/生成方式/商业授权说明、原始文件、最终 WebP SHA-256、无水印核对、手机端截图、审核者和日期。自动测试仅是尺寸/格式/遮罩准入，**不代替人体、构图和版权的人工复核**。

## 统一人物美术约束

- 四人必须具有**不同的脸部骨相、眼距、鼻梁、发际、身型比例与姿态语言**，不能只替换头发颜色或服装颜色。可以使用哥特奇幻与有魅力的成人时装，但不过度依赖裸露来代替人物设计。
- 每个姿态必须保持耳饰、角饰、衣领、发尾、标志性装备连续；双手与手指可辨、无多肢、无融合道具、无透视错误。
- 光照与当前房间匹配，阴影绘在角色本身，角色边缘无白边/黑边；透明背景不得包含地板、墙壁、书架或按钮。
- 角色脚点和占位需适配同一 `object-fit:contain` 区域；校验四姿态切换时头部位置稳定，无突兀闪跳。

## 资源入口与真实晋级

- 正式空景候选：`pnpm art:review --room yuesha --source /path/to/background.webp --out /tmp/yuesha-bg-review`（参数以脚本实际帮助/文档为准）。
- 四姿态候选：`pnpm art:poses --room yuesha --source /path/to/poses --out /tmp/yuesha-poses-review`。
- 首先生成 `review.html` 与 DRAFT 审核记录；在完成视觉/授权复核前，不执行晋级操作。
- 正式素材最终分别落在 `public/art/rooms/{room}/background.webp` 与 `public/art/rooms/{room}/poses/*.webp`；旧 `concept-scene.svg` 只作为未准入时的回退，不再冒充最终品质。
- 更新 `public/art/rooms/manifest.json` 时背景、人物分层独立设为 `production`，只有两层全部审核通过才允许 `composition=separated`。验证 `pnpm audit:room-art` 与 `pnpm e2e`。
