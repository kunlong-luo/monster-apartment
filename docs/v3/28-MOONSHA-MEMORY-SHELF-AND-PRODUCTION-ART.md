# V3.9 下一轮 · 场景占比和真实记忆收藏

## 已开发可玩内容
- 月纱会客室在宽屏采用约 2.1 : 0.9 的场景/对话比例，提升绘景可视面积，右侧仍是可滚动的真实人物话题与调查反馈；手机端不改变单列交互路径。
- 底部“月光回忆”是一个小型场景图鉴：蜡封、香料茶、账页各对应一张卡，蜡封+账页一起解锁第四张“半月旧契”。
- 收藏状态仅从已有 `monster-apartment:character-life:v1` 调查记录即时派生，不创建新的等级、亲密度、金币或道具，不修改存档结构。
- 未发现卡片禁用且不泄露文本；已发现卡片可直接重看角色在场景中的反馈（不重复写存档），第四张卡回看双线索共鸣。
- 第四张卡的封面沿用已知的月纱人像绘景，**只是图鉴封面**，不能冒充无人物室内背景或透明姿态素材。

## 美术实验失败与处理
本轮图像生成仍把人物、黑猫、图鉴按钮和资源栏烘焙进同一张图，不符合可独立演出的分层美术要求，故没有替换场景原画。当前 `public/art/rooms/manifest.json` 的月纱状态仍是 `concept`。

## 测试和可维护性
- Vitest：检查 0/4 → 1/4 → 3/4 → 4/4 的解锁边界、不同物件顺序及不修改 V1 旧记录。
- Playwright：桌面调查全部物品后 4/4 收录，第四张记忆可查看，点击蜡封记忆能聚焦对应场景；手机端只调查蜡封时应为 1/4、账页锁定，并能重看蜡封。
- 不创建无法操作的按钮或使用假的货币 UI。仍保留之前的七页面路由、原版房间对话与逐句自动演出。
- 下一项真正美术工作是分别交付无人物房间 `background.webp`、四张真透明姿态帧及审阅证据，再通过 `audit:room-art` 门禁，才可把状态改为 `production`。
