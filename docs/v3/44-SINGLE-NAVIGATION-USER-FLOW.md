# V3.21 · 七页面只有一套导航

## 问题
大厅同时展示底部导航、三个重复快捷入口和全部功能弹层；工坊同时显示回大厅、月光街“世界地图”和底部导航；月光街四个世界分页面有额外的“回大厅”和画面上不可见的委托大热区。玩家不知道自己位于哪里，也不知道进入街区和进入委托有什么区别。

## 统一规则
全局唯一的页面切换入口是游戏底部的 7 个目的地，顺序固定：
大厅（当前目标）/ 公寓（经营住客）/ 工坊（造设备、派工和生产）/ 角色（拜访与图鉴）/ 委托（查看交期与接单）/ 探索（街区交易与居民请求）/ 仓库（核查库存）。

所有导航由 `src/components/moonwork/world-navigation.ts` 唯一的数据源提供，当前页使用 `aria-current=page` 表明位置。月光街只是街区，不承担“所有页面地图”角色。地方性任务操作（如从角色卡片跳工坊选中工匠、从订单检查缺料进工坊）可以保留，但必须明确下一步动作，不能重复创建一套世界导航。

去重：大厅右侧快捷路由和“全部功能”菜单移除、工坊顶部的双路由移除、公寓顶部回大厅的重复入口改成位置标题、世界四页顶部回大厅和图片上的不可见委托跳转移除。带有具体语义的主线订单卡片和角色拜访按钮保留。

## 当前任务流程
1. 查看大厅主线 → 去工坊安排生产；
2. 工坊点击工匠、设备，推进一个生产班次；
3. 仓库核查水汽/孢子/晶核存量；
4. 委托核对交期、接取或交付；
5. 原料不足时到月光街采购，或帮助街区居民；
6. 公寓和角色页面经营住客、对话、拜访房间，与生产主线可并行。

修复了工匠深链接重复 choose-worker 导致工匠反选的真实 bug：Pixi runtime 已在 mount 时选择 `?worker=...`，React 不应再次派发同一切换事件。修正了手机端旧 E2E 必须三栏同时可见的错误假设，正确按标签切换后逐项验证。
