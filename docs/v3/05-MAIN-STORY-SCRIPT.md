# 《怪物公寓：永不熄灭的月光》V3 主线全剧本（可实施初稿）

> **状态：完整主线创作稿 / 尚未上线。** 章节：序章 + 第一至五章 + 终章三结局。对白为原创初稿；角色设定以 [世界观与人物圣经](04-WORLD-AND-CHARACTERS.md) 为准，触发条件以 [世界状态与任务模型](03-WORLD-STATE-AND-QUESTS.md) 为实现依据。所有数值仅是拟议配置，平衡后可调整。

## 演出通用约定

- 【场景】写明路由与场景背景；【镜头/动画】只描述需实现的效果，不把静态概念图当已集成资产。
- 【触发】依赖**已确认的真实事件**或玩家主动打开剧情；不靠客户端时间循环造剧情。
- 【选项】标注 choiceId 及实质影响。同一幕只能首次发生经济/剧情副作用；重看仅播文本。
- 【任务】由生产/采购/订单/调查等自动判断；不设置连续点击、送礼次数、签到门槛。
- 减少动效或弱机模式只播静帧与对白，禁止因特效没有播完而卡住剧情。
- 玩家台词为选项文本，允许未来支持多种称谓；不强行设定性别。
- 每幕最后的 `sceneId`、`flag` 为拟议数据标识，非现存已实现常量。

# 序章：夜色中的继承人

## P00 / ch0-s01「交给愿意照顾这里的人」

【地点】大厅、旧公寓门口。  
【触发】新档首次进入故事；旧档可主动回看，无重复赠送资源。  
【镜头】夜空的蓝紫月亮；空荡街道；钟楼指针停住。雨后路面倒映黄铜灯笼。一辆旧马车停在公寓前，镜头推到门牌。

**旁白：** 月光街已经很久没有在午夜听见完整的钟声了。  
**旁白：** 一封没有署名的遗书，把你带到这栋年久失修的公寓前。  
**阿洛：** 「你终于来了。我是阿洛，钟楼的守护人。」  
**阿洛：** 「这栋公寓的主人临走前留下一把钥匙，要我交给真正愿意照顾它的人。」  
**玩家选项 P00-A：** 「这里以前发生过什么？」  
**玩家选项 P00-B：** 「我先看看公寓还值不值得经营。」

- P00-A：阿洛神情僵住。「旧时的钟声很准。现在……我也不确定应该从哪件事说起。」设 `askedAboutHistory`。
- P00-B：阿洛点头。「屋顶还牢固，地下室里有一间旧工坊。若它还能运转，这地方便还有希望。」设 `askedAboutBusiness`。

**阿洛（汇合）：** 「别急着决定要留下还是离开。你先见见住在这里的人。」  
【演出】钟楼突然传来**一声不在整点的钟响**，街边一盏灯暗下去。  
**阿洛：** 「……又发生了。这不是正常的报时。」  
**旁白：** 钥匙沉甸甸的，像在等待一扇门重新打开。

【任务】进入地下工坊。无货币奖励。完成标记 `keyReceived`，下一幕 ch0-s02。

## P01 / ch0-s02「工坊醒来了」

【地点】工坊。  
【触发】首次进入工坊且 `keyReceived`。  
【镜头】灰尘被月光照亮，铜管有水滴滑过。玩家触碰主阀门，旧水汽泵轻响。

**泉泡（从泵后探头）：** 「咕噜！是谁？工坊又要开门了吗？」  
**青枝（在角落整理叶片）：** 「是新的脚步声。空气也变了一点。」  
**炽角（敲了敲锈掉的炉门）：** 「还好炉子没彻底报废。先别聊了，让我看看供能！」  
**泉泡：** 「新主人，你不需要天天守在这里按开关。只要给我们安排好岗位，我们就会自己工作。」  
**青枝：** 「不过别忘了，温室需要真正的水汽。设备离得太远，再热闹也长不出花。」  
**炽角：** 「说得好！机器得排成有用的队伍，不能只摆着好看。」

【互动】玩家选择泉泡并派往水泵。设备进入 startup → running；玩家**不用点击生产**。  
【自动触发】首份 `production-completed(well)` 事件后续播以下对白：

**泉泡：** 「成功啦！是我们的第一份水汽！」  
**炽角：** 「哼，水汽只是开始。等我把熔炉修好，才算真本事。」  
**青枝：** 「那我先去整理温室。也许我们能一起让它恢复生长。」  
**旁白：** 一台机器亮了起来。远处月光街，仍有许多灯等待点亮。

【任务】派工一次；等待自动产出 ≥1 水汽（事件已确认），不能用画面粒子模拟完成。  
【状态】`firstWaterProduced`，解锁第一章及自动生产教程；老档满足条件可直接补领剧情标记，不发第二份水汽。

# 第一章：重新亮起的灯火

## C01 / ch1-s01「真正的流水线」

【地点】工坊、三台基础设备区域。  
【触发】`firstWaterProduced`。  
【镜头】水泵的蓝光沿黄铜管线抵达玻璃温室；另一个方向是仍未点火的熔炉。

**炽角：** 「光有水汽，最多卖给洗衣铺。想做晶核，还需要让温室长出孢子。」  
**青枝：** 「温室不是随便放在哪儿都行。需要邻近稳定的水汽源。」  
**泉泡：** 「如果管路没有连通，我会在控制台提示你！不用一个个去敲机器问。」  
**玩家选项 C01-A：** 「优先保证线路稳定。」  
**玩家选项 C01-B：** 「尽快做出第一枚晶核。」

- C01-A：青枝认可可靠性；展示相邻和原料预留引导。
- C01-B：炽角认可速度；展示产线吞吐与临时瓶颈引导。
- 两选项均允许后续调整，不以初次回答锁死路线。

【任务】连接水泵 → 温室 → 熔炉，三位工匠在其擅长岗位；自动产出至少 1 枚晶核。  
【触发后对白】

**炽角：** 「看到没有？真正的晶核！像把一小片月光装进了石头里。」  
**青枝：** 「它消耗了水汽和孢子。每一枚都不是凭空出现的。」  
**泉泡：** 「我去把管道压力调稳一点！下一枚会更顺利！」  
【状态】`firstCoreProduced`。

## C02 / ch1-s02「东街失去的三盏灯」

【地点】月光街、东街灯杆下。  
【触发】`firstCoreProduced`；从大厅/街区主动进入。  
【镜头】伊索提着工具箱，正在爬梯检查街灯。旁边小店已提早关门。

**伊索：** 「麻烦了！东街又有三盏灯熄灭了。」  
**玩家：** 「灯具本身坏了吗？」  
**伊索：** 「灯具没坏，是晶核不够。商业街还有备用的，东街已经一枚也没有了。」  
**菲娅（从花店出来）：** 「今天的月光花也没有开放。花和灯一起变暗，这不是巧合。」  
**青枝：** 「水脉的味道有些不对。像有什么东西正在把它慢慢抽空。」  
**伊索：** 「我不要求你把所有晶核都交出来。只是能不能先为东街留六枚？有了它们，晚上孩子和老人就不必摸黑走路。」

【选项】C02-A「把公共照明设为优先保留」；C02-B「先保证普通订单，但公开安排援助计划」。  
两选项均创建街灯公共项目；A 直接设立默认预留 6；B 让玩家先在仓库设置预留期限和数量，之后不强制立即交出；没有“拒绝就死档”。

【任务】设置公共库存预留，等待自动生产累计至可交付 ≥6，自动执行一次 `public-project-completed(east-street-lamps)`。  
【演出】晶核通过运输轨道送到街灯基座，三盏灯逐一亮起；不需玩家点击三次。  
**伊索：** 「亮了……终于亮了！东街的门又可以开到晚一点了。」  
**菲娅：** 「你看，花瓣也开始微微发光。」  
**青枝：** 「这让我更确定，问题不只在灯具上。」  
【状态】`eastStreetLit`、公共建设首次完成，计入 communityScore 一次。

【地点】工坊出货口 → 大厅月色窗边。  
【触发】首张普通订单从共享库存**实际自动交付**，与 C02 先后不限；该幕要求 `firstOrderDelivered`。

**阿洛：** 「……你以后会知道。今晚可能先有位客人来访。」  
【镜头】大厅二楼窗边，一位深色礼服魔女放下茶杯。  
**月纱（自语）：** 「那座炉子，终于重新亮起来了。」  
【状态】`firstOrderDelivered`，第二章解锁。**这幕不是再次发放首单奖励。**

# 第二章：月纱的交易

## C04 / ch2-s01「合约上的月光」

【地点】大厅会客桌。  
【触发】首次订单交付且玩家主动点开月纱来访。  
【镜头】柔暖烛光、杯沿反射，桌面展开带月纹的合同。

**月纱：** 「欢迎，新的管理者。我是月纱，一个喜欢与真正有本事的人做生意的魔女。」  
**玩家：** 「你怎么知道工坊重新运转了？」  
**月纱：** 「在月光街，会发光的晶核向来藏不住。尤其是来自那座老熔炉的。」  
**月纱：** 「我愿意出更高的价格，但合同附带交货条件。若你把东街预留的晶核都卖给我，账面会漂亮些，街上的灯却不会因此更亮。」  
**玩家选项 C04-A：** 「让我看看普通和特别订单的风险差异。」  
**玩家选项 C04-B：** 「先不接特别委托，等产线稳定。」

- C04-A：打开委托风险预测；是否最终签约仍需玩家独立确认。
- C04-B：保留邀请为 offered，可之后再次访问；月纱不会施压，也不阻断主线。

**月纱：** 「看来你不像那些只看报价的人。不过，别急着相信我。我也并非没有做错过事。」  
【状态】`metYuesha`；真实合同是否接受由订单系统决定，剧本本身不签约不发奖励。

## C05 / ch2-s02「温室里的争执」

【地点】工坊玻璃温室。  
【触发】`metYuesha`，玩家首次修改仓库预留或接受特别委托。  
【镜头】水汽表针跳动，青枝从叶脉上摸到黯淡的光。

**炽角：** 「如果再升级一台熔炉，晶核产能就能翻上去！」  
**青枝：** 「温室里的孢子长得越来越慢。我不确定是水汽不够，还是水脉出了问题。」  
**炽角：** 「机器不是坏人！总不能因为担心就全部停工吧？」  
**青枝：** 「我没有说停工。我只是想知道，为什么花开始枯萎。」  
**泉泡：** 「别吵，别吵！我能先记录水汽变化。这样大家就知道问题在哪里了。」  
**玩家选项 C05-A：** 「先投资设备，再准备监测。」（trade +1，炽角 +1）  
**玩家选项 C05-B：** 「先查水脉，再计划扩产。」（ecology +1，青枝 +1）  
**玩家选项 C05-C：** 「一边监测一边扩产，保留公共库存。」（balanced route evidence，泉泡 +1）

【结果】记录政策倾向、展示可调整的生产优先级 UI；不能凭对白给仓库增加或减少晶核。  
**炽角（A 或 C）：** 「好，那我把设备计划画出来。」  
**青枝（B 或 C）：** 「我去做水脉采样。至少这次有人愿意听。」  
**泉泡：** 「我来记录管路温度！嗯……希望这次不会把扳手弄丢。」  
【状态】`firstPolicyChosen`。

【触发】`firstPolicyChosen` 并有一批新的生产出货。

**月纱：** 「消息比我的商队还快。」  
**伊索：** 「东街还需要稳定的后续供能。我只想知道：遇到物资紧张的时候，谁会先得到它？」

# 第三章：消失的钟声

【地点】公寓二楼。  
【触发】`supplyPolicyPublished`，至少安置一个已有灵核住客（免费或基础可得，不要求 UR）。

**玩家：** 「钟楼以前出现过这种问题吗？」  
**阿洛：** 「有一份被封起来的维修记录。是时候拿出来看看了。」  
【任务】改善一间住客房间的安全/舒适条件，与阿洛前往钟楼；居住行为是一次真实配置，不是点爱心。

## C08 / ch3-s02「钟楼旧账本」

【地点】钟楼地下档案室。  
【触发】C07 完成；玩家主动调查档案架。  
【镜头】尘封的齿轮仍有微弱声响，旧账本停在被撕过的一页。

**阿洛：** 「城市越建越大。为了让更多人用上灯，一位设计师加装了晶核增幅装置。」

**阿洛：** 「诺因。」  
**玩家：** 「最后一页怎么被撕掉了？」  
**阿洛：** 「……我以为把那部分藏起来，就能让居民少一些恐慌。」  
**玩家选项 C08-A：** 「谢谢你现在愿意告诉我。」（阿洛 +1）  
**玩家选项 C08-B：** 「隐瞒会让问题更严重。」（阿洛暂时 -1，增加公开责任的剧情对白）

**阿洛：** 「你说得对。钟楼应该记录事实，而不是替所有人决定什么可以知道。」  
【发现】`clocktower-record-found`，线索「晶核增幅装置」「水脉循环」。

## C09 / ch3-s03「未寄出的合同」

【地点】大厅夜窗旁。  
【触发】C08 完成，玩家与月纱谈话。

**月纱：** 「我赚了很多星币。可是有些街灯，终究还是熄灭了。」  
**玩家选项 C09-A：** 「跟我一起公开这些记录。」

**月纱：** 「我会留下来。不是为了另一笔买卖，而是为了把欠下的部分补上。」

# 第四章：没有月光的夜晚

**伊索：** 「街区一半的灯都黑了，居民已经不敢出门。」  
**菲娅：** 「最后一批月光花也闭合了……」  
**阿洛：** 「钟楼停止运转。我们要在黑雾再次扩散前恢复临时供能。」  
【系统】只使**受影响的设施**进入明确的故事性供能限制状态；给予可恢复路径，不随机清空既有生产库存。  
【任务】查看实际故障原因、设定紧急生产优先级；不要求连续点维修按钮。

## C11 / ch4-s02「一张桌子上的不同答案」

【地点】工坊会议桌。

**泉泡：** 「如果我负责水汽，青枝负责孢子，炽角负责锻造，也许就可以！」  
**玩家选项 C11-A：** 「先做临时供能，确保居民安全。」  
**玩家选项 C11-B：** 「先修复水脉，让系统稳住再升功率。」

【分支影响】两种路线需使用不同资源先后顺序，但都能完成稳定器。关系与三个结局指标产生有限可解释变化；不得产生无法追回的永久卡关。

## C12 / ch4-s03「夜间抢修」

**阿洛：** 「钟楼的核心还没恢复，但已经能维持最低照明。」

【演出】月光街暂时恢复；黑雾缓慢退至钟楼。

# 第五章：月心灯的真相

## C13 / ch5-s01「守着钟楼的人」

【地点】月心灯核心区。  
【触发】C12 完成、玩家选择深入钟楼。  
【镜头】巨大齿轮与静止的指针；诺因在旧控制台前记录能量数据。

**诺因：** 「我知道有人迟早会走到这里。」  
**玩家：** 「月光街正在失去光。你知道原因。」  
**诺因：** 「我曾用这套装置救过城市。当年人们在黑暗中等不到下一盏灯。」  
**诺因：** 「每一次扩建，都有更多人得到照明。可每解决一个需求，就有更多需求出现。」  
**玩家：** 「为什么你不停止增幅？」  
**诺因：** 「因为停止，意味着某些人必须重新回到黑暗。」  
**月纱：** 「你始终以为，只能一个人决定谁应当付出代价。」  
**青枝：** 「我们找到恢复水脉的方法。」  
**炽角：** 「也造出了过去没有的稳定器。」  
**泉泡：** 「大家都来了。你不用再一个人扛着！」  
**诺因：** 「你们真以为还有第三条路？」  
**玩家选项 C13-A：** 「请你把剩下的设计交给我们，一起做完。」  
**玩家选项 C13-B：** 「先向居民公开错误，再共同决定方案。」

【结果】诺因开放核心图纸。B 后续诺因道歉演出更完整，A 提前开放部分技术说明；两者都要求真实生产稳定器。记录 `noinBlueprintReceived`。

## C14 / ch5-s02「最后一条生产线」

【地点】工坊以及钟楼中央。  
【触发】获得图纸、玩家接受公共工程「修复月心灯」。  
【项目配方】月露水汽（净化水泵）、星辉孢子（生态温室）、永续晶核（新熔炉配方）；**具体资源消耗在 P1 纵切片后由平衡表冻结**，不得文案和代码各写一套。

**阿洛：** 「这一次不是无限增加能量，而是让水脉回到能自行恢复的节奏。」  
**青枝：** 「月光花的种子准备好了。」  
**炽角：** 「锻造方案也准备好了。我要做一枚可以真正长久使用的晶核！」  
**泉泡：** 「供水稳定。你们只管往前，我会守住管线。」  
【任务】玩家配置关键设备/配方与库存预留，然后让三位工匠自主工作。获得材料后自动运输，不按次数点击。  
【分段演出（只读 event 流）】

1. `moon-dew-delivered`：泉泡「水汽已经流进主环路！」
2. `star-spore-delivered`：青枝「月光孢子又开始发亮了。」
3. `eternal-core-delivered`：炽角「温度稳定，永续晶核成形！」
4. `moonheart-repaired`：钟楼齿轮缓缓启动，月心灯发光。

**诺因：** 「原来……缺少的不是更强大的机器。」  
**诺因：** 「是愿意一起承担结果的人。」  
**月纱：** 「你现在看见了。我们可以在承认错误之后，继续让城市有未来。」  
【状态】`moonheart-repaired`。解锁最终决议，不自动把玩家送到某个结局。

## C15 / ch5-s03「下一种月光」

【地点】钟楼观景台，所有主要角色到场。  
【触发】`moonheart-repaired`，玩家主动进入最终议事。  
【镜头】从灯火恢复的月光街扫向温室与工坊，三种重建图纸叠在桌面。

**阿洛：** 「钟楼恢复了。但今后该按什么规则运转，不该只由一个人说了算。」  
**伊索：** 「最重要的是，东街的居民不会再被忘记。」  
**青枝：** 「让花园恢复，需要长期的耐心。」  
**炽角：** 「机器还可以变得更好，而且更安全！」  
**月纱：** 「我愿意签一份新的合同。这一次，条款由所有人一起决定。」  
**玩家：** 「让我们决定月光街接下来要成为什么样的地方。」

【三个选项】A「月光花园」偏生态；B「繁荣之城」偏工商业；C「永不熄灭的月光」需贸易、生态、社区三个证据指标均满足条件。  
【锁定提示】如 C 未达标，应清楚说明缺的哪项项目，允许继续经营后再选，不应把理想结局伪装成必须充值的隐藏内容。

# 终章：三条未来

## EA / epilogue-garden「月光花园」

【条件】生态路线可选，玩家明确确认；系统仍要求基础公共供能保障。  
【镜头】许多温室和屋顶花园重新开放，水汽在晨雾中循环，街道上仍有温暖的灯光。

**菲娅：** 「月光花又开了。终于有人愿意等它们慢慢长大。」  
**伊索：** 「灯比以前柔和了一点，可它们的确更可靠。」  
**炽角：** 「生产速度慢些也行。让我试试新的低耗能炉子。」  
**青枝：** 「你看，这一次，它们不需要透支明天来维持今晚的美丽。」  
**月纱：** 「还有生意可做，只是我们终于学会把代价也写进账本。」  
**旁白：** 月光街选择让每一盏灯和每一朵花都有足够的时间。  
【解锁】生态温室、花园外观、慢速稳定配方，自由经营。

## EB / epilogue-prosperity「繁荣之城」

【条件】工商业路线可选且已经完成公共安全稳定器；不存在牺牲居民安全的“坏人获胜”文本。  
【镜头】黄铜轨道延伸，店铺灯火通明，炉火繁忙但有稳定器和维护区。

**炽角：** 「听见没？整座城市的机器都在运转！」  
**青枝：** 「至少现在，你知道该在什么时候停下来检修了。」  
**伊索：** 「东街也有自己的供能配额。以后不会只顾主街。」  
**月纱：** 「新的商路已经打开。我第一次觉得，繁荣也可以写得很有分寸。」  
**炽角：** 「这一次，产能和责任都在我们自己的手里！」  
**旁白：** 月光街再次成为远近闻名的工匠之都，而每一份增长都要说明来自何处。  
【解锁】高级自动化、贸易合同、工业外观，自由经营。

## EC / epilogue-everlasting「永不熄灭的月光」

【条件】贸易、生态、社区三个指标全部满足，且完成三方协作关键工程；可在游戏内查看条件。  
【镜头】花园、铜管与钟楼同步亮起。月心灯不再闪烁，温室的花瓣随着钟声展开。

**泉泡：** 「咕噜！水汽循环完全稳定啦！」  
**青枝：** 「花园自己恢复了生长。」  
**炽角：** 「新炉子既省材料又有力气。这才是我的得意作品！」  
**伊索：** 「街道上的灯，一盏也没落下。」  
**阿洛：** 「十二声钟响……一声不差。」  
**诺因：** 「原来我一直缺少的不是更强的机器，而是愿意共同承担的人。」  
**月纱：** 「我曾以为，所有选择都必须标明价格。」  
**月纱：** 「直到来到这里，我才知道，有些美好的东西，是大家一起创造出来的。」  
**旁白：** 这一夜，月光街找到了自己的节奏：既可以成长，也懂得守护。  
【解锁】永续月心灯、综合工坊与花园外观、后日谈，以及保留所有原有设备与住客的自由经营模式。

## E0 / 通用尾声「回家的地方」

【触发】任一结局首次完成。  
【镜头】钟楼缓缓敲响十二声钟声，光照在公寓窗台、工坊工具台、铺满花的街道。  
**旁白：** 钟楼再次响起，月光街的居民推开窗户，看见久违的灯火。  
**旁白：** 工坊里的机器仍在运转，水汽缓缓升起，孢子在温室中发光，熔炉映出忙碌的身影。  
**旁白：** 那间曾经破旧的怪物公寓，也终于成为所有人都能安心回去的家。  
**旁白：** 月光不会永远没有阴影。  
**旁白：** 但只要有人愿意守护这里，它就不会轻易熄灭。

【操作】「继续自由经营」「回到大厅」「重看回忆」。不强制重开，不清空资产。选择另一个结局需后续周目机制，P1 不提供重复刷结局奖励。
