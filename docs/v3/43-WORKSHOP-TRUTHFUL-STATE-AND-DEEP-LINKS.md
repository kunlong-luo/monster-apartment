# V3.20 · 派工深链接和数据可信度

角色图鉴已经有 `/workshop/?worker=brook|fern|cinder` 的“安排岗位”链接，过去工坊客户端没有消费 URL，玩家跳过去后只是打开普通工坊。现在 Pixi 完成初始化后读取白名单工匠 ID 并派发 `choose-worker`，玩家可接着在画布选择设备完成派工，不冒充已经完成排班。

顶部固定 Lv.60/EXP 72%/SparkPrairie 是演示数据，不来自游戏存档，现改为真实 `workshopRank(world.completed)` 和订单累计完成数。设备资料的原料库存也改为读取设备真实 stored 数量，不再出现“库存充盈”“自给自足”的虚假状态。

验收仍需确认浏览器端到端测试、存档状态、工坊打点操作并人工检查手机可视效果。
