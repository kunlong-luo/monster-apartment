# V3.72 · P2 十连自动演出、SSR 长镜头与回看

## 真实用户功能
- 十连结算后先进入 V3.71 的电影仪式，再自动按原始抽取顺序揭晓 10 张契约。中间十张仍由 `characters` 数组的**已持久化快照**驱动，不重抽、不提前暴露未揭晓卡面。
- 每张人物的大卡都在中心舞台翻入；N 460ms、R 540ms、SR 790ms、SSR 传说 1700ms、SSR 神话 2450ms，玩家可以完整欣赏高稀有人物。首张 380ms 启动。停留时间是 UI 表演，不表示任何概率变化。
- 支持「暂停 / 继续揭晓 / 全部翻开 / 重播揭晓」。手动点击缩略卡或方向键、上一张/下一张都会停止自动播放并保留已经揭晓的结果。继续播放从**最早还没揭晓的位置**开始，不重复计入存档或奖励。
- 完成之后可以点击任一缩略卡进行全尺寸回看，SSR 在卡框上方显示小型王冠与品阶标记，不遮住人物脸部，卡牌配色保持传说金与神话赤红。
- 玩家选择「减少动态效果」时立即完成十张卡的展示，不运行逐张倒计时。
- 已从本次召唤的卡面徽章与预兆中**移除 Sparkles 图标**，改用 Lucide Diamond 与 Crown，不增加新依赖。
- 复用 Motion、Lucide、Next/Image；继续直接在主分支迭代。
- **游戏逻辑不变**：46/31/17/5/1 概率、90 抽保底、十连 SR 保障、真实消耗、碎片、收藏和历史记录均由原引擎负责。重播只是观看本次获得的人物。

## 测试与验收
- Vitest 保证第一张及后续展示顺序、SSR 相对更长停留，不接触抽卡随机数。
- Desktop Visual Review 运行 1440×900 的十连自动播放、暂停后状态不变、继续播放、完整 10/10、重播/跳过仍总计只抽 10 次，以及 SSR 人物大卡截图；加 1 个减少动态效果测试。
- 日常 Quality 只做轻量构建与单测，专项浏览器检查不阻塞普通 Pages。
- 仍采用现有高质量个人面部肖像而非正式 3:4 全身卡 CG，后续 P3 才进行独立高清卡图制作。
