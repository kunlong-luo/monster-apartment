# V3.12 — 画面外物件的真实位置与可访问性

美术图采用 `object-fit:cover` 时，竖屏比原始 16:9 窄，部分物件会真实裁掉。不能把标记强制贴到图边并伪装成画面中的物件，也不能让用户失去剧情线索。

本轮添加 `roomSpotIsReachable`：检查一个完整 44×44px 热点是否在实际舞台内；`RoomSceneHotspots` 对不可完整点击的物件隐藏原地标记，并在画面右上角显示**仅在需要时出现**的 `画面外物件` 入口。展开后用真实语义的按钮调查对应道具，仍调用原 `onInspect`，所以复用原线索、人物反应、存档、秘密和剧情推进，不额外发放奖励。宽屏和当前四间 concept 房仍按原布局展示，不新增长驻按钮。

基准示例：月纱候选高清画面源坐标 `ledger=[0.77,0.815]`；舞台 390×315px 可以完整显示 44px 标记，320×315px 时部分溢出，需从备用入口调查。`seal` 和 `tea` 在 320px 手机仍可正常点击。

需继续检验：
- 实际 320、375、390、430px 移动设备，不同视口高度和旋转；
- 正式月纱 WebP 上传后检查桌面和手机物件画面位置与人物遮挡；
- 在未发布正式素材前，不切换 manifest 的 concept/production 状态；
- CI 的 Playwright 和 Vitest、静态导出全部通过后才视为可发布。

这次只改善交互容错和美术上线门禁，**没有生成或正式入库高清背景及透明四姿态精灵**。
