# V3.2 品阶与卡牌视觉 Token：UR 正式改为绯红

> **产品视觉决定（2026-10-28）：「神话 · 月蚀」UR 的主识别色改为红色。** 本文覆盖 [12 召唤 PRD](12-GACHA-RECRUITMENT-PRD.md)、[13 人物卡面](13-CARD-ROSTER-AND-ART-DIRECTION.md) 中此前的「月虹/黑金」**作为 UR 主色**的写法；黑金只可用作红色主题的次要材质。实现未完成，Token 是策划规格，不是已提交到 Tailwind 的变量。

## 1. 五档品质色彩规范（示意 CSS 色值，非当前代码）

| 品阶 | 中文 | 主题色 | 推荐 HEX | 辅助背景 | 绘景关键词 |
|---|---|---|---|---|---|
| N | 普通 · 星尘 | 暖灰/羊皮纸 | `#B7B4AA` | `#302B2A` | 温柔、日常 |
| R | 稀有 · 月辉 | 月蓝/银蓝 | `#69B7E8` | `#102C40` | 清澈、灵巧 |
| SR | 精英 · 星纹 | 星紫 | `#AB7BEF` | `#28163A` | 幻想、神秘 |
| SSR | 传说 · 夜冠 | 黄铜金 | `#E9BF6A` | `#382610` | 华丽、传说 |
| **UR** | **神话 · 月蚀** | **绯红/赤红** | **`#DE344B`** | **`#350C19`** | **红月、权威、罕见、惊喜** |

UR 辅助材料：`#FFE0E3`（浅玫红高光）、`#EBC18A`（少量金属金线）、`#130D13`（极深底色）。**区别：SSR 金光耀眼，UR 是「深红月光从黑暗中苏醒」**，不是重复的金色卡。

## 2. 不只改 CSS 颜色

- **卡背**：普通卡是黄铜/紫月纹基础，UR 独有深红月蚀纹章与断续的月环刻线。
- **抽取演出**：UR 3 秒左右「卡背绯红月纹浮现 → 血色红月背光扩散 → 独立人物卡缓缓翻出 → 红金线条和人物名字」。可即时跳过、减少动效只显示静态红卡。
- **卡框**：暗绯红细雕刻 + 边缘红宝石 + 少量香槟金细线；不要全屏纯红闪烁、血液/暴力意象。
- **文字/标识**：始终同时显示 `UR` 与「神话·月蚀」，加独有月蚀图标，不靠色彩区分等级；深红背景配高对比文字。
- **图鉴**：UR 卡缩略图、筛选标签、详情品质标志使用同一绯红，内部角色专属背景仍可保持职业风格。
- **房间**：UR 门牌/房间入口具有绯红身份识别；例如艾维拉的「绯月星象寝殿」有赤红月蚀天窗与黑檀星盘，但角色服装可以保留暗紫旅行装，用红色月光和道具形成统一视觉。
- **收藏 CG**：普通故事 CG 不必强制上红色滤镜；UR 人物专属卡面/房间中才明显体现品质，剧情 CG 仍以场景实际光照为准。

## 3. 红色与「告警/缺料」语义区分

当前设备缺料/阻塞可能使用红色警告，不能让 UR 品阶看起来像机器故障。通过 **颜色 + 图标 + 场景 + 边框形状**区分：

- UR：绯红宝石/月蚀纹章/辉光，附文字「神话·月蚀」；仅出现在卡牌、房间门牌、招募演出。
- 故障：短促三角警告、缺料标签/明确物料名，不使用宝石/月蚀边框；不会因角色品质改变设备警告颜色。
- 稀有奖励不使用破坏浏览器安全的超高频频闪；大量红色闪光禁用或降频，respect prefers-reduced-motion。

## 4. 测试门槛

- 卡背、抽取过程、翻卡完成、角色详情、房间门牌、UR 私室第一次揭幕使用相同绯红色板。
- SSR 永远是金色，不与 UR 混同；SR 保持紫色，R 蓝色，N 暖灰。
- 所有等级即使关闭颜色/使用灰度屏/视觉辅助模式仍有可辨文字和纹样。
- 手机低亮度下红框与深色哥特背景有足够对比；品质文字对比度按 WCAG AA 校验。
- 整个视觉 token 只能有一个配置源，UI/动画/图鉴/私室从同一配置读取；旧版「UR 月虹/黑金」只能作为辅助，不应出现在新截图的主色。
- 真正实施前对照已有世界设计，避免为了稀有度把所有角色房间做成同一张红背景。
