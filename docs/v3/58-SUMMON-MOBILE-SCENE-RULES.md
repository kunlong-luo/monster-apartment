# V3.58 · 召唤页 320–390px 首屏排版与真实角色拜访

遵循已归档的 1648×928 原始设计图；桌面维持左主题、中人物、右卡面、底部七入口。移动端缩成**顶部品牌/辅助入口、资源独立一行、横向主题、完整人物主舞台与抽卡操作、后置详情**，不能全屏堆面板。

## 工程改动

- 修复 Next.js App Router 同路径 `/characters/#summon-screen` → `/characters/?visit=fern` 切换时无原生 `hashchange` 的真实路由缺陷：人物视图监听 `useSearchParams()`，已知工匠拜访链接优先进入原角色图鉴/房间；静态导出要求的 `Suspense` 明确设置。
- 召唤页 600px 以下将品牌/辅助工具和实际资源分列两行，三种货币无需横向划动工具栏；不新增菜单按钮。
- 横排五卡池采用 60px 触控行和水平滚动；中央舞台随 700/844px 高度缩放，保持单抽与十连处在底部七入口**上方**。
- 390px 的后置资料栏双列展示卡面与概率/收录进度，320px 按自然单列，避免内容挤压和页面水平溢出；仅内容容器内部允许滚动。
- 保留七条正式路由、抽卡概率、保底、实际资源、人物存档；移动端回归检查宽度溢出、两行动线、首屏抽卡/十连与底部 dock 互不遮挡。

正式高质量人物 CG 仍需独立美术审核，不用 CSS 改动冒充素材交付。只有完整 Quality 与 Pages 成功后才确认部署。
