# V3.76 · 工坊 CG 透明边缘清理、机体占比与设备卡片同源

日期：2026-11-07。承接 V3.75 九张独立设备候选正式入库后的审核阶段。

## 这次解决的实际视觉问题

之前九张机器虽然是真实的 512×512 WebP，但展示方式存在两处直观缺陷：

1. 原对照板自动抠图在黄铜底座下残留了偏白/灰的浅色横线，铺在暗色哥特场景中尤其明显。
2. 以包含透明留边的 **完整 512×512** 画布直接按原机器宽度 0.89~0.95 个地块缩放，使可见机体再次缩小；设备库仍显示不对应的旧 AVIF 风景缩略图，场景与菜单美术割裂。

## 已落实的处理

- `v2/scripts/prepare-machine-review-sprite.mjs` 使用项目现有 Sharp，在构建时从**仍受源 SHA-256 校验的原始 WebP**产出审核用的派生图。只对 **底部 23%** 范围内（y≥394）近中性且高亮的外缘像素执行保守 Alpha 减薄；原颜色、主体、玻璃高光、植物、上方烟雾和原始源文件不变。三台设备 × 三档等级完整处理，各幅必须确实修正一定数量的像素，否则构建报警。原始素材仍可用于审美回滚与重新抠图。
- `v2/scripts/build.mjs` **只有** `status:review` 且 `generatedFrom: curated-cg-import` 的源机体应用派生清理；普通玩家的 `production` 资源保持直接复制、完全不处理；老结构稿和将来的独立批准原画也不会被这个清理脚本改变。
- `v2/src/workshop-lab-stage.ts` 只将审核模式中实际成功解码的机体显示宽高放大到 1.075～1.125 个地块（原为 0.89～0.95）；画布、15 格地板、工匠位置、背后背景、既有生产状态不改变。**点击继续通过固定 146×146 地块 hit-layer**，过宽的 CG 精灵不扩大命中范围，也不会选到相邻格子。对已画好的机器不再叠加与老机壳对应的程序活塞、叶片和晶体几何；保留状态反馈和资源流向提示。机器下方文字放入低调半透明底牌，避免覆盖金属底座。
- `src/components/moonwork/workshop-controls.tsx` 在 `?machine-art=review` 模式使用与场景**同一份派生 WebP 文件**作为卡片缩略图，并取当前已建该工种机器的**最高实际等级**（未建时按 Lv.1）渲染。卡片保留原按钮语义、价格和数量、操作逻辑；WebP 第一次解码失败自动回退旧缩略图。非审核模式继续显示此前正式的 AVIF，不新增玩家可见控件。
- `e2e/workshop-dock-clearance.spec.ts` 覆盖：正常模式旧缩略图不变；审核模式三张卡片加载已审核的独立透明图片；一级与二级的卡片等级跟随真实存档；放大仅在预览模式激活；PC 与手机实机截图，四帧仍待新机体专用图集，不误播放旧图。

## 质量标准与后续

本轮仍是对**候选 CG 的精准显示与边缘清理**，不是将九宫格生成素材冒充九张最终手绘原画。尚需要完整人工审查亮边、玻璃的散射反射、源九宫格的字体残留、透视一致性，再把级别升级为正式 `ready`。对应的水汽泵/温室/熔炉四帧新机体工作图集仍须重新绘制。桌面版优先观察棋盘构图，手机检查缩放后的分辨率与设备卡片可读性。
