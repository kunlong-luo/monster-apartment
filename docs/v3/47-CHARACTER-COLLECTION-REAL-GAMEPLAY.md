# V3.23 · 四名人物的角色收集与养成正式落地

## 已开发

- 四名已有故事人物：月纱、泉泡、青枝、炽角。原有私人房间、剧情线索、性格和二十项基础属性保留；抽取契约卡不会锁住剧情。
- 品阶潜力已真正接入属性：取该人物最高收录契约的 1~5 阶潜力，为其四项擅长能力分别增加 2~10 点（上限 100），与打造装备的加成共同显示。

- 每抽取至少获得一点碎片，重复契约按品阶加碎片。两种首饰与两种装备可打造，选择已收录角色装备，立刻更新人物档案里的二十项能力。
- 装备和剧情分别储存在独立的本地存档中，不改旧剧情选择、存档结构或工坊经济。损坏的收藏存档会冻结写入，不自动重置。
- Vitest 验证概率、资源、装备及存档；Playwright 验证实际抽取、打造、佩戴和刷新。
