# V3.3 六维属性、角色潜力与成长模型

> **状态：Proposal / 尚未上线。** 本文冻结「每个人物都拥有体魄、智慧、力量、精神、血气、速度；品阶越高成长潜力越大」的设计方向，但所有数值均为首测建议，需平衡测试后确认。联动 [12 招募](12-GACHA-RECRUITMENT-PRD.md)、[18 装备锻造](18-EQUIPMENT-FORGING-PRD.md)、[19 基础配方](19-EQUIPMENT-RECIPES-AND-ART.md)。

## 1. 体验目标

玩家抽到角色、访问专属房间、对话了解擅长的职业，再通过**自然工作的成长、适合的首饰装备和人物支线**让其发展。成长应当改变可以看见的生产效率、居民行为、探索提示或角色生活方式，而不是纯粹为了让大数字上涨。

- 所有十二位可招募住客及八位已认识的主线 NPC 都有一套六维基础属性定义，**不等于所有人都必需参与战斗**。没有战斗玩法就不出现没有用途的「攻击/防御/暴击」属性。
- 角色初始品质 `N/R/SR/SSR/UR` 固定；它决定**成长系数与上限潜力**，不决定人物是否值得喜欢，也不剥夺普通角色的生活故事或通关权利。
- 正式主线 NPC 由剧情获得，不从概率池抽；他们有**预设职业成长档案**，可有适用装备但不得因没有抽到 UR 而无法修复钟楼。
- 角色天赋方向（适合什么）与品质潜力（最高能成长多少）分离：力量高的 N 级锻造助手能胜过智慧型 UR 在低级搬运任务中的效果；职业契合、设备布局和资源供应至少同样重要。

## 2. 六个基础属性：严格定义用途

| 属性（代码建议 key） | 具体含义 | 影响玩法的主要场景 | **不应该**影响的场景 |
|---|---|---|---|
| **体魄** `physique` | 肉体承载能力、耐疲劳、环境适应 | 排班可持续性、重物搬运消耗、工作后疲劳积累 | 不等同血气，不代表人物能无限工作 |
| **智慧** `wisdom` | 学习、判断、精密工艺理解 | 特定订单预估准确度、蓝图研究效率、可选线索提示 | 不阻断主线必须的线索/对话 |
| **力量** `strength` | 肌力、机械操作与锻造力度 | 熔炉与重型器具匹配、搬运、某些锻造工序 | 不自动变成战斗伤害倍数 |
| **精神** `spirit` | 魔力控制力、专注与感知 | 水汽/温室灵能稳定、魔法首饰调谐、特殊交互 | 不当作情绪好感或付费能量 |
| **血气** `vitality` | 生命活力与恢复能力 | 休息恢复、连续工作时的精力余量、环境伤害缓冲 | 不与体魄重复堆叠所有抗疲劳收益 |
| **速度** `speed` | 反应、移动、操作节奏 | 运输物流、设备切换、特定非核心操作效率 | 不让所有产线靠速度无限提速 |

**体魄与血气区别**：体魄影响「工作时累得有多快」，血气影响「休息后恢复得有多快」。他们的独立边际价值必须有测试用例。游戏现阶段为模拟经营 + 剧情，不设计角色受到伤害后死亡；「血气」不会诱导对角色过度消耗或把角色写成需要血条的战斗单位。

## 3. 六维成长层级与数据来源

最终显示属性 = **固有基础** + **等级训练成长** + **支线/专精的小幅永久加成** + **已装备器具与首饰** + **条件型羁绊与环境修正**。

所有加项均留在不同的存档字段，**装备仅提供额外属性，不反写角色固有基础值**；卸装必须恢复原值。等级、训练、装备、羁绊分别有自己的来源和上限。切页/离线不能把同一角色成长累计多次。

**品质潜力首测系数（建议值而非已实现）：**

| 角色品阶 | 训练成长潜力系数 | 建议成长曲线 | 长期优势 |
|---|---:|---|---|
| N 星尘 | 1.00 | 易培养、材料便宜 | 在生活与专属房间互动有独特功能 |
| R 月辉 | 1.08 | 稳定成长 | 多一个实用辅助方向 |
| SR 星纹 | 1.16 | 中后期回报较高 | 职业专长与双人协作 |
| SSR 夜冠 | 1.26 | 较高训练成长 | 特殊精密/魔法活动 |
| **UR 月蚀** | **1.38** | **最高长期培养上限** | 独特调谐与个人故事，红色专属演出 |

**系数只作用于「等级/训练成长部分」**，不再对装备和羁绊数值乘一次！装备品阶单独决定装备提供的属性范围。对所有角色使用相同最高等级（首测 Lv.40），不通过低品阶不能到 40 级来人为废弃普通角色。

**拟议公式（清晰且容易测试）：**

```ts
levelGrowth[stat] = Math.floor(
  roleGrowthPerLevel[stat] * (level - 1) * rarityGrowthMultiplier
);
finalStat[stat] = clamp(
  base[stat] + levelGrowth[stat] + training[stat]
  + sum(equippedItems.flatStats[stat]) + situationalBuffs[stat],
  1, 200
);
```

示例：一个 N 级角色和一个 UR 级角色都拥有基础力量 18、每级力量成长 0.5，升到 Lv.21 后，N 的等级力量成长为 `floor(0.5×20×1.00)=10`，UR 为 `floor(0.5×20×1.38)=13`。差距只有 **3 点成长**，而不是 UR 天生对 N 无限碾压；两者使用同一件 +4 力量器具时都**只加 4**。等级系数、最高上限和训练速度正式冻结前需通过模拟验证。

## 4. 角色分工：每个人应有适合的成长方向

| 角色 / 群体 | 偏向属性 | 可见行为 / 用途 | 不能做的事 |
|---|---|---|---|
| 泉泡 | 精神、血气 | 水汽压力调谐、工作后恢复、漏水警报 | 把水汽凭空翻倍 |
| 青枝 | 智慧、精神 | 孢子培养、配方研究、观察月光花 | 提前揭示第三章秘密 |
| 炽角 | 力量、体魄 | 设备锻造、重型炉维护、稳定器实验 | 与任意英雄同时复制两个工作实体 |
| 月纱 | 智慧、精神、速度 | 合约识别、贸易策略、精密首饰调谐 | 没有公示就把订单风险取消 |
| 芽核 | 血气、精神 | 盆栽养护、邻居舒适度 | 被当作失败抽卡废料 |
| 露珠灵 | 精神、血气 | 居民休息活动、恢复提示 | 每秒给所有人加无限血气 |
| 灯甲虫 | 体魄、智慧 | 夜间照明维护、工作可靠性 | 代替东街公共供电项目 |
| 蕨尾兔 | 速度、精神 | 花房搬运、协助温室观察 | 无成本移动无限资源 |
| 月影雀 | 速度、智慧 | 信件运输、可选线索 | 一抽到就直接通关谜题 |
| SSR / UR 新角色 | 个性化主属性 + 明确短板 | 高潜力专精与特殊演出 | 全六维同时无短板碾压 |

最后三位 SSR/UR 招募者和其余住客的精确初始属性需要在角色 manifest 中逐人定义；不能按品阶所有人物用一组一模一样的初始六维。

## 5. 等级、训练与疲劳

- **经验来源**：有上限的真实工作贡献、人物支线、街区公共项目、首次达到生产/房间里程碑。禁止每天点爱心自动刷经验或利用刷新重领经验。
- **训练**：玩家给角色选择训练计划（如「体魄适应」「智慧研究」），角色会在自己的房间/训练时间**自动进行**；可以随时暂停或改计划，不做点一次加一点属性。
- **成长瓶颈**：训练占用有限时间/资源，职业匹配和房间条件影响学习效率，不能在全套自动生产同时凭空训练成满级；有真实机会成本。
- **疲劳**：0–100 作为单独工作状态，不是第七个「基本属性」；体魄降低累积、血气提高休息恢复。达到高疲劳自动休息，不会睡觉回来角色因系统强制劳作而受惩罚。
- **突破**：Lv.10/20/30/40 可开启小型职业认证/人物生活阶段，不用重复抽相同 UR 才能晋级；SSR/UR 可拥有额外外观而不是必需技能。
- **品质潜力**：稀有越高，长期成长空间更大；新手 N/R 更快形成有用的经营协同，保留策略而不是全 UR 最优。

## 6. 属性对经济的可解释影响与上限

**禁止直接使用 `cycleTime = baseTime / speed`，也不允许把六项属性的加成逐项相乘造成产量爆炸。**

首测建议：
- 一台设备的**全部角色/装备/羁绊带来的周期缩短总计最多 20%**；装备本身占用上限建议 ≤8 个百分点，剩余来自职业与房间/设备搭配。
- 物流行动速度最大改善 15%，不能使一份物资被运送两次。
- 蓝图/研究效率总提升最大 20%，不减少配方的实际保底必需材料，不跳过主线调查。
- 疲劳管理与恢复分开计算，角色正常轮班时绝不能因少一点血气变成长期不可用。
- 护符/饰品允许改善恢复和特定可选探索提示，但**对话选项的大事必须仍由玩家选择**。
- 超过上限的提升应在 UI 显示「本岗位加成已达上限」，不可暗中无效或忽然衰减。

数值需要注入真实生产公式和可解释的角色工作状态；如果某项暂时没有实际玩法影响，角色面板就应显示「待开放用途」，**不能假装已生效**。

## 7. 数据模型建议（非现存代码）

```ts
type AttributeKey = 'physique'|'wisdom'|'strength'|'spirit'|'vitality'|'speed';
type Rarity = 'N'|'R'|'SR'|'SSR'|'UR';
type Attributes = Record<AttributeKey,number>;
interface CharacterGrowth {
  characterId:string;
  intrinsicRarity:Rarity;
  level:number;
  experience:number;
  base:Attributes;
  roleGrowthPerLevel:Attributes;
  training:Attributes;
  trainingPlan:AttributeKey|null;
  fatigue:number;
  equipmentBySlot:Partial<Record<EquipmentSlot,string>>;
}
```

其中 `EquipmentSlot` 的完整定义在 [18 装备锻造](18-EQUIPMENT-FORGING-PRD.md)，角色等级与成长建议维护为单一角色记录，由图鉴/房间/工坊只读投影；不能在不同页面各自存一份增长后的最终属性。

## 8. 品阶与内容公平性

- **品阶是潜力，不是角色价值**；拥有 UR 不能直接跳过劳动与故事。所有主线能够使用固定获得的泉泡/青枝/炽角完成。
- N/R 不需要 UR 装备才能胜任基础经营；基础装备能够由前期工坊确定性锻造。
- SSR/UR 的高潜力不能叠加「固定额外订单奖励、倍率翻倍和免费材料产出」三重优势。
- 不能强制送礼/连续登录提升成长；角色成长不和现实付费相关。

## 9. 验收清单

- [ ] 所有角色都有六维 base、growth、level 和可装备槽定义；入驻/切房后人物 id 一致。
- [ ] N/R/SR/SSR/UR 的成长潜力系数 1.00/1.08/1.16/1.26/1.38 只应用于等级成长，UR 红色标签统一。
- [ ] 同样装备在不同品质角色上提供相同的**固定属性值**；卸装完全回退。
- [ ] 体魄与血气对工作疲劳与恢复分别产生真实且可测的作用。
- [ ] 智慧/精神/力量/速度都有至少一个可验证的经营或探索效果，且总体加成有上限。
- [ ] 低品阶 + 合适岗位能够胜过高品阶 + 错误岗位；剧情与主要 CG 不依赖 UR。
- [ ] 派工/训练/休息角色无克隆、生产收益不重复；旧 `cozy:v1` 和 `workshop-v2-lab` 可读。
