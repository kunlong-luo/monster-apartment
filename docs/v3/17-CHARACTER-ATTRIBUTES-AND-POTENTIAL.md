# V3.4 人物能力成长、天赋潜力与数值平衡

> **状态：Planned，非客户端已实装。** 原来的六维属性不再被视为完整的「人」；它们被保留为 **20 项能力中的兼容子集**，完整人物由身份、能力、心理、动态需求、社交关系、技能和人生经历共同构成。**权威人物结构见 [20 人物完整模拟](20-HOLISTIC-PERSON-SYSTEM.md)，主要人物设定见 [21 完整人物档案](21-CHARACTER-LIVING-PROFILES.md)。**

## 1. 20 项能力分组与设计原则

| 领域 | 能力（每项独立，含原六项） | 具体可见用途 |
|---|---|---|
| 身体五项 | 体魄 `physique`、力量 `strength`、速度 `speed`、耐力 `endurance`、血气 `vitality` | 高温/潮湿适应、重型工艺、物流、持续工作、休息恢复 |
| 认知五项 | 智慧 `wisdom`、感知 `perception`、记忆 `memory`、创造 `creativity`、专注 `focus` | 配方研究、观察花朵、回忆线索、设计创新、精密制作 |
| 精神四项 | 精神/灵能 `spirit`、意志 `willpower`、抗压 `resilience`、自律 `discipline` | 魔法调谐、个人意愿、危机后恢复、训练计划 |
| 社交四项 | 共情 `empathy`、表达 `communication`、亲和 `affinity`、领导 `leadership` | 理解居民、解释交易、社交氛围、团队协调 |
| 生活两项 | 手巧 `dexterity`、审美 `aesthetics` | 戒指镌刻、花艺和空间装饰 |

原来已约定的 **体魄、智慧、力量、精神、血气、速度** 仍使用原来的英文 key，不需要在升级时重命名。新十四项单独增加。**体魄/耐力/血气**不许使用三个相同的耐疲劳系数：体魄=岗位环境适应，耐力=工作时长维持，血气=休息恢复；**精神**为奇幻灵能调谐，不等同情绪开心。

20 项只是**属性词典**，不是首个版本必须在屏幕上显示的 20 根进度条。没有实际玩法效果的属性不承诺「已生效」。

## 2. 数值来源和潜力

```ts
type AbilityKey =
  | 'physique'|'strength'|'speed'|'endurance'|'vitality'
  | 'wisdom'|'perception'|'memory'|'creativity'|'focus'
  | 'spirit'|'willpower'|'resilience'|'discipline'
  | 'empathy'|'communication'|'affinity'|'leadership'
  | 'dexterity'|'aesthetics';
type AbilityScores = Record<AbilityKey,number>;
type CharacterGrowth = {
  characterId: string; level: number; exp: number; rarity: 'N'|'R'|'SR'|'SSR'|'UR'|null;
  base: AbilityScores;
  perLevel: Partial<AbilityScores>;
  trained: Partial<AbilityScores>;
  affinities: Partial<AbilityScores>; // 每人物显著强弱项
};
```

`final[stat] = base[stat] + floor(perLevel[stat] × (level - 1) × rarityPotential × affinity[stat]) + trained[stat] + itemFlatStats[stat] + permittedSituationalBonus[stat]`。

- **`rarityPotential`**：N=1.00、R=1.08、SR=1.16、SSR=1.26、UR=1.38，均为首测建议，非已上线平衡；**只放大等级/训练的部分成长潜力，不对装备和所有能力额外叠乘**。具体实现可限制仅 3–5 项职业相关天赋明显受益，以免 UR 全属性碾压。
- **`affinity[stat]`**：角色专精系数，随人物定义，不能所有 SSR/UR 长成相同模板；非职业能力可以设低亲和或短板。
- **`base`**：与角色独立身份/物种/职业设定相关，但不能依据年龄/性别自动套用价值等级。
- **`trained`**：真实训练事件累计，按训练时长、专长、资源和上限审核，默认不会因为离线睡觉无限成长。
- **`itemFlatStats`**：装备固定属性，**一件器具同属性对不同品质人物都提供相同加值**，卸装即消失；没有随机炸装。
- 可训练能力拟议范围 1–200；显示时可以转化为适合手机的简洁等级条，但不能混用未经定义的 1–100/1–200 量表。
- 与品质无关的**人格、信任、恐惧、生活习惯、价值观、经历、承诺**不得装进 `AbilityScores` 以装备增强。人物心理与故事进度见 [20](20-HOLISTIC-PERSON-SYSTEM.md)。

## 3. 劳动、生活、训练和装备的真实用途

| 系统 | 有效能力示例 | 可测改变 | 必须受限的地方 |
|---|---|---|---|
| 水汽泵 | 精神、感知、耐力 | 灵能调谐、异常提示、正常轮班 | 不凭空生产水汽 |
| 温室 | 感知、专注、创造、智慧 | 正确处理水脉变化、研制花艺配方 | 不跳过主线必须的调查 |
| 熔炉和锻造 | 力量、体魄、手巧、专注 | 工作时长、精密锻造、维修提示 | 不因六项叠乘变成 10 倍速 |
| 街区物流 | 速度、领导、表达 | 交付调度、互助运输、团队协调 | 不能复制物料 |
| 公寓生活 | 血气、共情、审美、自律 | 休息恢复、人物习惯对白、房间布置 | 不靠频繁送礼无限加信任 |
| 调查与剧情 | 记忆、智慧、感知、创造 | 非必需提示、更多对话选择与注释 | 不阻断主线或替玩家作道德决定 |

**全产线角色+装备+羁绊对同一设备周期缩短上限建议为 20%，装备部分 ≤8 个百分点。** 超出显示「已达效率上限」，不可继续叠乘。没有实际模拟子系统支撑的能力先只用作人物文字身份标记。

## 4. 动态状态绝不是永久属性

另外维护 `energy` 精力、`fatigue` 疲劳、`mood` 心情、`stress` 压力、`safety` 安全感、`socialNeed` 社交需求、`inspiration` 灵感。它们因工作、休息、事件、关系、房间环境变化，**不随等级无限永久上升**。高疲劳时自动休息；离线模拟与工作状态一致。

人格采用五组倾向加标签：内向/外向、谨慎/冒险、计划/即兴、温柔/直率、理想/现实；不把「善良」「道德」做成可通过戒指永久上升的属性。喜欢什么、害怕什么、信任谁、人生目标、秘密等是人物档案与故事事件。

## 5. 人物示范

- 泉泡：精神/血气/感知见长，害怕让人失望；高能戒指改善调谐，不会自动克服不会拒绝别人。
- 青枝：感知/专注/创造见长，谨慎而有原则；研究笔提高精密观察，不让她自动喜欢无节制工业化。
- 炽角：力量/体魄/耐力高，讲话直接、行动派；锻锤改善工作但成长弧线需要和青枝合作。
- 月纱：智慧/记忆/表达高，成熟外向却不轻易信任；戒指不会自动清除旧合同责任。
- UR 艾维拉：拥有较高成长潜力和独特灵能天赋，仍然可能不擅长居民纠纷与长期体力劳动。

## 6. 升级、存档和验收

- 首个角色纵切片只真正接入 6–8 项可测能力，其他能力进入配置表并公开标记未来用途，避免 UI 过度复杂。
- 老档可从 `characterId` + 现有角色记录初始化能力，新十四项必须来自**逐人专属设定**，不能所有居民同一份人格数值。
- 剧情、私室、图鉴、工坊必须读取一个权威人物档案/装备快照，不能按页面单独计算成长。
- 只在生产规则函数/权威事务中获得经验与完成训练，不依赖动画或打开人物面板次数。
- N/R 与主线固定角色可完成全部五章；UR 不绕开主线，任何人都不能用数值「买到」他人的信任。
- 20 属性与人格/身心/社交记录的完整字段、可见变化和约束以 [20](20-HOLISTIC-PERSON-SYSTEM.md) 为准，人物具体实例以 [21](21-CHARACTER-LIVING-PROFILES.md) 为准。
