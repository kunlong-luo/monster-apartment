# V3.62 · Next Image 原生能力 + 首次图片失败恢复

## 使用成熟依赖而非额外加载框架
依据 `AGENTS.md`，优先使用 Next.js 16 已有的静态图片、预加载及 `onError` 处理机制。用 `ReliableImage` 做极薄的错误恢复包装，不增加第三方依赖与第二个图片缓存系统。

- 现有静态资源保留真正的路径、宽高、尺寸、alt、优先级；成功时完全不改变请求地址。
- **确实收到浏览器加载错误时**，仅追加一次 `?asset_retry=1` 避开失败缓存。无频繁轮询、无无界请求、不会刷新整页或重置游戏状态。
- 场景主图在首图和重试都失败后，才用原本现成的第二版高清场景绘画作为最后后备。
- 欢迎页移动端 `picture/source` 需要同步重试 source，不然仅改 img.src 仍会被浏览器选择错误的 source。
- 首次进入欢迎页的人物头像、首页中央绘景、召唤人物/卡池/背景、角色房间背景复用同一轻量机制。
- 图片组件使用 Next.js 现有能力，补纯函数 Vitest 来检验 Pages basePath、query/hash 与 blob 安全；保留现有静态资源审计。日常 CI 不恢复全量 E2E。
- 游戏可见 UI 版本为 `V3.62`。视觉素材未大改，主要解决连接首次不稳时的图片空白，绝不冒充重新生成高清 CG。
