# V3.18 游戏质量：双标签页进度同步与后台动画暂停

## 当前修复

- 公寓原有保存逻辑只有本页状态变化时才写入 localStorage，却没有侦听另一个标签页的 `storage` 事件。两页同时打开时，旧标签页的下一次计时保存可能覆盖另一个页面的建造与住客操作。现在收到外部公寓存档变化时同步 UI 状态；损坏的外部数据进入原有安全恢复页，绝不自动写入空白存档。
- 保存前先比较现有 JSON；完全相同的跨标签页更新不再重复写入，减少无意义的存储事件。
- PixiJS 已有后台 ticker 停止机制，不重复开发；补全 Motion 烛光动画的页面可见性暂停。返回前台后恢复当前光照，不重置剧情和经营数据。
- Next 站点标题/分享说明由过时的“灵核公寓”统一为《怪物公寓》，匹配当前七个页面。
