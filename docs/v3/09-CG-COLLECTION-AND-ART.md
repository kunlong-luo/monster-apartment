# V3.1 收藏插画（CG Gallery）与美术资产生产规范

> **状态：Planned / 尚未集成正式 CG。** 玩家收藏的是一次选择、一段人物成长和一个真实事件的回忆，而非随机弹出的高质量图片。关联 [剧情 UX](08-NARRATIVE-DIALOGUE-UX.md)、[伏笔和彩蛋](10-FORESHADOWING-AND-EASTER-EGGS.md)。

## 1. 收藏系统定位

- **主要回报**：完成主线、角色支线、公共工程时解锁一张精美永久收藏 CG。
- **隐藏回报**：细心探索可解锁额外「秘密相片、道具手稿、角色信件」与变体；它们**不含数值优势和主线必须技能**。
- **陈列价值**：图鉴可筛选人物/章节/地点、查看故事说明、放大、轻视差展示、无文字原图预览、已发现伏笔说明与重看对应剧情。
- **主线 CG 不依赖抽卡**：本体主线与关键 CG 可确定性完成；V3.2 可选随机招募「居民卡」，但人物卡牌和剧情回忆 CG 是两套收藏，绝不把主线关键 CG 放进随机池。P1 不设计购买 CG、付费稀有度或付费解锁结局。
- **明确原画状态**：占位 Canvas 精灵和现有背景不能冒充正式收藏 CG；每张入库前进行角色一致性和画质审核。

## 3. 收藏数据与解锁

```ts
type CollectibleId = string;
type CollectibleRecord = {
  id: CollectibleId;
  sceneId: string;
  characterIds: string[];
  category: 'main'|'character'|'secret';
  assetKey: string;
  unlockBy: {kind:'event';eventId:string};
  spoilerStage: 'none'|'chapter'|'reveal';
  altTextZh: string;
  descriptionZh: string;
};
type CollectionProgress = {
  schemaVersion:1;
  unlockedIds:string[];
  seenIds:string[];
  inspectedClueIds:string[];
};
```

解锁由世界事件、人物支线和持久进度的可信事务触发。不能仅凭 `img.onload`、播放粒子或点击收藏卡写入游戏资源。重播场景和重新加载不能重复发奖励。

- **未解锁**：显示中性轮廓和章节占位编号「神秘回忆」，禁止预加载未解锁 CG 全分辨资源，避免浏览器缓存泄露剧情真相。
- **已解锁**：展示完整原画、日期/地点/角色说明、前置故事回顾入口；可查看收藏进度。
- **隐藏 CG**：未发现时不展示标题、角色头像、剪影剧透和确切未解锁数量；发现后归入独立的「秘密回忆」分类。
- **离线**：一旦解锁，进度存在本地可靠存档；离线再次进入可展示已打包的本地素材。没有联网生图 API 才能查看的机制。
- **资源缺失**：状态仍为已解锁，展示审美一致的占位提示而不是破坏剧情流程；资源 QA 不通过不得标记为「正式 CG 完成」。

## 4. 高质量图片的美术规格

**统一视觉：** 哥特木铜玻璃、深蓝/月紫环境、暖金烛火、花草翠绿与有层次的柔光；角色造型、发色/体色、服饰、标志物、年龄表述与角色圣经一致。画风统一优先于单张极端写实。

| 类别 | 建议母版 | 场景用途 | 交付要求 |
|---|---|---|---|
| 章节 CG | 2560×1440 或同等 ≥2K 16:9 | 全屏剧情插画/收藏大图 | 原始无 UI 字幕、全屏构图，安全裁切 |
| 角色回忆 | 2048×2732 约 3:4 | 图鉴纵向卡与人物故事 | 成人角色设定一致，完整主体 |
| 秘密手稿/道具 | 2048×2048 1:1 | 放大可研究的线索 | 画上文字由排版层后期加，不把 AI 乱码当可读档案 |
| 角色透明立绘 | 单角色 ≥1024px 高 | 对话分层或独立展示 | 透明 alpha，严格避免背景假透明 |
| 窄屏资源 | 从原画裁切/另绘移动版 | 手机对话/收藏 | 保留眼睛、手势和关键信息，不拉伸 |

以上是**制作目标而非已存在的文件**。发布的 WebP/AVIF 目标质量和大小依据目测与端上性能测试调整；不要以只变更图片 metadata 或锐化来冒充增加真实细节。

**交付单位：** 一个 `assetId` 对应母版、压缩版本、缩略图、移动安全裁切参考、人物设定比对、alt 文本、来源/许可/制作记录、审核状态。角色特写可拆分前景/背景供 Motion/Pixi 轻视差；不能把单张静画标为 12 帧工作动作。

## 5. AI 辅助原画生产流水线（无强制订阅）

1. 根据人物圣经制作角色身份基准图：正面/侧面、服饰标记、配色与表情规范。
2. 从剧情场景生成文字分镜：情绪、镜头、角色站位、光源、动作；每张 CG 至少具备一个明确叙事目的。
3. 生成候选母版；只使用有授权的参考资源，检查版权、形体/手指、服饰与五官连续性。
4. **人工审稿**：角色像不像同一个人？画面是否透露错误伏笔？夜景亮度/对比度是否能在 390px 上看懂？
5. 修正或重绘后导出正式 16:9 和所需 3:4 变体，保留原始 master；透明人物单独导出。
6. 压缩、签入仓库资源目录或受控资源包，生成资产 manifest，验证本地和 Pages basePath。
7. 对比实际浏览器截图，审核不会因为导航/放大产生糊图；审美不合格不以测试绿灯冒充完成。

**不建议 P1 采用运行时 AI 即时绘图来生成收藏奖励**：成本与延迟不可控、角色一致性难保证、离线玩不了且无法人工审查；预制原画才适合收藏价值。

## 6. 收藏观看交互

- 角色页有「人物 / 章节 / 回忆」三类轻量入口，避免新增第八个正式页面；大图展示使用场景内画廊，不盖满工坊操作区。
- 点击已解锁 CG：高清原画、简短回忆注释、关联角色、可选轻视差/音效、查看对应剧情；退出后回到原滚动位置。
- 支持「查看无文字图片」，收藏才可以被欣赏；分享/导出要检查作品许可与个人隐私，没有授权不可上传用户自定义图片。
- 隐藏 CG 的奖励应该包含新的对白、世界理解或纪念价值，**不提供打破平衡的强力设备**。
- 不推出「未集齐就不能结局」的收集度压力，收藏是奖励不是惩罚。

## 7. QA 门禁

- 26 个逻辑槽位 ID 唯一；首次事件只解锁一次；按场景/人物筛选准确。
- 新用户看不到章节秘密、诺因身份或月纱过往的完整标题与缩略图；隐藏 CG 不泄露。
- 刷新、切七页、离线、回忆重放和多标签访问后，解锁状态一致、无重复资源奖。
- WebP/AVIF 解码失败、减少动态、无声音、弱机模式均可关闭收藏回到游戏。
- 原画在 PC、320/390px 手机中不变形、不出现文字/角色脸部被字幕或导航挡住；资源丢失有降级。
- 审核通过才将一张收藏从 `draft` 改 `approved`；**AI 生成候选图不自动等于正式游戏美术**。

## 8. V3.2 角色卡面与剧情 CG 的资产边界

- 招募人物卡是 `CardPortrait`（2:3 竖向构图、品质框、职业/性格展示），从完整角色身份中衍生；它不是玩家完成故事后才获得的 `StoryCG`（通常 16:9，带明确情节和人物转折）。
- 获得人物卡会解锁该角色的入驻档案及首次相遇对白，**不会自动开放她/他的全部个人回忆插画、隐藏线索或主线大结局图**。
- 同一个人物的卡面、剧情立绘、房间活动、个人 CG 必须保持服饰、五官、轮廓与名称一致。只有 CG 取得自己的事件解锁资格后才加入回忆画廊。
- 角色卡与 CG 的 manifest 分开管理、可以共用人物基础设定；不预加载未解锁秘密全分辨 CG。详见 [12 招募 PRD](12-GACHA-RECRUITMENT-PRD.md) 与 [13 首批卡池](13-CARD-ROSTER-AND-ART-DIRECTION.md)。
