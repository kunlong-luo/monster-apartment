# V3.13 · 游戏内高清候选素材预览

进入 `/apartment/?roomArtReview=1`，与月纱交谈并进入会客室。场景右上角出现**仅审核时显示**的本机 WebP 选择器。选一张无人物、16:9 的高清会客室候选绘景即可临时替换场景底图；独立人物站位移到左侧，三处物件锚点按照真实容器 `object-fit:cover` 投影，调查光圈同步。可以调查、对话并观察是否遮挡；点击“恢复原概念背景”即可撤销临时效果。

- 不带 `roomArtReview=1` 参数的普通玩家不会看到选择器。
- 图片只作为 `blob:` 本机 URL 在浏览器里使用；**不上传服务器、不写入本地存档**，卸载组件或更换文件会注销对象 URL。
- 预览只接收 10 MB 以下 WebP；正式资源仍必须经过 `art:review`、人工审查、`art:promote` 和 CI；本地预览不构成美术批准。
- 此模式只对月纱开放，不能用带人物的合成 CG 当无人物背景。月纱当前独立角色还是概念期旧素材，最终须使用审核后的透明四姿态。
- 注意：未选择本机图片时一切仍沿用已发布的概念画与老热点，不变更任何角色或经济数据模型。
