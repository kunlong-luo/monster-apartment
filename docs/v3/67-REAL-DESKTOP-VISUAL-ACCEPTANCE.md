# V3.67 · 真实 PC 截图验收反馈

## V3.66 浏览器截图揭示的失真
- 自动浏览器测试虽然通过，但工坊画布在 screenshot 时仍然是黑底，因为旧测试未等待 PixiJS mount 完成。
- Linux GitHub runner 原生环境缺少 CJK 字体，中文文字渲染为空框，不能用于合格的中文 UI 审查。这是测试环境问题，不代表 Windows/macOS 玩家一定遇到相同问题。
- 1440×900 工坊中第三位工匠卡片被面板下边界裁切，必须滚动，属于实际桌面 UX 问题。
- 开发环境 Next.js 工具徽标会出现在截图左下角，但静态发布没有此徽标。

- 桌面专用调度面板给派工列表留足高度，并压缩说明、卡片间距、标题内边距；保证三名工匠同屏可见，保留中央 Pixi 绘景。
- Browser Review 先安装 Ubuntu 正版 Noto CJK 系统字体，再截图；安装非项目打包依赖，不增加游戏运行时体积。
- 浏览器截图只在测试时隐藏开发工具徽标，并等待真实 `data-runtime-ready=true`、Pixi canvas 可见后截图。检测真实第三位工匠卡片的边界是否被截断。
- 继续在独立 Desktop Visual Review 流水线里做专项 PC 截图，不加入 Quality / Pages 硬门槛。
