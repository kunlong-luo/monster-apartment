# V3.59 · 召唤展示品阶与概率数据统一

## 问题
V3.56 原逻辑从角色潜力等级推测 SSR/SR/R 卡面品阶，导致泉泡的真实 N 常规卡被标为 R。该标注与抽卡引擎相矛盾；此外概率表为静态文字，未来改动引擎后有可能不同步。

## 改动
- 右侧人物卡品阶直接读取 `GACHA_CHARACTERS` 的 `rarityZh`；不再由潜力等级猜测品阶。
- 当前主题人物的基础概率直接读取同一 `rate` 字段，并明确提示「主题不额外加成」。五个视觉主题不会修改实际随机分布。
- 五档概率由 `GACHA_CHARACTERS` 动态渲染，杜绝 UI 与抽取引擎的重复硬编码。
- Playwright 核对泉泡 N 常规 46%、青枝 R 稀有 31%、炽角 SR 精英 17%、月纱 SSR 神话 1% 与完整五档概率。
- 所有改动限于展示层；不变更玩家货币、保底、抽取概率、存档键、七条路由。卡面仍使用现有缩略 CG，不冒充四姿态透明正式原画。

## UI 基线
继续遵循 2026-10-29 的黑紫酒红/哑金设计图：全屏绘景、人物主体、左卡池、右精简展示卡、顶部真实资源、底部唯一七项导航；不要叠加新的悬浮按钮。
