# V3.2 人物专属房间图鉴与美术分镜圣经

> **状态：创作与制作规范，未交付正式房间插画。** 设计承诺：**每个人物一个专属可进入空间 + 一张独立精美室内展示大图 + 可以与人物交谈的真实生活场景。** 除房间外每位有卡面和独立回忆 CG；三种美术资产不能互相冒充。参考 [14 房间 PRD](14-CHARACTER-PRIVATE-ROOMS-PRD.md)、[13 角色池](13-CARD-ROSTER-AND-ART-DIRECTION.md)。

## 1. 绘景总美术要求

- 整体画风：精致 2D 哥特奇幻、月夜靛蓝与烛金交织、铜制工艺、玻璃、木质、植物细节；**每一间房有独立主题主色、建筑细节、桌上物件、人物生活痕迹**。
- 镜头建议：室内 16:9 横屏完整构图、人物有明确站/坐/倚位置，近景 1–2 件可互动道具，远景可观察季节或月光街；画面有可供对话 HUD 的安全空白。
- 角色必须融入房间而不是把立绘贴到场景正中；角色着装/配件与召唤卡、主线 CG 统一。
- 不是每间都要巨大祭坛和强光；普通角色的小房间也有自己的温暖、幽默、私密与设计感。
- 所有剧情秘密物件按章节揭示条件展示；例如诺因的完整增幅设计图只有第五章后允许读。
- UR：深绯红/赤红月蚀主题、金属红金细节、高级渐变，不能误作受伤/系统警告。

## 4. 最小首批视觉分镜（四间，不要一次性投入 20 间）

### R01「泉泡的铜管休息间」

**画面**：左侧发蓝光的铜阀与小水池，中间泉泡靠在工具箱边，右侧一扇月光窗；空挂钩一眼可见但不过分高亮。  
**动作**：工作后疲倦地打呵欠，空闲时拍拍水泡。  
**初次拜访对白**：  
泉泡：「咕噜！原来你真的会来看我。」  
玩家：「你是不是还在担心水泵？」  
泉泡：「一点点……不过你进来了，我想先把工作放一放。」  
**热点**：工具挂钩（F-03）、水位表。  
**变化**：完成 BR-03 后工具放回原位，房间灯变暖。

### R02「芽核的萌芽小屋」

**画面**：木窗台的盆栽与小枕头、细碎的星点，芽核靠近窗边照看嫩苗；视觉风格温暖。  
**动作**：蹲下种花、拂掉叶片上的露水。  
**初次拜访对白**：  
芽核：「我想把这里弄成世界上最小、也最快乐的花园。」  
玩家选项：「先种窗边的那盆花」／「和蕨尾兔商量一下种子」。  
**热点**：窗台小盆、种子信。  
**变化**：与蕨尾兔互动后盆栽开出微光小花。

### R03「露珠灵的雨露浴室」

**画面**：室内水纹玻璃窗、水面淡蓝倒影、铜制小吊灯；露珠灵把故事书放在浴池边，泡泡浮起。  
**动作**：轻轻浮在水面、打开书本。  
**初次拜访对白**：  
露珠灵：「想听个睡前故事吗？今天这一篇有一点点关于月亮。」  
玩家选项：「好啊」／「今天先看看你的藏书」。  
**热点**：故事书、水纹镜。  
**变化**：与灯甲虫成为邻居后，夜灯不再太亮。

### R04「月纱的契约会客室」

**画面**：深紫与香槟金配色，月纱倚坐银色茶桌旁，窗外月光街钟楼清晰但不剧透；蜡封、茶杯、旧账簿位于可观察的位置。  
**动作**：翻合同、轻敲杯沿、对话时缓慢抬眼。  
**初次拜访对白**：  
月纱：「怎么，来找我谈一笔大生意？」  
玩家：「只是想看看，你平时在这里做些什么。」  
月纱（轻笑）：「那恐怕比一份合同更难看懂。」  
玩家选项：「问她最近的生意」／「注意桌上的月纹蜡封」。  
**热点**：蜡封（F-02）、旧账簿（第三章之前只允许外观观察）。  
**变化**：第三章旧合同揭晓后桌面多出一份可公开阅读的档案；完成 YU-03 后窗边出现东街居民的感谢信。

## 5. 本轮房间设计的画质验收

| 检查项 | 每间必须满足 |
|---|---|
| 独一性 | 去掉人物立绘和名字后，仍能从物件/光线/构图辨认所属角色 |
| 人物一致性 | 卡牌、工坊精灵、房间立绘同样的形象/服饰/标记 |
| 高清展示 | PC 1920px 无显著锯齿/模糊，放大不是低清图片锐化 |
| 手机适配 | 390px 保留人物面部、1–2 个关键热点、字幕和退出控件 |
| 情境真实 | 工作/休息/访客状态和经济/世界事件一致，不产生角色分身盈利 |
| 伏笔保护 | 初见只埋设而不泄露第 3–5 章的完整真相 |
| 可访问性 | 物件有文字标签、44px 触控区、减少动画与静音可用 |
| 玩法价值 | 进入房间能与人物对话、观察物品、看到可验证的情感/环境变化 |

## 6. 房间资源 ID 及实现顺序

房间以 `room:<characterId>` 作为逻辑资源键，资源由 manifest 指向独立 WebP/AVIF 层，访客房也使用同一组件，不硬编码路径拼接猜资源；运行时应当按当前角色加载，退出时销毁 Pixi 贴图引用/中断动画并保持可恢复剧情状态。

- **第一期**：泉泡、芽核、露珠灵、月纱四间正式图及可交谈实物；形成「房间 → 对话 → 线索 → CG」闭环。
- **第二期**：剩余九位可招募居民与七位剧情 NPC 的专属场景，凑齐 12+8，共二十种；每位有明确可访问条件。
- **第三期**：更丰富的时间/天气分层、角色关系道具变化、个人支线片段和收藏级房间截图功能。

**不要把表中拟议绘景、对白或房间当作已发布的素材。**

## 7. V3.3 首饰、护具与个人房间的视觉连续性

每间房允许一处真实装备陈列：泉泡的水纹首饰盒、芽核的植物护衣挂架、露珠灵的柔光灵环、炽角的锻锤架、月纱的契约戒盒等。陈列显示来自角色实际穿戴/已拥有的装备配置，不能未制作就展示高级 UR 道具；角色尚未佩戴时有合理空置状态。

**高阶佩戴视觉**可利用 1–2 层局部透明装饰和少量微光体现，不强制重画每套房间或 6×20 套人物姿势；人物相貌与故事道具优先保持一致。UR 神话装备与门牌保持 **绯红色主题**，普通装备也有独特工艺与生活痕迹，而非全靠边框颜色。

角色房间原画与装备原画依次审核，先制作泉泡/芽核/露珠灵/月纱四间作为演示，再扩展；全套配饰和装饰变体属于后续制作，不是现已存在资源。参考 [18 锻造规则](18-EQUIPMENT-FORGING-PRD.md) 与 [19 装备美术](19-EQUIPMENT-RECIPES-AND-ART.md)。
