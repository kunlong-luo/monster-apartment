# V3.65 · PC 工坊、公寓、月光街的实际组件改造

- 优先桌面版（≥1100px），修复工坊三栏控制台面板过密：为工匠列表提供固定合理宽度与独立滚动，缩减虚假按钮式标签，保留一键派工和完整的手动换岗按钮事件。
- 工坊设备生产图标与材料图标改为 Lucide 组件；无意义的“已建造/已建 0”叠加标签删除一层，取消 PC 端重复 logo。主生产按钮从塑料金色改为深酒红雕金按钮；原工作流仍由现有 runtime dispatch 负责。
- 公寓六扇门、建筑、居民照顾/搬迁、家具、日志与时间控制改为 Lucide 图标，统一视觉符号；房门与右边操作面板变成细金色玻璃样式，中央背景和命中区域不变。
- 月光街三个真实路由门户与三类货品全部改为 Lucide，狭窄侧栏的建筑、居民、交易区收缩边距、保护文字阅读。
- 所有变更只换现有 React/Tailwind UI，继续使用已安装 lucide-react，不动概率、游戏存档、游戏逻辑及七个正式路由。暂不强制日常全量 E2E。
- 新增 1440×900 工坊、公寓、月光街的定向浏览器检查和截图脚本；实际截图审核需执行浏览器测试后才可声明。
