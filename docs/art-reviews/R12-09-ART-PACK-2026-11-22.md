
原生图片与 WebP 的真实二进制已分别通过 `mcp__GitHub__create_blob` 上传，核对了 Git 对象 SHA，并使用同一个原子 Git tree 提交。审稿 JPEG 联系表也在 `docs/art-reviews/R12-09-ART-CONTACT-SHEET-REVIEW-ONLY.jpg`。

现在可以直接在仓库根目录运行：

```bash

```

验证器核对六个资源文件的真实 SHA-256、字节长度、PNG/WebP 文件头和原生尺寸，并检查它们**只是已入库待审文件、未获得生产批准**。Quality 流水线同样运行此检查。

## 不允许的捷径

- 不得将 S05 1672×941 / 941×1672 的素材插值扩大到 2560×1440 / 1080×1920 后声称通过原生尺寸。
- 不得将这些 review WebP 移至 `public/art/world-scenes/r12/orders-{desktop,mobile}.webp`，或将 `r12-scene-manifest.json` 的 orders 从 `review` 改为 `production`。
- 不得覆盖 `public/art/beauty-beasts/characters/fern/cg-spring-candidate.webp` 或调整 `cg-manifest.json` 的 `status`；新 CG 暂时应在 `fern/review/` 独立存放。
- 不得将 PNG/WEBP 打包成功等同于实际浏览器视觉 QA、身份核验或授权签署；ZIP 中的联系表只作人审参考。
