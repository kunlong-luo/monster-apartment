## 二进制资产在项目中的正确路径

本次 ZIP 的**根目录就是 `monster-apartment` 仓库根目录**，解压时请保留以下路径：

```text
art-sources/review/2026-11-22/
  orders-desktop-v1.png
  orders-mobile-v1.png
  fern-spring-bow-v1.png
public/art/world-scenes/review/2026-11-22/

  R12-09-ART-CONTACT-SHEET-REVIEW-ONLY.jpg
scripts/
  verify-r12-review-assets.mjs
```

可在仓库根目录解压：

```bash
unzip monster-apartment-r12-art-review-2026-11-22.zip -d .
node scripts/verify-r12-review-assets.mjs
```

验证器校验六个文件的真实 SHA-256、PNG/WebP 文件头和原生尺寸，**不会**修改任何正式生产清单或签审字段。该 JSON 清单也单独保存在 Git 中，便于下载后离线校验。**此条必须如实记录：当前 GitHub 连接没有从 ChatGPT 本地文件系统读取并推送二进制 PNG/WebP 的写入接口，因此本轮无法独立完成远端二进制提交；只能交付带完整项目路径的 ZIP，并提交同步文档、脚本、哈希到 `main`。** 若日后在具备仓库文件写入能力的环境完成复制，必须再次核对 SHA 和提交记录后才把 `availableInGit` 状态更新。
