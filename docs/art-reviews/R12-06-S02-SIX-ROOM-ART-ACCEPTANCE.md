## 美术必须交付的六个房间

一张**独立于 S01 大厅**的 S02 建筑画作：一眼能够认出同一栋幻想公寓的六个物理房门（左右两翼每边三个可区分、带立体门框），保留女主人站位的中央留白。每扇门必须有不同装饰和符合房间类别的可识别线索，但不得将任何 UI 按钮、文字或房间编号烘焙进原图。

## 真正的双端原生图

- PC 横版：独立绘制、至少 3296×1856 能覆盖 1648×928 DPR2；游戏也检查 1440×900 与其他屏幕的 cover 采样，必须源图和发布 WebP **都不放大**。
- 手机：再绘制一幅独立、真正以竖向建筑节奏安排六扇房门的至少 1080×1920 PNG；不是从 PC 4K 画面 crop、插值或旧大厅拼贴。
- 正式发布两个 WebP 时均固定源 PNG、源 SHA-256、真实编码像素、图片版权和图像人工签收。场景图不包含 UI、文字、固定角色立绘或其他误点区域。

## 从绘景到可点击区域

在 `public/art/world-scenes/r12-scene-manifest.json` 的 production review 下，需要新增经过人工审核的

```json
{
  "roomHotspots": {
    "desktop": [{"roomIndex": 0, "x": 0.25, "y": 0.4}],
    "mobile": [{"roomIndex": 0, "x": 0.45, "y": 0.3}]
  },
  "roomHotspotBrowserProof": {"desktop": true, "mobile": true}
}
```

以上只示范**一项结构**，并不是已经完成的六门映射或可发布配置。实际各自必须填满索引 0–5 的六个唯一位置，坐标是**原生源画 0–1 归一化坐标**。导出 WebP、不同屏幕下都按 `object-fit: cover` 几何投影，任何房门落出 22px 安全区域或任意两扇门在同一设备上的中心距离小于 44px，CI 拒绝晋级。制作团队还须真实在 390×844、390×550、1440×900、1648×928 DPR2 截图下手动点击全部六门，核对每次都打开**对应真实房间抽屉**，才能签署 `roomHotspotBrowserProof`。单纯填两个布尔值不代表视觉审核已经发生。

本轮增加的是**生产准入合同与坐标几何拒绝规则**，并未制作生产六房间原画、没有在当前旧大厅背景上强行摆六个假门，也没有改变玩家的存档。只有后续艺术作品实际到位、按钮真正接上 `onChoose` 并经过同 SHA 浏览器验收，才可将 S02 从 review 升为 production。
